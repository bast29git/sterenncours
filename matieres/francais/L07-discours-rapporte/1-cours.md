## 1. Ce qu'est le discours rapporté

::: definition Discours rapporté
Le **discours rapporté** est la façon dont un récit intègre les **paroles** ou les **pensées** d'un personnage.
:::

::: grille
| Forme | Ce qu'elle fait | Exemple |
|---|---|---|
| **Discours direct** | cite les paroles telles quelles | Il dit : « Je pars demain. » |
| **Discours indirect** | les intègre dans une subordonnée | Il dit qu'il part le lendemain. |
| **Discours narrativisé** | les résume en un mot | Il annonça son départ. |
| **Discours indirect libre** | mêle la voix du personnage à celle du narrateur | Il partirait demain. Rien ne le retiendrait. |
:::

::: retenir
Ces quatre formes ne disent pas la même chose du même fait.
Le choix de la forme est un **choix d'écriture** : il modifie la distance entre le lecteur et le personnage.
:::

## 2. Le discours direct

::: definition Discours direct
Le **discours direct** rapporte les paroles **exactement** telles qu'elles ont été prononcées.
Il se reconnaît à trois marques : les **guillemets** ou les **tirets**, les **deux-points**, et un **verbe de parole**.
:::

::: exemple Les trois marques
`Elle répondit : « Je n'ai pas le temps aujourd'hui. »`

Le verbe de parole : **répondit**.
Les deux-points, qui annoncent la parole.
Les guillemets, qui l'encadrent.
:::

::: grille
| Élément | Rôle |
|---|---|
| **Verbe de parole** | indique qui parle et comment |
| **Deux-points** | annoncent la parole qui suit |
| **Guillemets** | encadrent l'ensemble d'un dialogue |
| **Tirets** | marquent chaque changement d'interlocuteur |
| **Incise** | le verbe de parole placé à l'intérieur ou après la parole |
:::

::: definition Incise
Une **incise** est une proposition courte insérée dans la parole rapportée, ou placée après elle, et qui indique qui parle.
Le sujet et le verbe y sont **inversés**, et elle est encadrée par des virgules.
`« Je pars demain, dit-il, et je ne reviendrai pas. »`
:::

::: piege L'inversion dans l'incise
On écrit `dit-il`, `répondit-elle`, `s'écria Marie`, avec un trait d'union quand le sujet est un pronom.
On n'écrit **jamais** `« Je pars, il dit. »` L'inversion du sujet et du verbe est obligatoire.
:::

## 3. La ponctuation du dialogue

::: methode Ponctuer un dialogue
::: etapes
1. J'ouvre les **guillemets** au début du dialogue.
2. J'écris la première réplique directement après les deux-points.
3. Je vais à la **ligne** et je mets un **tiret** à chaque changement d'interlocuteur.
4. Je ferme les **guillemets** à la fin du dialogue entier, une seule fois.
:::
:::

::: exemple Un dialogue correctement ponctué
`Elle s'arrêta sur le seuil et demanda :`
`« Tu viens ?`
`— Dans une minute, répondit-il sans lever les yeux.`
`— Tu as dit ça il y a une heure.`
`— Je sais. »`

Remarque : les guillemets s'ouvrent **une fois** au début et se ferment **une fois** à la fin. Les tirets suffisent à marquer les changements de locuteur.
:::

::: piege Les erreurs de ponctuation les plus fréquentes
Mettre des guillemets à **chaque** réplique : inutile, les tirets suffisent.
Oublier d'aller à la **ligne** à chaque changement d'interlocuteur : le lecteur ne sait plus qui parle.
Oublier les **deux-points** avant l'ouverture du dialogue.
Mettre une majuscule après une incise qui coupe une phrase : `« Je pars, dit-il, et je reviendrai. »`, avec un `e` minuscule.
:::

::: info Deux conventions coexistent
Certains éditeurs ouvrent les guillemets une seule fois et utilisent ensuite des tirets, comme ci-dessus. D'autres emploient uniquement des tirets, sans aucun guillemet.
Les deux usages sont corrects. Ce qui est évalué, c'est la **cohérence** : on choisit une convention et on s'y tient sur tout le texte.
:::

## 4. Les verbes de parole

::: retenir
Le verbe de parole ne dit pas seulement **qu'on parle** : il dit **comment** on parle.
Choisir `murmura` plutôt que `dit` change la scène sans ajouter un mot d'explication.
:::

::: grille
| Intention | Verbes possibles |
|---|---|
| **Neutre** | dire, déclarer, ajouter, poursuivre |
| **Interroger** | demander, interroger, s'enquérir |
| **Répondre** | répondre, répliquer, rétorquer, objecter |
| **Volume faible** | murmurer, chuchoter, souffler, marmonner |
| **Volume fort** | crier, s'écrier, hurler, tonner |
| **Émotion** | soupirer, gémir, s'exclamer, protester |
| **Autorité** | ordonner, exiger, trancher, imposer |
:::

::: piege Ne pas surcharger
Un dialogue dans lequel chaque réplique est introduite par un verbe expressif devient fatigant à lire.
Les auteurs alternent : quelques `dit` neutres, et un verbe expressif au moment qui compte. Le contraste fait l'effet.
:::

::: exemple Le verbe qui remplace une explication
`« Ce n'est rien », dit-elle.`
`« Ce n'est rien », murmura-t-elle.`
`« Ce n'est rien », trancha-t-elle.`

Les paroles sont identiques. La première phrase est neutre, la deuxième suggère la fragilité, la troisième une volonté de clore la discussion.
:::

::: pause
Fin de la première séance. Le discours direct et sa ponctuation sont posés.
:::

## 5. Le discours indirect

::: definition Discours indirect
Le **discours indirect** rapporte les paroles dans une **proposition subordonnée**, introduite le plus souvent par `que`.
Il n'y a plus ni guillemets, ni tirets, ni deux-points.
:::

::: exemple Du direct à l'indirect
Direct : `Il dit : « Je pars demain. »`
Indirect : `Il dit qu'il part le lendemain.`

Trois choses ont changé : la ponctuation a disparu, le pronom `je` est devenu `il`, et `demain` est devenu `le lendemain`.
:::

::: retenir
Le discours indirect **intègre** la parole au récit. Le lecteur n'entend plus la voix du personnage : il entend celle du narrateur qui rapporte.
La distance augmente, la vivacité diminue.
:::

## 6. Les six transformations

::: formule Ce qui change en passant au discours indirect
1. La **ponctuation** disparaît : ni guillemets, ni tirets, ni deux-points.
2. Un **mot subordonnant** apparaît : `que`, `si`, `ce que`, un mot interrogatif.
3. Les **pronoms personnels** changent de personne.
4. Les **déterminants possessifs** changent.
5. Les **indications de temps et de lieu** changent.
6. Les **temps verbaux** changent, si le verbe introducteur est au passé.
:::

::: grille
| Discours direct | Discours indirect |
|---|---|
| `je`, `tu` | `il`, `elle` |
| `mon`, `ton` | `son`, `sa` |
| `nous` | `ils`, `elles` |
| `ici` | `là` |
| `aujourd'hui` | `ce jour-là` |
| `hier` | `la veille` |
| `demain` | `le lendemain` |
| `maintenant` | `alors` |
| `la semaine prochaine` | `la semaine suivante` |
:::

::: exemple Une transformation complète
Direct : `Elle me dit : « Je viendrai te chercher ici demain avec mon frère. »`

Indirect : `Elle me dit qu'elle viendrait me chercher là le lendemain avec son frère.`

`je` → `elle`. `te` → `me`, car c'est moi qui rapporte. `ici` → `là`. `demain` → `le lendemain`. `mon` → `son`. `viendrai` → `viendrait`, par concordance des temps.
:::

::: piege La transformation des pronoms dépend de qui rapporte
`Il me dit : « Je te verrai. »` devient `Il me dit qu'il me verrait.`
Le `je` du personnage devient `il`, mais le `te` devient `me`, parce que c'est moi qui rapporte la parole.
Il faut donc se demander, pronom par pronom, **qui désigne qui** dans la nouvelle phrase.
:::

## 7. La concordance des temps

::: retenir La règle
Si le verbe introducteur est au **présent**, les temps ne changent **pas**.
S'il est au **passé**, les temps **reculent** d'un cran.
:::

::: grille
| Verbe introducteur au présent | Verbe introducteur au passé |
|---|---|
| `Il dit qu'il part.` | `Il a dit qu'il partait.` |
| présent → **présent** | présent → **imparfait** |
| passé composé → **passé composé** | passé composé → **plus-que-parfait** |
| futur → **futur** | futur → **conditionnel présent** |
:::

::: exemple Les trois cas avec un introducteur au passé
Direct : `Il dit : « Je pars. »` → Indirect : `Il a dit qu'il **partait**.`
Direct : `Il dit : « Je suis parti. »` → Indirect : `Il a dit qu'il **était parti**.`
Direct : `Il dit : « Je partirai. »` → Indirect : `Il a dit qu'il **partirait**.`
:::

::: piege Le conditionnel n'exprime pas ici une condition
Dans `Il a dit qu'il partirait`, le conditionnel ne signifie pas « si les circonstances le permettent ».
Il exprime un **futur vu depuis le passé** : au moment où il parlait, le départ était à venir.
On l'appelle parfois « futur du passé ». C'est un emploi grammatical, pas un sens.
:::

::: exemple Un test pour vérifier
Pour vérifier une concordance, on remet la phrase au discours direct.
`Elle expliqua qu'elle avait perdu ses clés la veille.`
Retour au direct : `Elle expliqua : « J'ai perdu mes clés hier. »`
Si la phrase obtenue est naturelle, la concordance est juste.
:::

## 8. Les questions au discours indirect

::: formule Les trois cas
**Question fermée**, à laquelle on répond oui ou non → on emploie **`si`**.
`Il demande : « Viens-tu ? »` → `Il demande **si** je viens.`

**Question avec mot interrogatif** → on **garde** le mot.
`Il demande : « Où vas-tu ? »` → `Il demande **où** je vais.`

**Question en « qu'est-ce que »** → on emploie **`ce que`**.
`Il demande : « Qu'est-ce que tu fais ? »` → `Il demande **ce que** je fais.`
:::

::: piege Trois erreurs à ne pas commettre
Le **point d'interrogation disparaît** au discours indirect : `Il demande si je viens.` et non `Il demande si je viens ?`
L'**inversion disparaît** aussi : on écrit `Il demande où je vais`, jamais `Il demande où vais-je`.
`Est-ce que` **ne se conserve pas** : `Il demande si je viens`, et non `Il demande est-ce que je viens`.
:::

::: exemple Quatre questions transformées
`« Est-ce que tu as faim ? »` → `Il demande si j'ai faim.`
`« Quand pars-tu ? »` → `Il demande quand je pars.`
`« Pourquoi as-tu fait cela ? »` → `Il demande pourquoi j'ai fait cela.`
`« Qu'est-ce qui t'inquiète ? »` → `Il demande ce qui m'inquiète.`
:::

Fin de la deuxième séance. Le discours indirect et ses règles sont posés.
:::

## 9. Le discours narrativisé

::: definition Discours narrativisé
Le **discours narrativisé** résume les paroles en quelques mots, sans les rapporter.
Il n'y a ni citation, ni subordonnée : seulement un verbe et un complément.
:::

::: exemple Le même fait, trois formes
Direct : `Il dit : « Je démissionne. »`
Indirect : `Il dit qu'il démissionnait.`
Narrativisé : `Il annonça sa démission.`
:::

::: grille
| Avantage | Inconvénient |
|---|---|
| très rapide | on perd les mots exacts |
| permet de résumer une longue conversation | on perd le ton et l'émotion |
| évite de ralentir le récit | le lecteur n'entend plus le personnage |
:::

::: exemple Quand l'employer
`Ils discutèrent pendant deux heures de la répartition de l'héritage.`

Rapporter deux heures de conversation au discours direct prendrait dix pages. Le narrativisé condense en une ligne.
On l'emploie donc pour ce qui n'est **pas essentiel mot à mot**, et on réserve le direct aux répliques qui comptent.
:::

## 10. Le discours indirect libre

::: definition Discours indirect libre
Le **discours indirect libre** rapporte les paroles ou les pensées **sans verbe introducteur** et **sans subordonnant**.
La voix du personnage se mêle à celle du narrateur.
:::

::: exemple Les quatre formes sur le même contenu
Direct : `Il pensa : « Je suis fichu. Personne ne me croira. »`
Indirect : `Il pensa qu'il était fichu et que personne ne le croirait.`
Narrativisé : `Il désespéra d'être cru.`
**Indirect libre** : `Il était fichu. Personne ne le croirait.`
:::

::: retenir Comment on le reconnaît
Les **temps** et les **pronoms** sont ceux du discours indirect : troisième personne, imparfait, conditionnel.
Mais il n'y a **ni `que`, ni verbe introducteur**, et la phrase garde les marques de l'oral : exclamations, questions, mots familiers, rythme heurté.
:::

::: exemple Les marques d'oralité conservées
`Il était fichu. Fichu ! Et après tout, qu'avait-il fait de mal ?`

L'exclamation et la question sont celles du personnage, pas du narrateur. Pourtant la phrase est à l'imparfait et à la troisième personne.
C'est ce mélange qui caractérise le discours indirect libre.
:::

::: info Pourquoi les romanciers réalistes l'emploient tant
Flaubert en fait un usage systématique. Le procédé permet de faire entendre la pensée d'un personnage **sans que le narrateur la prenne en charge**.
Le lecteur ne sait plus si la phrase exprime l'avis du personnage ou celui du narrateur : c'est précisément l'ambiguïté recherchée. Elle permet de suggérer un jugement sans jamais l'énoncer.
:::

::: piege L'ambiguïté est voulue
Devant une phrase au discours indirect libre, on ne peut pas toujours trancher entre la voix du personnage et celle du narrateur.
Ce n'est pas un défaut d'analyse : c'est l'effet du procédé. La bonne réponse en commentaire consiste à **nommer cette ambiguïté**, pas à la supprimer.
:::

## 11. Choisir sa forme

::: grille
| Effet recherché | Forme à employer |
|---|---|
| Faire entendre la voix du personnage | **direct** |
| Rendre une scène vivante | **direct** |
| Intégrer une parole au récit sans le couper | **indirect** |
| Résumer une longue conversation | **narrativisé** |
| Faire entendre une pensée de l'intérieur | **indirect libre** |
| Suggérer un jugement sans l'énoncer | **indirect libre** |
| Accélérer le récit | **narrativisé** |
| Ralentir et détailler | **direct** |
:::

::: retenir Le principe
Le discours **direct** rapproche le lecteur du personnage.
Le discours **narrativisé** l'en éloigne le plus.
L'indirect et l'indirect libre se situent entre les deux, l'indirect libre étant plus proche du personnage que l'indirect.
:::

::: exemple Le choix dans un même récit
Un romancier ne choisit pas une forme pour tout le roman : il **alterne**.
Une scène de dispute sera au discours direct, pour qu'on entende les mots. Les négociations qui suivent seront narrativisées, parce qu'elles n'ajoutent rien. Le remords du personnage sera au discours indirect libre, parce qu'il ne le formule à personne.
:::

## 12. Les pièges à éviter

::: grille
| Piège | Ce qui est faux | Ce qui est juste |
|---|---|---|
| L'incise | « Je pars, il dit. » | « Je pars, **dit-il**. » |
| Les guillemets | on en met à chaque réplique | **une** ouverture, **une** fermeture |
| Le point d'interrogation | `Il demande si je viens ?` | il **disparaît** à l'indirect |
| L'inversion | `Il demande où vais-je.` | `Il demande **où je vais**.` |
| Est-ce que | `Il demande est-ce que je viens.` | `Il demande **si** je viens.` |
| Les indicateurs | `Il dit qu'il partait demain.` | `... le **lendemain**.` |
| La concordance | `Il a dit qu'il partira.` | `... qu'il **partirait**.` |
| Le conditionnel | il exprime une condition | c'est un **futur du passé** |
:::

::: retenir
Trois phrases suffisent à retenir le chapitre.
**Quatre formes, quatre distances entre le lecteur et le personnage.**
**Au discours indirect, six choses changent, et la ponctuation disparaît toujours.**
**Le conditionnel du discours indirect n'est pas une condition : c'est un futur vu depuis le passé.**
:::
