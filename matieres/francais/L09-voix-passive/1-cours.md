## 1. Ce qu'est une voix

::: definition Voix active et voix passive
La **voix** indique le rapport entre le sujet et l'action du verbe.
À la voix **active**, le sujet **fait** l'action.
À la voix **passive**, le sujet **subit** l'action.
:::

::: exemple La même information, deux voix
**Active** : `Le vent a renversé l'arbre.`
Le sujet, `le vent`, fait l'action de renverser.

**Passive** : `L'arbre a été renversé par le vent.`
Le sujet, `l'arbre`, subit l'action.

Les deux phrases décrivent le même événement. Ce qui change, c'est **ce qu'on met en avant**.
:::

::: retenir Le point essentiel
Le passif n'ajoute aucune information nouvelle.
Il change l'**ordre** dans lequel on présente les éléments, et donc ce que le lecteur remarque en premier.
:::

## 2. Reconnaître le passif

::: formule
**La construction du passif**
`être` conjugué + **participe passé** du verbe

`est mangé`, `a été construit`, `sera terminé`, `avait été oublié`.
:::

::: piege L'auxiliaire `être` ne suffit pas
`Elle est partie` n'est **pas** un passif : c'est le passé composé du verbe `partir`, qui se conjugue avec `être`.
`Elle est aimée` **est** un passif : on peut demander « par qui ? ».
:::

::: methode Reconnaître un passif en deux tests
1. **Le test de l'agent** : peut-on ajouter « par quelqu'un » ou « par quelque chose » ? Si oui, c'est un passif.
2. **Le test du retour à l'actif** : peut-on retourner la phrase de sorte que le sujet devienne complément ? Si oui, c'est un passif.
:::

::: grille
| Phrase | Passif ? | Pourquoi |
|---|---|---|
| `La lettre est écrite par Léa.` | **oui** | agent présent, retour possible |
| `Elle est partie hier.` | non | passé composé de `partir` |
| `Le mur est repeint chaque été.` | **oui** | on peut ajouter « par les employés » |
| `Il est content.` | non | `content` est un adjectif, pas un participe |
:::

## 3. La transformation

::: methode Passer de l'actif au passif, en quatre étapes
1. Le **COD** de la phrase active devient le **sujet** de la phrase passive.
2. Le verbe passe à la forme `être` + participe passé, **au même temps** que le verbe actif.
3. Le **sujet** de la phrase active devient **complément d'agent**, introduit par `par`.
4. On accorde le participe passé avec le nouveau sujet.
:::

::: exemple La transformation, étape par étape
Phrase active : `Les élèves ont planté trois arbres.`

1. COD `trois arbres` → sujet : `Trois arbres ...`
2. `ont planté` est au passé composé → `ont été plantés`
3. Sujet `les élèves` → agent : `par les élèves`
4. Accord avec `trois arbres`, masculin pluriel : `plantés`

Phrase passive : `Trois arbres ont été plantés par les élèves.`
:::

::: piege Le temps ne change jamais
Une phrase au passé composé reste au passé composé, une phrase au futur reste au futur.
C'est l'auxiliaire `être` qui porte le temps : `mange` → `est mangé`, `mangera` → `sera mangé`, `a mangé` → `a été mangé`.
:::

::: grille
| Temps de l'actif | Forme passive |
|---|---|
| Présent : `il range` | `il est rangé` |
| Imparfait : `il rangeait` | `il était rangé` |
| Futur : `il rangera` | `il sera rangé` |
| Passé composé : `il a rangé` | `il a été rangé` |
| Plus-que-parfait : `il avait rangé` | `il avait été rangé` |
:::

::: methode Passer du passif à l'actif
1. Le **complément d'agent** devient le sujet.
2. Le **sujet** devient le COD.
3. Le verbe reprend sa forme simple, au même temps.
4. S'il n'y a pas d'agent, on emploie `on` comme sujet.
:::

## 4. Le complément d'agent

::: definition Complément d'agent
Le **complément d'agent** désigne celui qui fait réellement l'action dans une phrase passive.
Il est introduit par la préposition **`par`**, plus rarement par **`de`**.
:::

::: exemple `par` et `de`
`La ville a été détruite **par** un séisme.` → cas ordinaire, action concrète.
`Il est respecté **de** tous.` → verbes de sentiment ou d'état : `aimé de`, `respecté de`, `craint de`, `suivi de`.
:::

::: retenir Le complément d'agent peut disparaître
`Le musée a été rénové.` La phrase est complète et correcte, mais on ne sait pas par qui.
Cette disparition n'est pas un oubli : c'est souvent le but même du passif.
:::

::: piege L'agent n'est pas un complément circonstanciel
`Le vase a été cassé **par mon frère**` : complément d'agent, il fait l'action.
`Le vase est tombé **par accident**` : complément circonstanciel de manière, personne ne fait l'action.
Le test : peut-on en faire le sujet d'une phrase active ? `Mon frère a cassé le vase` fonctionne ; `L'accident a cassé le vase` change le sens.
:::

🔁 **Point de pause.** Reprends après cinq minutes. La suite explique à quoi sert vraiment le passif.

## 5. Les effets du passif

::: grille
| Effet | Ce que le passif permet | Exemple |
|---|---|---|
| **Mettre en avant** | placer en tête ce qui subit l'action | `La cathédrale a été achevée en 1345.` |
| **Effacer l'agent** | ne pas dire qui fait l'action | `Des erreurs ont été commises.` |
| **Généraliser** | décrire un usage sans acteur précis | `Le pain est cuit à 250 degrés.` |
| **Enchaîner** | garder le même sujet d'une phrase à l'autre | `Il entra. Il fut aussitôt reconnu.` |
:::

::: exemple L'effacement de l'agent
« Des erreurs ont été commises. »
Qui les a commises ? La phrase ne le dit pas, et c'est précisément son intérêt pour celui qui la prononce.
La version active, « J'ai commis des erreurs », engage une responsabilité que le passif permet de contourner.
:::

::: retenir Pourquoi cela compte
Repérer un passif sans agent dans un discours, un article ou un communiqué, c'est repérer une **information manquante**.
La question à poser est toujours la même : **par qui ?**
:::

## 6. Le passif dans les textes

::: grille
| Type de texte | Usage du passif |
|---|---|
| **Texte scientifique** | l'expérimentateur s'efface : `le mélange est chauffé` |
| **Texte juridique** | la règle s'énonce sans acteur : `nul n'est censé ignorer la loi` |
| **Article de presse** | prudence quand l'auteur du fait n'est pas établi |
| **Récit** | le personnage subit, il devient victime des événements |
:::

::: exemple Le passif dans un récit
« Il fut poussé, bousculé, entraîné par la foule. »
Les trois verbes au passif montrent un personnage qui ne maîtrise plus rien.
Passé à l'actif, « la foule le poussa », l'effet disparaît : c'est la foule qui devient le personnage principal de la phrase.
:::

::: aide Comment analyser un passif dans un texte
1. Repère les formes `être` + participe passé.
2. Demande-toi si l'agent est exprimé ou non.
3. Si l'agent manque, demande-toi **pourquoi** l'auteur l'a effacé.
4. Réécris la phrase à l'actif et compare les deux effets.
:::

## 7. Les phrases qui ne se transforment pas

::: formule
**La condition indispensable**
Seuls les verbes ayant un **COD** peuvent se mettre au passif.
Sans COD, pas de passif possible.
:::

::: grille
| Phrase | Transformable ? | Pourquoi |
|---|---|---|
| `Le chat mange la souris.` | **oui** | `la souris` est COD |
| `Le chat dort.` | non | aucun COD |
| `Il parle à sa sœur.` | non | `à sa sœur` est un COI, pas un COD |
| `Elle ressemble à sa mère.` | non | COI |
| `Il a trois frères.` | non | `avoir` n'admet pas le passif |
:::

::: piege Les verbes de mesure
`Ce sac pèse trois kilos.` Le groupe `trois kilos` ressemble à un COD, mais il ne l'est pas : il mesure, il ne subit rien.
On ne dit donc pas `Trois kilos sont pesés par ce sac`.
D'autres verbes de ce type : `coûter`, `valoir`, `mesurer`, `durer`.
:::

## 8. Ne pas confondre passif et état

::: piege La phrase ambiguë
`La porte est fermée.`
**Lecture passive** : quelqu'un ferme la porte en ce moment. On peut ajouter « par le gardien ».
**Lecture d'état** : la porte se trouve dans l'état « fermée ». `fermée` est alors un adjectif.
:::

::: methode Trancher entre passif et état, en deux tests
1. **Le test de l'agent** : « par qui ? » fonctionne → passif. Ne fonctionne pas → état.
2. **Le test du remplacement** : on peut remplacer par un adjectif de sens proche, `ouverte`, `close`, `neuve` → état.
:::

::: exemple Les deux lectures en contexte
`À huit heures, la porte est fermée par le gardien.` → passif, l'action se produit.
`Inutile d'insister, la porte est fermée.` → état, on décrit une situation.

Le contexte tranche presque toujours. Quand il ne tranche pas, la phrase est ambiguë, et un bon rédacteur la réécrit.
:::

## 9. Le participe passé employé seul

::: formule
**Règle 1 : le participe passé employé seul**
Il s'accorde comme un **adjectif**, avec le nom auquel il se rapporte.

`Fatiguée, elle s'assit.` → accord avec `elle`.
`Les fenêtres, ouvertes depuis l'aube, laissaient entrer le froid.` → accord avec `les fenêtres`.
:::

::: retenir Comment reconnaître ce cas
Il n'y a **ni `être` ni `avoir`** devant le participe.
Il fonctionne exactement comme un adjectif qualificatif, et on l'accorde de la même façon.
:::

## 10. Le participe passé avec être

::: formule
**Règle 2 : avec l'auxiliaire `être`**
Il s'accorde toujours avec le **sujet**.

`Elle est partie.` · `Ils sont arrivés.` · `Les lettres ont été envoyées.`
:::

::: grille
| Phrase | Sujet | Accord |
|---|---|---|
| `Elle est venue.` | `elle`, fém. sing. | `venue` |
| `Ils sont sortis.` | `ils`, masc. plur. | `sortis` |
| `Les portes sont ouvertes.` | `les portes`, fém. plur. | `ouvertes` |
| `Marie et Paul sont arrivés.` | masc. plur. | `arrivés` |
:::

::: piege Le masculin l'emporte
`Marie, Julie et Paul sont arrivés.`
Un seul élément masculin dans le groupe suffit à imposer l'accord au masculin pluriel.
:::

::: retenir Ce cas couvre aussi le passif
Toutes les phrases passives relèvent de la règle 2, puisqu'elles se construisent avec `être`.
`Les arbres ont été plantés` : accord avec `les arbres`, sujet.
:::

## 11. Le participe passé avec avoir

::: formule
**Règle 3 : avec l'auxiliaire `avoir`**
Il ne s'accorde **jamais** avec le sujet.
Il s'accorde avec le **COD** uniquement si celui-ci est placé **avant** le verbe.
:::

::: exemple Les deux cas
`Elle a mangé les pommes.` → COD `les pommes` placé **après**, donc **pas d'accord** : `mangé`.
`Les pommes qu'elle a mangées.` → COD `que`, mis pour `les pommes`, placé **avant**, donc **accord** : `mangées`.
`Elle les a mangées.` → COD `les` placé avant, donc accord.
:::

::: methode Appliquer la règle 3, en trois questions
1. Y a-t-il un **COD** ? Si non, pas d'accord, le participe reste invariable.
2. Le COD est-il **avant** le verbe ? Si non, pas d'accord.
3. Si oui, avec quel nom s'accorde-t-il ? On accorde avec ce nom.
:::

::: grille
| Phrase | COD | Position | Accord |
|---|---|---|---|
| `Il a écrit une lettre.` | `une lettre` | après | `écrit` |
| `La lettre qu'il a écrite.` | `que` = la lettre | **avant** | `écrite` |
| `Il l'a écrite.` | `l'` = la lettre | **avant** | `écrite` |
| `Il a dormi.` | aucun | ... | `dormi` |
| `Il a parlé à sa sœur.` | aucun, COI | ... | `parlé` |
:::

::: piege Les trois occasions où le COD passe devant
1. Le **pronom personnel** : `il les a vus`.
2. Le pronom relatif **`que`** : `les films que j'ai vus`.
3. Dans une **question** : `Quelle robe as-tu choisie ?`
En dehors de ces trois cas, le COD est presque toujours après le verbe, et le participe reste invariable.
:::

::: retenir La question qui règle presque tout
Pose-toi toujours : *où est le COD ?*
Après le verbe, ou absent → **pas d'accord**.
Avant le verbe → **accord avec lui**.
:::

::: exemple Un cas fréquent en dictée
`Les erreurs que j'ai **commises** m'ont beaucoup appris.`
`que` reprend `les erreurs`, féminin pluriel, et il est placé avant `ai commises`. L'accord se fait donc : `commises`.

`J'ai **commis** des erreurs.`
Ici `des erreurs` est après le verbe : pas d'accord.
:::

## 12. Les pièges à éviter

::: piege 1. `être` ne signale pas toujours un passif
`Elle est partie` est un passé composé. `Elle est aimée` est un passif. Le test de l'agent tranche.
:::

::: piege 2. Le temps du verbe
Il ne change jamais dans la transformation. C'est l'auxiliaire `être` qui le porte.
:::

::: piege 3. Le complément d'agent
Il est introduit par `par`, parfois par `de`. Il n'est pas un complément circonstanciel.
:::

::: piege 4. Les phrases sans COD
Un verbe sans COD ne se met jamais au passif. `Il dort`, `il parle à sa sœur` : pas de passif possible.
:::

::: piege 5. Les verbes de mesure
`peser`, `coûter`, `valoir`, `mesurer`, `durer` : leur complément n'est pas un COD.
:::

::: piege 6. Avec `avoir`, jamais d'accord avec le sujet
`Elle a mangé`, jamais `elle a mangée`. C'est l'erreur la plus fréquente de tout le chapitre.
:::

::: piege 7. Le COD après le verbe
Avec `avoir`, un COD placé après ne déclenche aucun accord.
:::

::: piege 8. Le passif sans agent
Il n'est jamais neutre. Demande-toi toujours pourquoi l'auteur ne dit pas **par qui**.
:::

::: cocher
- Je reconnais un passif par le test de l'agent
- Je transforme une phrase dans les deux sens sans changer le temps
- Je sais dire pourquoi un auteur a choisi le passif
- J'accorde le participe passé avec être, avec le sujet
- Avec avoir, je cherche le COD et je regarde s'il est avant le verbe
:::
