## 1. Les deux voix

::: formule-cle
À la voix **active**, le sujet **fait** l'action : `Le vent a renversé l'arbre.`
À la voix **passive**, le sujet **subit** l'action : `L'arbre a été renversé par le vent.`
Les deux phrases décrivent le même fait. Ce qui change, c'est ce qu'on met en avant.
:::

## 2. Reconnaître un passif

::: formule-cle
**Construction** : `être` conjugué + **participe passé**.
`est mangé`, `a été construit`, `sera terminé`, `avait été oublié`.
:::

::: grille
| Test | Comment faire | Conclusion |
|---|---|---|
| **De l'agent** | peut-on ajouter « par quelqu'un » ? | oui → passif |
| **Du retour à l'actif** | peut-on retourner la phrase ? | oui → passif |
:::

::: piege `être` ne signale pas toujours un passif
`Elle est partie` : passé composé de `partir`.
`Elle est aimée` : passif, on peut demander « par qui ? ».
`Il est content` : `content` est un adjectif.
:::

## 3. La transformation

::: grille
| Étape | Actif → passif |
|---|---|
| 1 | le **COD** devient **sujet** |
| 2 | le verbe devient `être` + participe passé, **au même temps** |
| 3 | le **sujet** devient **complément d'agent**, avec `par` |
| 4 | on accorde le participe avec le nouveau sujet |
:::

::: formule-cle
`Les élèves ont planté trois arbres.` → `Trois arbres ont été plantés par les élèves.`
Le temps ne change **jamais** : c'est l'auxiliaire `être` qui le porte.
:::

::: grille
| Actif | Passif |
|---|---|
| `il range` | `il est rangé` |
| `il rangeait` | `il était rangé` |
| `il rangera` | `il sera rangé` |
| `il a rangé` | `il a été rangé` |
| `il avait rangé` | `il avait été rangé` |
:::

::: retenir Ce qui ne se transforme pas
Seuls les verbes ayant un **COD** peuvent se mettre au passif.
Pas de passif pour `il dort`, `il parle à sa sœur`, `ce sac pèse trois kilos`, `il a trois frères`.
:::

## 4. Le complément d'agent

::: formule-cle
Introduit par **`par`**, plus rarement par **`de`** après les verbes de sentiment : `aimé de tous`, `respecté de tous`.
Il peut **disparaître** : `Le musée a été rénové.` Cette disparition est presque toujours volontaire.
:::

::: piege Agent et circonstanciel
`Le vase a été cassé **par mon frère**` : agent, il fait l'action.
`Le vase est tombé **par accident**` : circonstanciel de manière, personne ne fait l'action.
:::

## 5. Les effets du passif

::: grille
| Effet | Ce qu'il permet | Exemple |
|---|---|---|
| **Mettre en avant** | placer en tête ce qui subit | `La cathédrale a été achevée en 1345.` |
| **Effacer l'agent** | ne pas dire qui fait l'action | `Des erreurs ont été commises.` |
| **Généraliser** | décrire sans acteur précis | `Le pain est cuit à 250 degrés.` |
| **Enchaîner** | garder le même sujet | `Il entra. Il fut aussitôt reconnu.` |
:::

::: formule-cle
Un passif sans agent signale une **information manquante**.
La question à poser est toujours la même : **par qui ?**
:::

## 6. Les trois règles d'accord

::: grille
| Cas | Règle | Exemple |
|---|---|---|
| **Seul** | comme un **adjectif**, avec le nom qu'il qualifie | `Fatiguée, elle s'assit.` |
| **Avec `être`** | avec le **sujet**, toujours | `Ils sont arrivés.` |
| **Avec `avoir`** | avec le **COD** si, et seulement si, il est **avant** | `Les pommes qu'elle a mangées.` |
:::

::: formule-cle
Avec `avoir`, on n'accorde **jamais** avec le sujet.
`Elle a mangé les pommes` → pas d'accord, le COD est après.
`Elle les a mangées` → accord, le COD est avant.
:::

::: retenir Les trois occasions où le COD passe devant
1. Un **pronom personnel** : `il les a vus`.
2. Le pronom relatif **`que`** : `les films que j'ai vus`.
3. Une **question** : `Quelle robe as-tu choisie ?`
En dehors de ces trois cas, le participe reste invariable.
:::

::: grille
| Phrase | COD | Position | Accord |
|---|---|---|---|
| `Il a écrit une lettre.` | `une lettre` | après | `écrit` |
| `La lettre qu'il a écrite.` | `que` | **avant** | `écrite` |
| `Il l'a écrite.` | `l'` | **avant** | `écrite` |
| `Il a dormi.` | aucun | ... | `dormi` |
| `Il a parlé à sa sœur.` | aucun, COI | ... | `parlé` |
:::

## 8. Les huit pièges

::: piege 1. `être` ne signale pas toujours un passif
Le test de l'agent tranche.
:::

::: piege 2. Le temps du verbe
Il ne change jamais dans la transformation.
:::

::: piege 3. Le complément d'agent
Introduit par `par` ou `de`, ce n'est pas un circonstanciel.
:::

::: piege 4. Les phrases sans COD
Un verbe sans COD ne se met jamais au passif.
:::

::: piege 5. Les verbes de mesure
`peser`, `coûter`, `valoir`, `mesurer`, `durer` : leur complément n'est pas un COD.
:::

::: piege 6. Avec `avoir`, jamais d'accord avec le sujet
`Elle a mangé`, jamais `elle a mangée`. C'est l'erreur la plus fréquente du chapitre.
:::

::: piege 7. Le COD après le verbe
Avec `avoir`, un COD placé après ne déclenche aucun accord.
:::

::: piege 8. Le passif sans agent
Il n'est jamais neutre. Demande-toi toujours pourquoi l'auteur ne dit pas **par qui**.
:::

## 9. Auto-test

Réponds sans regarder la fiche de cours. Les réponses sont juste en dessous.

::: exercice 1 | application | 10 min | ecran
1. Quelle est la différence entre voix active et voix passive ?
2. Comment se construit le passif ?
3. Cite les deux tests qui permettent de reconnaître un passif.
4. Transforme au passif : `Le jury a récompensé deux élèves.`
5. Transforme à l'actif : `La maison sera vendue par l'agence.`
6. Comment s'introduit le complément d'agent ?
7. Pourquoi un auteur choisit-il parfois d'effacer l'agent ?
8. Quelles phrases ne peuvent pas se mettre au passif ?
9. Avec `être`, avec quoi le participe passé s'accorde-t-il ?
10. Avec `avoir`, dans quel cas y a-t-il accord ?

::: corrige
1. À la voix **active**, le sujet fait l'action ; à la voix **passive**, il la subit. Les deux voix décrivent le même fait, mais ne mettent pas en avant le même élément.
2. Avec l'auxiliaire **`être`** conjugué, suivi du **participe passé** du verbe.
3. Le **test de l'agent** : peut-on ajouter « par quelqu'un » ? Et le **test du retour à l'actif** : peut-on retourner la phrase ?
4. `Deux élèves ont été récompensés par le jury.` Le temps reste le passé composé, porté par `ont été`.
5. `L'agence vendra la maison.` Le complément d'agent devient sujet, le sujet devient COD, le verbe reprend sa forme simple au futur.
6. Par la préposition **`par`**, plus rarement par **`de`** après les verbes de sentiment : `aimé de tous`, `respecté de tous`.
7. Pour ne pas dire **qui** fait l'action, souvent pour éviter d'engager une responsabilité. « Des erreurs ont été commises » ne dit pas par qui, et c'est précisément son intérêt pour celui qui le prononce.
8. Celles dont le verbe n'a **pas de COD** : verbes intransitifs comme `dormir`, verbes suivis d'un COI comme `parler à`, verbes de mesure comme `peser` ou `coûter`, et le verbe `avoir`.
9. Avec le **sujet**, toujours. C'est aussi ce qui règle l'accord dans toutes les phrases passives.
10. Uniquement si le **COD est placé avant le verbe**. Cela se produit dans trois cas : pronom personnel, pronom relatif `que`, ou question.
:::
