## 1. La définition par l'hésitation

::: formule La définition à savoir par cœur
Le **fantastique** est un genre dans lequel un événement **inexplicable** surgit dans un univers **ordinaire**, sans qu'on puisse décider s'il relève du surnaturel ou d'une explication rationnelle.
:::

::: formule-cle
Tant que le doute **subsiste**, on est dans le fantastique.
Le récit tranche pour le rationnel → **étrange**.
Le récit tranche pour le surnaturel → **merveilleux**.
:::

::: retenir Le siècle
Le genre se développe au **XIXᵉ siècle**, en parallèle du réalisme. Il faut croire au monde rationnel pour qu'une entorse à ses lois fasse peur.
:::

## 2. Les quatre genres

::: grille
| Genre | Statut du surnaturel | Réaction du personnage |
|---|---|---|
| **Merveilleux** | admis comme normal | aucune surprise |
| **Fantastique** | **inexpliqué**, il dérange | peur et doute |
| **Science-fiction** | expliqué par une science future | curiosité |
| **Étrange** | finalement expliqué | soulagement |
:::

::: formule Le test le plus rapide
Se demander : **le personnage s'étonne-t-il ?**
Dans un conte, la fée ne surprend personne. Dans *Le Horla*, le narrateur est terrifié.
:::

## 3. Les auteurs et les œuvres

::: grille
| Auteur | Œuvres | Particularité |
|---|---|---|
| **Maupassant** | *Le Horla*, *La Peur*, *La Main* | la folie et le doute |
| **Gautier** | *La Cafetière*, *Le Pied de momie* | l'objet qui s'anime |
| **Mérimée** | *La Vénus d'Ille* | la statue vivante |
| **Poe** | *Le Chat noir*, *Le Cœur révélateur* | le narrateur peu fiable |
:::

::: formule-cle
*Le Horla* est le modèle du genre : un **journal intime**, une présence jamais vue, et deux lectures possibles jusqu'à la dernière ligne.
:::

## 4. Le cadre réaliste

::: formule Le paradoxe fondateur
Pour qu'un événement paraisse **inexplicable**, il faut d'abord que le monde paraisse **explicable**.
:::

::: grille
| Élément | Fonction |
|---|---|
| Date précise | ancre dans le temps réel |
| Lieu identifiable | rend le décor vérifiable |
| Détails quotidiens | installe la banalité |
| Ton neutre au début | contraste avec la suite |
:::

::: piege L'erreur de départ
Commencer par l'événement étrange ne produit aucun effet : le lecteur n'a rien à quoi rattacher l'étrangeté.
Plus le début est ordinaire, plus la suite est troublante.
:::

## 5. La gradation en cinq étapes

::: formule Les cinq étapes
1. Une **sensation vague** : un malaise.
2. Un **détail anormal**, encore explicable.
3. Une **répétition** qui rend le hasard improbable.
4. Un **fait indéniable** qu'on ne peut plus nier.
5. La **confrontation** ou la **fuite**, et la chute.
:::

::: formule-cle
C'est l'**accumulation** qui produit l'effet, pas un événement unique.
Chaque étape rend l'explication rationnelle plus fragile que la précédente.
:::

## 6. Le narrateur et les marques du doute

::: formule Le point de vue
Presque toujours la **première personne** et le **point de vue interne**.
Le lecteur ne sait que ce que sait le narrateur, et partage son incertitude.
:::

::: grille
| Forme | Effet |
|---|---|
| **Journal intime** | on suit son esprit jour après jour |
| **Lettre** | un ton de plaidoirie |
| **Témoignage écrit** | souci de preuve |
:::

::: retenir Les marques du doute
« il me sembla que », « j'eus l'impression », « comme si », « peut-être », « une sorte de », « je ne sais quoi ».
Un texte fantastique contient très **peu d'affirmations nettes**.
:::

::: piege Le narrateur qui affirme sa raison
« Je ne suis pas fou », « j'ai toute ma tête » : ces phrases produisent l'effet **inverse** de celui qu'elles annoncent.
:::

::: grille
| Motif | Ce qu'il permet |
|---|---|
| **Le double** | le personnage se rencontre lui-même |
| **L'objet animé** | statue, cafetière, main |
| **Le miroir** | il renvoie autre chose |
| **La maison** | un lieu clos |
| **La nuit** | toute perception devient incertaine |
| **La présence invisible** | on la sent sans la voir |
:::

::: formule-cle
Ce qu'on **ne décrit pas** fait plus peur que ce qu'on décrit.
La meilleure chute est **ouverte** : elle n'explique rien et ne nomme rien.
:::

## 8. Les huit pièges

::: piege 1. La définition
Le fantastique n'est pas le surnaturel : c'est l'**hésitation** entre deux explications.
:::

::: piege 2. Le monstre
Aucune créature n'est nécessaire. Le **doute** suffit.
:::

::: piege 3. Le merveilleux
Dans un conte, le surnaturel est **admis** et personne ne s'en étonne : ce n'est pas du fantastique.
:::

::: piege 4. Le cadre
Il faut installer le **réel** avant de le fissurer.
:::

::: piege 5. La progression
Un événement isolé ne suffit pas : il faut une **gradation**.
:::

::: piege 6. La description
Suggérer est plus efficace que détailler. Le lecteur complète mieux que l'auteur.
:::

::: piege 7. Le narrateur
Son **doute** est un moteur du récit, pas un défaut.
:::

::: piege 8. La fin
« C'était un rêve » annule tout. « C'était un fantôme » bascule dans le merveilleux. La bonne chute est **ouverte**.
:::

## 9. Auto-test

Réponds sans regarder la fiche de cours. Les réponses sont juste en dessous.

::: exercice 1 | application | 8 min | ecran
1. Donne la définition du fantastique en une phrase.
2. Sur quoi repose le genre ?
3. Quelle différence entre fantastique et merveilleux ?
4. Quel test rapide permet d'identifier le genre d'un texte ?
5. Cite trois auteurs fantastiques avec une œuvre.
6. Pourquoi faut-il installer un cadre réaliste ?
7. Cite les cinq étapes d'une gradation.
8. Cite trois marques du doute dans un texte.
9. Cite trois motifs récurrents du genre.
10. Quelle est la meilleure chute pour un récit fantastique, et pourquoi ?

::: corrige
1. Un genre dans lequel un événement **inexplicable** surgit dans un univers **ordinaire**, sans qu'on puisse décider entre une explication rationnelle et une explication surnaturelle.
2. Sur l'**hésitation**.
3. Dans le **merveilleux**, le surnaturel est **admis** d'emblée et n'étonne personne. Dans le **fantastique**, il dérange et reste inexpliqué.
4. Se demander si le **personnage s'étonne**. S'il ne s'étonne pas, c'est du merveilleux.
5. Trois au choix : Maupassant, *Le Horla* ; Gautier, *La Cafetière* ; Mérimée, *La Vénus d'Ille* ; Poe, *Le Chat noir*.
6. Parce que pour qu'un événement paraisse **inexplicable**, il faut d'abord que le monde paraisse **explicable**. Sans normalité initiale, l'étrange n'a rien à contredire.
7. Sensation vague, détail anormal encore explicable, répétition, fait indéniable, confrontation ou fuite.
8. Trois au choix : « il me sembla que », « j'eus l'impression », « comme si », « peut-être », « une sorte de ».
9. Trois au choix : le **double**, l'**objet animé**, le **miroir**, la **maison**, la **nuit**, la **présence invisible**.
10. Une chute **ouverte**, qui n'explique rien. Une explication rationnelle dissipe le malaise et laisse le lecteur indifférent, alors qu'une chute ouverte laisse la question active longtemps après la lecture.
:::
