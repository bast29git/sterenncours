## 1. Le groupe nominal en une image

::: formule-cle
Le **noyau** est le nom dont on parle. Il commande l'accord et **ne se supprime pas**.
`la vieille voiture rouge de mon oncle qui roule encore` → noyau : **voiture**.
:::

## 2. Les trois expansions

::: grille
| Expansion | Nature | Exemple | Verbe conjugué ? |
|---|---|---|---|
| **Adjectif épithète** | un adjectif | une route **étroite** | non |
| **Complément du nom** | groupe introduit par une préposition | une route **de montagne** | non |
| **Proposition relative** | proposition à pronom relatif | une route **qui monte en lacets** | **oui** |
:::

::: formule-cle
Seule la **relative** contient un **verbe conjugué**. C'est le critère le plus fiable.
:::

## 3. Le test de reconnaissance

::: formule Le test de suppression
Une expansion se **supprime** sans rendre la phrase incorrecte.
`J'ai emprunté une route étroite de montagne qui monte en lacets.`
`J'ai emprunté une route.` → correct, donc les trois groupes étaient des expansions.
:::

::: piege Expansion ou complément du verbe
`Elle regarde la route` → `la route` complète le **verbe** : ce n'est pas une expansion.
`la route de montagne` → `de montagne` complète le **nom** : c'est une expansion.
:::

## 4. Épithète ou attribut

::: grille
| | Épithète | Attribut du sujet |
|---|---|---|
| Construction | collé au nom | relié par un verbe d'état |
| Exemple | une mer **calme** | la mer **semble** calme |
:::

::: formule-cle
Les verbes d'état : **être, paraître, sembler, devenir, rester, demeurer, avoir l'air, passer pour**.
:::

## 5. Les pronoms relatifs

::: grille
| Pronom | Fonction | Exemple |
|---|---|---|
| **qui** | sujet | la fille **qui** chante |
| **que** | complément d'objet direct | la chanson **que** j'écoute |
| **dont** | complément avec `de` | le film **dont** je t'ai parlé |
| **où** | lieu **ou temps** | la ville **où** je vis, le jour **où** je suis née |
| **lequel** | après préposition | le stylo **avec lequel** j'écris |
:::

::: formule Le test qui/que
Remplaçable par `il` ou `elle` → **qui**.
Remplaçable par `le` ou `la` → **que**.
:::

## 6. Les accords à surveiller

::: grille
| Situation | Règle | Exemple |
|---|---|---|
| Adjectif épithète | s'accorde avec le nom qu'il **complète** | des maisons au toit **rouge** |
| Deux noms de genres différents | **masculin pluriel** | une veste et un pantalon **neufs** |
| Verbe après `qui` | s'accorde avec l'**antécédent** | c'est moi qui **suis** |
:::

::: formule-cle
La **virgule** change la portée.
`Les élèves fatigués sont rentrés` → seulement ceux qui étaient fatigués.
`Les élèves, fatigués, sont rentrés` → **tous**, et ils étaient fatigués.
:::

## 8. Les huit pièges

::: piege 1. Le noyau
Ce n'est pas le premier nom, c'est le nom **dont on parle**. Dans `le chapeau de paille de ma grand-mère`, le noyau est **chapeau**.
:::

::: piege 2. Épithète ou attribut
S'il y a un **verbe d'état** entre le nom et l'adjectif, c'est un attribut, pas une épithète.
:::

::: piege 3. L'accord de proximité
L'adjectif s'accorde avec le nom qu'il **complète**, pas avec celui qui le précède. `des maisons au toit rouge`, sans `s`.
:::

::: piege 4. Qui ou que
`qui` est **sujet** du verbe de la relative, `que` est **objet**. Le test du remplacement par `il` ou `le` ne trompe pas.
:::

::: piege 5. Dont
Le `de` est déjà contenu dans `dont`. On n'écrit ni `dont je t'ai parlé de`, ni `dont je connais son frère`.
:::

::: piege 6. Où
Il indique aussi le **temps** : `le jour où nous sommes partis`.
:::

::: piege 7. L'accord dans la relative
`C'est moi qui **suis** responsable`, et non `qui est`. Le verbe s'accorde avec l'antécédent.
:::

::: piege 8. La surcharge
Deux à trois expansions par groupe nominal suffisent. Au-delà, on coupe la phrase.
:::

## 9. Auto-test

Réponds sans regarder la fiche de cours. Les réponses sont juste en dessous.

::: exercice 1 | application | 8 min | ecran
1. Quel est le noyau de `la petite boîte en carton de mon frère` ?
2. Cite les trois expansions du nom.
3. Quelle expansion contient toujours un verbe conjugué ?
4. Dans `la mer est calme`, `calme` est-il épithète ou attribut ?
5. `des chemises au col blanc` : pourquoi `blanc` ne prend-il pas de `s` ?
6. Complète : `le livre … je te parle`.
7. Complète : `le livre … est sur la table`.
8. `le jour où je suis née` : le pronom `où` indique-t-il un lieu ?
9. Écris correctement : `C'est moi qui (être) responsable.`
10. Que change la virgule dans `Les élèves, fatigués, sont rentrés` ?

::: corrige
1. **boîte**. C'est de la boîte qu'on parle ; `carton` et `frère` ne font que la préciser.
2. L'**adjectif qualificatif épithète**, le **complément du nom**, la **proposition subordonnée relative**.
3. La **proposition subordonnée relative**.
4. **Attribut du sujet** : le verbe d'état `est` se trouve entre le nom et l'adjectif.
5. Parce que `blanc` complète `col`, qui est au singulier, et non `chemises`.
6. `le livre **dont** je te parle`, puisqu'on dit « parler **de** quelque chose ».
7. `le livre **qui** est sur la table` : le pronom est sujet du verbe `est`.
8. **Non**, ici il indique le **temps**. Le pronom `où` couvre le lieu et le temps.
9. `C'est moi qui **suis** responsable.` Le verbe s'accorde avec l'antécédent `moi`.
10. Elle change la **portée** : avec les virgules, **tous** les élèves sont rentrés, et la fatigue est un commentaire. Sans virgules, seuls les élèves fatigués sont rentrés.
:::
