## 1. Le groupe nominal et son noyau

::: definition Groupe nominal
Un **groupe nominal** est un ensemble de mots organisé autour d'un **nom**.
Ce nom est le **noyau** du groupe : c'est lui qui commande l'accord et qu'on ne peut pas supprimer.
:::

::: exemple Repérer le noyau
`la voiture` → noyau : **voiture**
`la vieille voiture rouge` → noyau : **voiture**
`la vieille voiture rouge de mon oncle qui roule encore` → noyau : **voiture**

Le groupe s'allonge, le noyau ne change pas.
:::

::: methode Trouver le noyau d'un groupe nominal
::: etapes
1. Je **supprime** tous les mots que je peux enlever sans rendre la phrase impossible.
2. Il reste le **déterminant** et un **nom** : ce nom est le noyau.
3. Je **vérifie** : le noyau commande le genre et le nombre du groupe entier.
:::
:::

::: piege Le noyau n'est pas toujours le premier nom
Dans `le chapeau de paille de ma grand-mère`, le noyau est **chapeau**, pas `paille` ni `grand-mère`.
Le test est simple : « de quoi parle-t-on ? » On parle d'un chapeau. Les deux autres noms servent seulement à le préciser.
:::

## 2. Ce qu'est une expansion du nom

::: definition Expansion du nom
Une **expansion du nom** est un mot ou un groupe de mots qui vient **compléter** le nom noyau pour le préciser.
On peut la **supprimer** : la phrase reste correcte, elle devient seulement moins précise.
:::

::: grille
| Expansion | Nature | Exemple |
|---|---|---|
| **Adjectif qualificatif épithète** | un adjectif | une route **étroite** |
| **Complément du nom** | un groupe introduit par une préposition | une route **de montagne** |
| **Proposition subordonnée relative** | une proposition introduite par un pronom relatif | une route **qui monte en lacets** |
:::

::: retenir Le test de suppression
Une expansion se **supprime** sans rendre la phrase incorrecte.
`J'ai emprunté une route étroite de montagne qui monte en lacets.`
`J'ai emprunté une route.`
La seconde phrase est plus pauvre, mais elle est grammaticalement juste. C'est la preuve que les trois groupes étaient bien des expansions.
:::

::: piege Ne pas confondre expansion et complément du verbe
Dans `Elle regarde la route`, le groupe `la route` complète le **verbe** : c'est un complément d'objet, il ne se supprime pas librement.
Dans `la route de montagne`, le groupe `de montagne` complète le **nom** : c'est une expansion.
La question à poser est toujours : ce groupe complète-t-il un verbe ou un nom ?
:::

## 3. L'adjectif qualificatif épithète

::: definition Adjectif épithète
L'adjectif **épithète** est un adjectif qui se rapporte directement au nom, sans verbe entre les deux.
Il se place **avant** ou **après** le nom.
:::

::: exemple Avant ou après
`une **longue** attente` : l'adjectif est avant le nom.
`une attente **interminable**` : l'adjectif est après le nom.
`une **longue** attente **interminable**` : les deux positions à la fois.
:::

::: grille
| Fonction | Construction | Exemple |
|---|---|---|
| **Épithète** | collé au nom, sans verbe | une nuit **claire** |
| **Attribut du sujet** | relié au sujet par un verbe d'état | la nuit **est** claire |
:::

::: piege Épithète ou attribut
Le test tient en un mot : y a-t-il un **verbe d'état** entre le nom et l'adjectif ?
`une mer calme` → pas de verbe → **épithète**.
`la mer semble calme` → verbe d'état `semble` → **attribut du sujet**.
Les verbes d'état à connaître : être, paraître, sembler, devenir, rester, demeurer, avoir l'air, passer pour.
:::

::: info Quand l'adjectif change de sens selon sa place
`un homme grand` désigne sa taille. `un grand homme` désigne son importance.
`un livre cher` parle du prix. `un cher ami` parle de l'affection.
La place de l'adjectif n'est donc pas toujours un simple effet de style : elle peut changer le sens.
:::

## 4. L'accord de l'adjectif épithète

::: formule La règle
L'adjectif épithète s'accorde **en genre et en nombre** avec le nom qu'il complète.
:::

::: exemple Quatre accords
`un chemin étroit` → masculin singulier
`une route étroite` → féminin singulier
`des chemins étroits` → masculin pluriel
`des routes étroites` → féminin pluriel
:::

::: piege L'adjectif ne s'accorde pas avec le nom le plus proche
Dans `des maisons au toit **rouge**`, l'adjectif `rouge` complète `toit`, qui est singulier : pas de `s`.
Dans `des maisons aux toits **rouges**`, il complète `toits`, pluriel : un `s`.
Il faut toujours se demander **quel nom** l'adjectif complète, et non regarder le mot d'à côté.
:::

::: formule Deux noms, un seul adjectif
Quand un adjectif complète deux noms de genres différents, il se met au **masculin pluriel**.
`une veste et un pantalon **neufs**`
:::

::: pause
Fin de la première séance. Le groupe nominal et l'adjectif épithète sont posés.
:::

## 5. Le complément du nom

::: definition Complément du nom
Le **complément du nom** est un groupe placé après le nom et introduit le plus souvent par une **préposition** : `de`, `à`, `en`, `pour`, `sans`, `avec`, `par`.
:::

::: exemple Six compléments du nom
`un verre **de** vin`
`une machine **à** coudre`
`une bague **en** argent`
`une salle **pour** les répétitions`
`un café **sans** sucre`
`une maison **avec** jardin`
:::

::: grille
| Ce que le complément du nom apporte | Exemple |
|---|---|
| La **matière** | une table **en bois** |
| L'**appartenance** | le vélo **de ma sœur** |
| La **destination** | une brosse **à dents** |
| Le **contenu** | un verre **de lait** |
| Le **lieu** | la boulangerie **du village** |
| La **qualité** | un homme **de courage** |
:::

::: piege « un verre de vin » et « un verre en verre »
`un verre **de** vin` indique le **contenu** : ce qu'il y a dedans.
`un verre **en** verre` indique la **matière** : de quoi l'objet est fait.
La préposition change complètement le sens. C'est elle qu'il faut lire, pas seulement le nom qui suit.
:::

::: info Le complément du nom sans préposition
Certains compléments du nom se passent de préposition, notamment dans la langue journalistique et commerciale : `le rayon fruits`, `un dossier santé`, `une assurance habitation`.
Cette construction est admise, mais elle reste moins précise que la version avec préposition. En rédaction, on préfère `le rayon des fruits`.
:::

## 6. La proposition subordonnée relative

::: definition Proposition subordonnée relative
Une **proposition subordonnée relative** est une proposition qui complète un nom et qui commence par un **pronom relatif**.
Elle contient toujours un **verbe conjugué**.
:::

::: definition Antécédent
L'**antécédent** est le nom que la relative complète, et que le pronom relatif reprend.
Il se trouve juste avant le pronom relatif, ou très près.
:::

::: exemple Repérer les trois éléments
`Le chien **qui aboie** appartient au voisin.`

Antécédent : **chien**.
Pronom relatif : **qui**.
Proposition relative : **qui aboie**, avec le verbe conjugué `aboie`.
:::

::: retenir Ce qui distingue la relative des deux autres expansions
L'adjectif et le complément du nom n'ont **pas de verbe conjugué**.
La relative en a **toujours un**. C'est le critère de reconnaissance le plus fiable.
:::

## 7. Choisir le bon pronom relatif

::: grille
| Pronom | Fonction dans la relative | Exemple |
|---|---|---|
| **qui** | sujet du verbe de la relative | la fille **qui** chante |
| **que** | complément d'objet direct | la chanson **que** j'écoute |
| **dont** | complément introduit par `de` | le film **dont** je t'ai parlé |
| **où** | complément de lieu ou de temps | la ville **où** je suis née |
| **lequel, laquelle** | après une préposition | le stylo **avec lequel** j'écris |
:::

::: methode Choisir entre « qui » et « que »
::: etapes
1. Je repère le **verbe** de la relative.
2. Je me demande si le pronom est le **sujet** de ce verbe.
3. Si oui, j'écris **qui**. Sinon, j'écris **que**.
4. Test rapide : si je peux remplacer par `il` ou `elle`, c'est `qui`. Si je peux remplacer par `le` ou `la`, c'est `que`.
:::
:::

::: exemple Le test à l'œuvre
`la chanson … j'écoute` → j'écoute **quoi** ? la chanson. C'est un objet, donc **que**.
`la chanson … me plaît` → **qui** me plaît ? la chanson. C'est le sujet, donc **qui**.
:::

::: piege « dont » remplace un groupe avec « de »
On écrit `le film **dont** je t'ai parlé`, parce qu'on dit « parler **de** quelque chose ».
On n'écrit **jamais** `le film dont je t'ai parlé **de**` : la préposition `de` est déjà contenue dans `dont`.
De même, `la personne dont je connais le frère`, et non `dont je connais son frère`.
:::

::: exemple « où » n'est pas réservé au lieu
`la ville **où** j'habite` : complément de lieu.
`le jour **où** nous sommes partis` : complément de temps.
Le pronom `où` couvre les deux. C'est un cas fréquent en dictée.
:::

## 8. Reconnaître l'antécédent

::: methode Trouver l'antécédent
::: etapes
1. Je repère le **pronom relatif**.
2. Je remonte au **nom qui le précède immédiatement**.
3. Je **vérifie le sens** : est-ce bien de ce nom qu'on parle ?
4. Je contrôle l'**accord** : le verbe de la relative s'accorde avec l'antécédent quand le pronom est `qui`.
:::
:::

::: exemple L'accord du verbe dans la relative
`C'est moi qui **suis** responsable.` L'antécédent de `qui` est `moi`, donc la première personne du singulier.
`C'est nous qui **avons** décidé.` L'antécédent est `nous`, donc la première personne du pluriel.
L'erreur fréquente consiste à écrire `c'est moi qui est responsable` : le verbe s'accorde avec `moi`, pas avec `c'est`.
:::

::: piege Un antécédent éloigné
`J'ai relu la lettre de mon grand-père qui était pleine de fautes.`
Grammaticalement, `qui` peut renvoyer à `lettre` ou à `grand-père`. La phrase est ambiguë.
En rédaction, on rapproche le pronom de son antécédent : `J'ai relu la lettre, pleine de fautes, de mon grand-père.`
:::

::: pause
Fin de la deuxième séance. Les trois expansions sont posées.
:::

## 9. Combiner plusieurs expansions

::: exemple Un groupe nominal riche
`la vieille maison de pierre qui domine le village`

Noyau : **maison**.
Expansion 1 : `vieille`, adjectif épithète.
Expansion 2 : `de pierre`, complément du nom.
Expansion 3 : `qui domine le village`, proposition relative.
:::

::: retenir
Un même nom peut recevoir **plusieurs expansions**, de natures différentes.
On les identifie l'une après l'autre, sans chercher à tout nommer d'un coup.
:::

::: exemple Une expansion dans une expansion
`le toit de la maison qui domine le village`

Ici, la relative `qui domine le village` complète `maison`, et non `toit`.
`de la maison qui domine le village` forme un seul complément du nom, à l'intérieur duquel se niche une relative.
Le repérage se fait toujours du plus petit vers le plus grand.
:::

## 10. Enrichir une description

::: methode Enrichir un groupe nominal en trois temps
::: etapes
1. J'écris le groupe nominal **minimal** : déterminant plus nom.
2. J'ajoute un **adjectif** qui dit une qualité perceptible.
3. J'ajoute un **complément du nom** qui dit la matière, l'origine ou l'appartenance.
4. J'ajoute une **relative** qui dit une action ou un détail qui demande un verbe.
:::
:::

::: exemple L'enrichissement pas à pas
Étape 1 : `un couloir`
Étape 2 : `un couloir étroit`
Étape 3 : `un couloir étroit de service`
Étape 4 : `un couloir étroit de service qui sentait la peinture fraîche`

Chaque ajout apporte une information que les précédents ne donnaient pas. C'est le critère : une expansion qui répète ce qui est déjà dit est une expansion inutile.
:::

::: piege Trop d'expansions tuent la description
`la vieille grande belle immense maison ancienne de pierre grise du village voisin qui domine la vallée et qui date du siècle dernier` est illisible.
La règle pratique : **deux à trois expansions** par groupe nominal suffisent. Au-delà, on coupe la phrase en deux.
:::

## 11. Épithète détachée et apposition

::: definition Épithète détachée
Une **épithète détachée** est un adjectif séparé du nom par une **virgule**.
Elle apporte un commentaire, souvent une explication ou une cause.
:::

::: exemple La virgule change le sens
`Les élèves fatigués sont rentrés.` Sans virgule : seuls les élèves fatigués sont rentrés, les autres non.
`Les élèves, fatigués, sont rentrés.` Avec virgules : **tous** les élèves sont rentrés, et ils étaient fatigués.

La virgule n'est pas un détail de ponctuation : elle change le nombre d'élèves concernés.
:::

::: definition Apposition
Une **apposition** est un groupe nominal placé à côté d'un autre nom, séparé par une virgule, et qui le désigne autrement.
`Paris, capitale de la France, compte deux millions d'habitants.`
:::

::: retenir
Détachée ou non, une expansion complète toujours un nom.
Ce qui change avec la virgule, ce n'est pas la nature de l'expansion, c'est la **portée** de l'information.
:::

## 12. Les pièges à éviter

::: grille
| Piège | Ce qui est faux | Ce qui est juste |
|---|---|---|
| Le noyau | c'est le premier nom du groupe | c'est le nom dont **on parle** |
| Épithète et attribut | tout adjectif est épithète | avec un **verbe d'état**, c'est un attribut |
| Accord de l'adjectif | il s'accorde avec le nom le plus proche | avec le nom qu'il **complète** |
| Qui et que | on choisit à l'oreille | `qui` est **sujet**, `que` est **objet** |
| Dont | `le film dont je t'ai parlé de` | le `de` est **déjà dans** `dont` |
| Où | il n'indique que le lieu | il indique aussi le **temps** |
| Accord dans la relative | « c'est moi qui est » | « c'est moi qui **suis** » |
| La virgule | elle ne change rien | elle change la **portée** de l'expansion |
:::

::: retenir
Trois phrases suffisent à retenir le chapitre.
**Une expansion complète un nom et peut se supprimer.**
**Il y en a trois : adjectif épithète, complément du nom, proposition relative.**
**Seule la relative contient un verbe conjugué.**
:::
