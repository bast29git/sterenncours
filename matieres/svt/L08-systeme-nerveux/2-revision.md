## 1. Le schéma à avoir en tête

::: retenir La chaîne de la commande
Stimulation → **récepteur** (organe des sens) → **nerf sensitif** → **centre nerveux** → **nerf moteur** → **muscle** → mouvement.
:::

## 2. Les mots-clés

::: cartes
- **Récepteur** → cellule d'un organe des sens qui capte une stimulation.
- **Message nerveux** → signal électrique qui circule dans les nerfs.
- **Nerf sensitif** → porte le message vers le centre nerveux.
- **Nerf moteur** → porte la commande vers le muscle.
- **Centre nerveux** → cerveau ou moelle épinière.
- **Effecteur** → le muscle qui exécute.
:::

## 3. Réflexe ou volontaire

::: formule-cle Deux chemins
- **Réflexe** : moelle épinière, très rapide, non décidé. Exemple : retirer la main d'une plaque chaude.
- **Volontaire** : cerveau, plus lent, choisi. Exemple : lever la main en classe.
:::

## 4. Le neurone en trois mots

::: definition Neurone, fibre, synapse
Le neurone est la cellule nerveuse ; sa fibre transporte le message ; la synapse est l'espace entre deux neurones, où le message passe par des molécules.
:::

## 5. Les trois facteurs de santé

::: retenir À connaître
1. **Sommeil** : le cerveau fixe la mémoire ; sans sommeil, l'attention chute.
2. **Écrans le soir** : la lumière bleue retarde l'endormissement.
3. **Substances** (alcool, tabac, cannabis) : elles agissent sur les synapses et créent une dépendance.
:::

## 6. Les quatre pièges

::: piege À ne pas faire
1. Confondre nerf et muscle.
2. Faire passer le réflexe par le cerveau.
3. Inverser sensitif et moteur.
4. Croire que dormir ne sert à rien.
:::

## 7. Auto-test en 8 questions

::: cartes
- **Q1.** Quel organe capte la lumière ? → L'**œil**, avec la rétine.
- **Q2.** Quel nerf porte le message vers le centre nerveux ? → Le nerf **sensitif**.
- **Q3.** Quels sont les deux centres nerveux ? → Le **cerveau** et la **moelle épinière**.
- **Q4.** Qui exécute le mouvement ? → Le **muscle**, l'effecteur.
- **Q5.** Retirer la main d'une plaque chaude : réflexe ou volontaire ? → **Réflexe**, par la moelle épinière.
- **Q6.** Comment s'appelle l'espace entre deux neurones ? → La **synapse**.
- **Q7.** Que fait la lumière bleue des écrans le soir ? → Elle **retarde l'endormissement**.
- **Q8.** Sur quoi agissent l'alcool et le cannabis ? → Sur les **synapses** : les messages sont perturbés.
:::

::: aide Comment utiliser l'auto-test
Cache la partie droite de chaque carte. Réponds à voix haute, puis découvre. Une carte ratée renvoie à la partie de la fiche de cours qui la traite.
:::
