## 1. Une situation pour commencer

Maomao, l'apothicaire, sent une odeur de fumée. Elle tourne la tête, voit les flammes, et court prévenir. Entre l'odeur et la course, il s'est passé une chaîne d'événements dans son corps, en moins d'une seconde.

::: retenir La chaîne de la commande
**Stimulation** → **organe des sens** (récepteur) → **nerf sensitif** → **centre nerveux** (cerveau ou moelle épinière) → **nerf moteur** → **muscle** (effecteur) → **mouvement**.
:::

🔁 Pause. Redis cette chaîne à voix haute avec l'exemple du chat qui saute quand on claque une porte.

## 2. Les organes des sens et leurs récepteurs

Le corps capte le monde par cinq organes des sens : l'œil, l'oreille, le nez, la langue, la peau. Chacun contient des **récepteurs** : des cellules qui réagissent à un type de stimulation précis.

::: definition Récepteur sensoriel
Un récepteur est une cellule spécialisée qui transforme une stimulation (lumière, son, odeur, goût, pression, chaleur) en **message nerveux**.
:::

::: exemple Cinq stimulations, cinq récepteurs
| Organe | Stimulation | Récepteurs |
|---|---|---|
| Œil | Lumière | Cellules de la rétine |
| Oreille | Vibrations sonores | Cellules ciliées de l'oreille interne |
| Nez | Molécules odorantes | Cellules de la muqueuse nasale |
| Langue | Molécules dissoutes | Papilles gustatives |
| Peau | Pression, chaleur, douleur | Récepteurs sous la peau |
:::

## 3. Le message nerveux et les nerfs

Le récepteur envoie un **message nerveux** : un signal électrique qui circule le long des **nerfs**. Un nerf est un câble fait de très nombreuses fibres nerveuses, chacune reliée à une cellule.

::: definition Message sensitif et message moteur
- Le **message sensitif** va d'un organe des sens vers un centre nerveux : il informe.
- Le **message moteur** va d'un centre nerveux vers un muscle : il commande.
:::

::: exemple La vitesse du message
Le message nerveux circule à environ 100 mètres par seconde dans les fibres les plus rapides. C'est trop lent pour la lumière, mais assez rapide pour retirer la main d'une plaque brûlante en un dixième de seconde.
:::

::: piege Un nerf n'est pas un muscle
Le nerf transporte un message. Le muscle produit le mouvement. Un nerf coupé laisse le muscle intact mais sans commande : il ne bouge plus.
:::

🔁 Pause. Sur ton schéma, colorie en bleu le trajet sensitif et en rouge le trajet moteur.

## 4. Les centres nerveux : cerveau et moelle épinière

Les messages sensitifs arrivent dans les **centres nerveux** : le **cerveau**, protégé par le crâne, et la **moelle épinière**, protégée par la colonne vertébrale. C'est là que le message est traité et qu'une réponse est décidée.

::: definition Centres nerveux
Le cerveau et la moelle épinière forment le **système nerveux central**. Ils reçoivent les messages sensitifs, les analysent et envoient les messages moteurs.
:::

::: exemple Deux commandes différentes
- Tu décides de lever la main : le cerveau envoie un message moteur au bras. C'est un mouvement **volontaire**.
- Ta main touche une casserole brûlante et se retire avant même que tu aies mal : la moelle épinière a répondu seule, sans attendre le cerveau. C'est un **réflexe**.
:::

::: retenir Deux centres, deux vitesses
Le réflexe passe par la moelle épinière : il est très rapide et ne se décide pas. Le mouvement volontaire passe par le cerveau : il est plus lent mais choisi.
:::

## 5. Les muscles, effecteurs du mouvement

Le message moteur arrive à un **muscle**. Le muscle se **contracte** : il raccourcit et tire sur l'os auquel il est attaché par un **tendon**. L'os bouge autour d'une articulation.

::: definition Effecteur
Un effecteur est l'organe qui exécute la réponse : pour un mouvement, c'est un muscle.
:::

::: exemple Plier le bras
Le biceps se contracte et tire sur l'avant-bras : le bras se plie. Pour le tendre, c'est le triceps, de l'autre côté, qui se contracte pendant que le biceps se relâche. Les muscles travaillent par paires.
:::

## 6. Le neurone, une cellule spéciale

Le système nerveux est fait de cellules nerveuses, les **neurones**. Un neurone a un corps cellulaire et un long prolongement, la **fibre nerveuse**, qui peut mesurer jusqu'à un mètre.

::: definition Neurone et synapse
Le **neurone** est la cellule qui transporte le message nerveux. Entre deux neurones, il y a un tout petit espace, la **synapse** : le message y passe grâce à des molécules chimiques, les neurotransmetteurs.
:::

::: exemple Un relais chimique
À la synapse, le message électrique s'arrête, libère des molécules, et ces molécules déclenchent un nouveau message électrique dans le neurone suivant. C'est là que certaines substances agissent.
:::

🔁 Pause. Dessine deux neurones bout à bout et place la synapse.

## 7. Ce qui perturbe le système nerveux

Le système nerveux a besoin de repos, d'oxygène, et d'être protégé de certaines molécules.

::: retenir Trois facteurs à connaître
- **Le manque de sommeil** : la mémoire se fixe pendant le sommeil ; sans lui, l'attention baisse et le temps de réaction s'allonge.
- **Les écrans le soir** : la lumière bleue retarde l'endormissement, car elle trompe l'horloge du cerveau.
- **Les substances** : alcool, tabac, cannabis et certains médicaments agissent sur les synapses. Elles perturbent les messages, ralentissent les réflexes, et créent une dépendance.
:::

::: exemple Le temps de réaction
Avec la règle : quelqu'un lâche une règle entre tes doigts, tu la rattrapes. La distance parcourue avant le rattrapage donne ton temps de réaction : 15 cm correspondent à environ 0,17 s. Après une nuit courte, cette distance augmente.
:::

::: info Le programme et la santé
Le programme demande de relier ces connaissances à des **choix responsables** : dormir assez, couper les écrans avant de dormir, refuser les substances qui abîment les synapses. Ce ne sont pas des interdits sans raison : ce sont des conséquences biologiques.
:::

## 8. Les pièges à éviter

::: piege Les quatre erreurs les plus fréquentes
1. Confondre nerf (câble) et muscle (moteur).
2. Croire que tout passe par le cerveau : le réflexe passe par la moelle épinière.
3. Inverser message sensitif (vers le centre) et message moteur (vers le muscle).
4. Penser que le sommeil est du temps perdu : c'est le moment où le cerveau range ce qu'il a appris.
:::

::: retenir Ce qu'il faut retenir
- Récepteur → nerf sensitif → centre nerveux → nerf moteur → muscle.
- Cerveau : mouvement volontaire. Moelle épinière : réflexe.
- Le neurone transporte le message ; la synapse le transmet chimiquement.
- Sommeil, écrans et substances agissent sur ce système.
:::
