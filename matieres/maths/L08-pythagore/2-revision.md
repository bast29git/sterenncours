::: retenir La phrase qui résume tout
L'hypoténuse est le côté **qui ne touche pas l'angle droit**.
C'est **toujours** le côté le plus long.
:::

## 2. Les deux outils du chapitre

::: grille
| | Le théorème | La réciproque |
|---|---|---|
| **Ce que je sais déjà** | Le triangle **est** rectangle | Les **trois longueurs** |
| **Ce que je cherche** | Une **longueur** manquante | Si le triangle **est rectangle** ou non |
| **Ce que j'écris** | BC² = AB² + AC² | Deux calculs **séparés**, puis je compare |
| **Mot déclencheur dans l'énoncé** | « calculer », « quelle est la longueur » | « démontrer que », « le triangle est-il… ? » |
:::

::: formule-cle
Si ABC est rectangle en A, alors BC² = AB² + AC²
:::

## 3. Les deux méthodes en 4 étapes

::: methode Méthode A : calculer une longueur
::: etapes
1. Repérer **où est l'angle droit** → en déduire l'hypoténuse.
2. Se demander : l'inconnue **est-elle l'hypoténuse** ?
3. **Oui → j'additionne** les carrés. **Non → je soustrais** : (hypoténuse)² − (côté connu)².
4. Prendre la **racine carrée**, puis conclure par une phrase avec l'unité.
:::
:::

::: methode Méthode B : démontrer avec la réciproque
::: etapes
1. Identifier le **plus grand côté**.
2. Calculer, **à part**, le carré du plus grand côté.
3. Calculer, **à part**, la somme des carrés des deux autres.
4. **Comparer** : égaux → rectangle ; différents → pas rectangle. Conclure par une phrase.
:::
:::

## 6. Les six pièges

::: grille
| ⚠️ Piège | Le bon réflexe |
|---|---|
| Se tromper d'hypoténuse | Doigt sur l'angle droit : l'hypoténuse est le côté **non touché** |
| S'arrêter au carré (répondre 100 au lieu de 10) | Ma **dernière** opération doit être une racine carrée |
| Écrire √(a+b) = √a + √b | Test mental : √(9+16) = 5, mais 3+4 = 7. **Faux** |
| Additionner dans une réciproque | **Deux calculs séparés**, puis comparaison |
| Arrondir en cours de calcul | Valeur exacte jusqu'à la **dernière** ligne |
| Oublier l'unité ou écrire = au lieu de ≈ | La conclusion est une **phrase** ; **≈** dès qu'il y a un arrondi |
:::

## 7. Auto-test en 8 questions

Réponds **sans regarder la fiche de cours**, puis vérifie avec le corrigé.

::: exercice 1 | application | 8 min
1. Dans un triangle RST rectangle en **S**, quel côté est l'hypoténuse ?
2. Écris le théorème de Pythagore pour ce triangle RST.
3. Combien vaut 13² ? Et √196 ?
4. Un triangle rectangle a des côtés de l'angle droit de 9 cm et 12 cm. Quelle est son hypoténuse ?
5. Un triangle rectangle a une hypoténuse de 17 cm et un côté de 8 cm. Quel est le troisième côté ?
6. Un triangle a pour côtés 6 cm, 8 cm et 11 cm. Est-il rectangle ? Justifie par deux calculs.
7. Pourquoi écrit-on BC ≈ 8,6 cm et non BC = 8,6 cm ?
8. Dans une démonstration, quelle phrase doit précéder le calcul ?

::: corrige
::: etapes
1. L'angle droit est en **S**, donc l'hypoténuse est **[RT]** (les deux autres lettres).
2. **RT² = SR² + ST²**
3. 13² = **169** ; √196 = **14**.
4. h² = 9² + 12² = 81 + 144 = 225, donc h = √225 = **15 cm**. *(trio 9-12-15)*
5. c² = 17² − 8² = 289 − 64 = 225, donc c = √225 = **15 cm**. *(trio 8-15-17)*
6. Plus grand côté : 11 cm. D'un côté 11² = **121**. De l'autre 6² + 8² = 36 + 64 = **100**. 121 ≠ 100, donc le triangle **n'est pas rectangle**.
7. Parce que 8,6 est une **valeur arrondie** : la valeur exacte est √74. Le signe **≈** signale l'arrondi.
8. **« D'après le théorème de Pythagore »** : c'est elle qui justifie qu'on a le droit d'écrire l'égalité.
:::
:::
