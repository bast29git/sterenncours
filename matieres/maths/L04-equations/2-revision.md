## 1. Le vocabulaire

::: grille
| Terme | Définition |
|---|---|
| **Équation** | une égalité contenant une inconnue |
| **Inconnue** | la lettre dont on cherche la valeur |
| **Solution** | une valeur qui rend l'égalité vraie |
| **Résoudre** | trouver toutes les solutions |
| **Membre de gauche** | ce qui est avant le signe égal |
| **Membre de droite** | ce qui est après |
:::

::: formule-cle
On ne résout que ce qui contient un **signe égal**.
`3x + 5` est une **expression**. `3x + 5 = 20` est une **équation**.
:::

## 2. Les deux règles

::: formule Règle 1
On peut **ajouter** ou **soustraire** un même nombre aux deux membres.
:::

::: formule Règle 2
On peut **multiplier** ou **diviser** les deux membres par un même nombre **non nul**.
:::

::: formule-cle
L'image de la balance : tout ce qu'on fait d'un côté, on le fait de l'autre.
:::

## 3. La méthode en six étapes

::: formule Les six gestes
1. **Développer** les parenthèses s'il y en a.
2. **Réduire** chaque membre séparément.
3. **Rassembler les `x`** d'un côté, les nombres de l'autre.
4. **Diviser** par le coefficient de `x`.
5. **Vérifier** en calculant les deux membres séparément.
6. **Conclure** par une phrase.
:::

::: exemple Le geste complet
`3x + 5 = 20` → `3x = 15` → `x = 5`
Vérification : gauche `3 × 5 + 5 = 20`, droite `20`. Correct.
:::

## 4. Les trois situations à savoir traiter

::: grille
| Situation | Geste supplémentaire | Exemple |
|---|---|---|
| `ax + b = c` | rien | `3x + 5 = 20` → `x = 5` |
| inconnues des **deux côtés** | soustraire le terme en `x` le plus petit | `5x + 3 = 2x + 18` → `x = 5` |
| avec **parenthèses** | développer d'abord | `3(x + 4) = 2x + 19` → `x = 7` |
| avec **fractions** | multiplier par le dénominateur commun | `x/2 + x/3 = 5` → `x = 6` |
:::

::: piege Multiplier tous les termes
Dans `x/3 + 2 = 5`, multiplier par `3` touche **aussi** le `2` et le `5`.
On obtient `x + 6 = 15`, et non `x + 2 = 5`.
:::

## 5. Les cas particuliers

::: grille
| Ce qu'on obtient | Conclusion |
|---|---|
| `5 = 9`, égalité fausse | **aucune solution** |
| `6 = 6`, égalité vraie | **une infinité** de solutions |
| `x = 0` | **une** solution, qui vaut zéro |
:::

::: formule-cle
Les `x` disparaissent des deux côtés → il reste une égalité entre nombres.
**Fausse** → aucune solution. **Vraie** → une infinité.
:::

## 6. Le dictionnaire de mise en équation

::: grille
| Français | Traduction |
|---|---|
| la somme de `x` et de 7 | `x + 7` |
| 5 de plus que `x` | `x + 5` |
| 5 de moins que `x` | `x − 5` |
| le double de `x` | `2x` |
| le triple de `x` | `3x` |
| la moitié de `x` | `x/2` |
| `x` augmenté de 20 % | `1,2 × x` |
:::

::: piege Deux formulations proches
`5 de moins que x` s'écrit `x − 5`.
`5 moins x` s'écrit `5 − x`.
Ce ne sont pas les mêmes expressions.
:::

## 8. Les huit pièges

::: piege 1. Résoudre une expression
`3x + 5` n'a pas de signe égal : il n'y a rien à résoudre.
:::

::: piege 2. Opérer d'un seul côté
`3x + 5 = 20` ne donne pas `3x = 20`. Il faut soustraire `5` **des deux** membres.
:::

::: piege 3. Diviser par zéro
La règle 2 exige un nombre **non nul**.
:::

::: piege 4. Oublier des termes en supprimant les fractions
Multiplier par le dénominateur commun doit toucher **tous** les termes.
:::

::: piege 5. Résoudre avant de développer
Les parenthèses se développent **d'abord**. Sinon on rassemble des termes qui n'existent pas encore.
:::

::: piege 6. Interpréter `5 = 9`
Cela signifie **aucune solution**, et non `x = 0`.
:::

::: piege 7. Confondre zéro et rien
`x = 0` est **une** solution. C'est différent d'une équation sans solution.
:::

::: piege 8. Oublier la conclusion
`x = 8` ne répond pas à la question. La conclusion reprend les mots de l'énoncé et l'unité.
:::

## 9. Auto-test

Réponds sans regarder la fiche de cours. Les réponses sont juste en dessous.

::: exercice 1 | application | 8 min | ecran
1. `x = 4` est-il solution de `2x + 1 = 9` ?
2. Résous `5x = 35`.
3. Résous `x + 12 = 7`.
4. Résous `4x − 3 = 17`.
5. Résous `6x + 2 = 3x + 14`.
6. Résous `2(x + 3) = 16`.
7. Résous `x/4 = 5`.
8. Que conclure si l'on obtient `7 = 7` ?
9. Que conclure si l'on obtient `3 = 8` ?
10. Traduis en équation : « le double d'un nombre diminué de 5 vaut 13 ».

::: corrige
1. **Oui.** Gauche : `2 × 4 + 1 = 9`. Droite : `9`. Égalité vérifiée.
2. `x = 7`.
3. `x = −5`.
4. `4x = 20`, donc `x = 5`.
5. `3x + 2 = 14`, puis `3x = 12`, donc `x = 4`.
6. `2x + 6 = 16`, puis `2x = 10`, donc `x = 5`.
7. Je multiplie les deux membres par `4` : `x = 20`.
8. L'équation a une **infinité de solutions** : elle est vraie pour tout nombre.
9. L'équation n'a **aucune solution**.
10. `2x − 5 = 13`. La solution est `x = 9`.
:::
