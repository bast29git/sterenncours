## 1. La figure à avoir en tête

::: retenir Trois axes depuis un coin
Un pavé droit posé sur son coin A. Trois arêtes partent de A : la longueur, la largeur, la hauteur. Ce sont les trois axes. Chaque sommet se lit avec trois nombres : 0 ou la dimension.
:::

## 2. La définition en une phrase

::: definition Coordonnées dans l'espace
Un point de l'espace est repéré par trois nombres, dans cet ordre : abscisse, ordonnée, cote. La cote est la hauteur.
:::

## 3. La méthode en trois étapes

::: methode Placer M (x ; y ; z)
::: etapes
1. x le long du premier axe.
2. y parallèlement au second axe.
3. z vers le haut, parallèlement au troisième axe.
:::
:::

## 4. Les huit sommets du pavé 5 × 3 × 2

::: formule-cle Origine en A, longueur 5, largeur 3, hauteur 2
A (0 ; 0 ; 0) · B (5 ; 0 ; 0) · C (5 ; 3 ; 0) · D (0 ; 3 ; 0)
E (0 ; 0 ; 2) · F (5 ; 0 ; 2) · G (5 ; 3 ; 2) · H (0 ; 3 ; 2)
Base : cote 0. Dessus : cote 2.
:::

## 5. Les mots-clés

::: cartes
- **Origine** → le point O, de coordonnées (0 ; 0 ; 0).
- **Abscisse** → le premier nombre, le long de la longueur.
- **Ordonnée** → le deuxième nombre, le long de la largeur.
- **Cote** → le troisième nombre, la hauteur.
- **Milieu** → moyenne de chaque coordonnée des deux extrémités.
- **Face, arête, sommet** → une, deux ou trois coordonnées au bord.
:::

## 6. Les quatre pièges

::: piege À ne pas faire
1. Changer l'ordre des trois nombres.
2. Oublier la cote.
3. Confondre un sommet du bas et celui juste au-dessus.
4. Mesurer sur le dessin en perspective.
:::

## 7. Auto-test en 8 questions

::: cartes
- **Q1.** Combien de nombres pour un point du plan ? De l'espace ? → **Deux**, puis **trois**.
- **Q2.** Comment s'appelle la troisième coordonnée ? → La **cote**.
- **Q3.** Coordonnées de l'origine ? → **(0 ; 0 ; 0)**.
- **Q4.** Pavé 5 × 3 × 2, origine en A : coordonnées de G, le sommet opposé ? → **(5 ; 3 ; 2)**.
- **Q5.** Le sommet juste au-dessus de B (5 ; 0 ; 0) ? → **(5 ; 0 ; 2)**.
- **Q6.** Milieu de [AB] avec A (0 ; 0 ; 0) et B (5 ; 0 ; 0) ? → **(2,5 ; 0 ; 0)**.
- **Q7.** Le point (5 ; 1 ; 1) est-il sur une face ? → **Oui**, l'abscisse vaut la longueur : face BCGF.
- **Q8.** Le point (2 ; 1 ; 3) est-il dans le pavé 5 × 3 × 2 ? → **Non**, la cote 3 dépasse la hauteur 2.
:::

:::
