## 1. Rappel : se repérer dans le plan

Dans le plan, un repère est formé de deux axes gradués qui se coupent en un point appelé **origine**, noté O. L'axe horizontal donne l'**abscisse**, l'axe vertical donne l'**ordonnée**. Un point est repéré par deux nombres, écrits entre parenthèses et séparés par un point-virgule.

::: definition Coordonnées dans le plan
Le point A (3 ; 2) est le point d'abscisse 3 et d'ordonnée 2 : trois carreaux vers la droite, deux carreaux vers le haut.
:::

::: exemple Sur un plan de ville
Sur le plan d'un quartier quadrillé, le café est en (4 ; 1) et la bibliothèque en (4 ; 5). Ils ont la même abscisse : ils sont dans la même rue verticale. La bibliothèque est quatre carreaux plus haut.
:::

::: retenir L'ordre compte
On écrit toujours l'abscisse en premier, l'ordonnée en second. (3 ; 2) et (2 ; 3) sont deux points différents.
:::

🔁 Pause. Place (2 ; 3) et (3 ; 2) sur un quadrillage et vérifie qu'ils ne sont pas au même endroit.

## 2. Une troisième direction

Pose un livre sur la table. Un point du plan de la table se repère avec deux nombres. Mais le coin supérieur du livre n'est pas sur la table : il est **au-dessus**. Pour le décrire, il faut dire de combien il monte. C'est une **troisième direction**, perpendiculaire aux deux autres.

::: definition La cote
Dans l'espace, la troisième coordonnée s'appelle la **cote**. Elle mesure la hauteur au-dessus du plan des deux premiers axes.
:::

::: exemple Dans un immeuble
Un appartement se repère par sa position dans le bâtiment (deux nombres, comme sur un plan) et par son étage (un troisième nombre). L'étage joue le rôle de la cote.
:::

## 3. Le repère de l'espace et la cote

Un repère de l'espace est formé de **trois axes** gradués, perpendiculaires deux à deux, qui se coupent en l'origine O. Un point est repéré par **trois nombres** : abscisse, ordonnée, cote, dans cet ordre.

::: formule Écriture des coordonnées
M (x ; y ; z) : x est l'abscisse, y l'ordonnée, z la cote.
:::

::: exemple Le point M (2 ; 3 ; 4)
Pour atteindre M depuis O : 2 unités le long du premier axe, 3 unités le long du second, puis 4 unités vers le haut. Les trois déplacements se font dans trois directions perpendiculaires.
:::

::: retenir Trois nombres, trois directions
Plan : deux axes, deux nombres. Espace : trois axes, trois nombres. La cote est toujours écrite en dernier.
:::

🔁 Pause. Avec ta main, montre les trois directions à partir d'un coin de la table.

## 4. Les huit sommets d'un pavé droit

Le pavé droit est le solide idéal pour apprendre : ses arêtes sont dans les trois directions du repère. On place l'origine sur un sommet, et les trois axes le long des trois arêtes qui partent de ce sommet.

::: exemple Le pavé ABCDEFGH
Le pavé a pour dimensions 5 (longueur), 3 (largeur) et 2 (hauteur). L'origine est en A. L'axe des abscisses suit [AB], l'axe des ordonnées suit [AD], l'axe des cotes suit [AE].

| Sommet | Coordonnées | Pourquoi |
|---|---|---|
| A | (0 ; 0 ; 0) | l'origine |
| B | (5 ; 0 ; 0) | au bout de la longueur |
| C | (5 ; 3 ; 0) | longueur et largeur, au sol |
| D | (0 ; 3 ; 0) | au bout de la largeur |
| E | (0 ; 0 ; 2) | juste au-dessus de A |
| F | (5 ; 0 ; 2) | au-dessus de B |
| G | (5 ; 3 ; 2) | le sommet opposé à A |
| H | (0 ; 3 ; 2) | au-dessus de D |
:::

::: retenir Les sommets d'en bas et d'en haut
Les quatre sommets de la base ont une cote **0**. Les quatre sommets du dessus ont une cote égale à la **hauteur**. Un sommet et celui qui est juste au-dessus ont la même abscisse et la même ordonnée.
:::

::: methode Écrire les coordonnées d'un sommet
::: etapes
1. Je repère l'origine et les trois axes sur la figure.
2. Je lis la distance parcourue le long de chaque axe pour atteindre le sommet : 0 ou la dimension du pavé.
3. J'écris les trois nombres dans l'ordre : abscisse, ordonnée, cote.
:::
:::

## 5. Lire les coordonnées d'un point

Un point de l'espace n'est pas forcément un sommet. Il peut être au milieu d'une arête, au centre d'une face, ou à l'intérieur du pavé.

::: exemple Le milieu d'une arête
I est le milieu de [BC], avec B (5 ; 0 ; 0) et C (5 ; 3 ; 0). Il a la même abscisse que B et C, soit 5, la même cote, soit 0, et une ordonnée à mi-chemin entre 0 et 3, soit 1,5. Donc I (5 ; 1,5 ; 0).
:::

::: exemple Le centre d'une face
Le centre de la face du dessus EFGH est à mi-longueur, mi-largeur, et à la hauteur du pavé : (2,5 ; 1,5 ; 2).
:::

::: methode Trouver les coordonnées d'un milieu
::: etapes
1. J'écris les coordonnées des deux extrémités.
2. Pour chaque coordonnée, je calcule la moyenne des deux valeurs : (valeur 1 + valeur 2) ÷ 2.
3. J'écris les trois résultats dans l'ordre.
:::
:::

🔁 Pause. Cherche les coordonnées du centre de la face ABFE avant de lire la suite : c'est (2,5 ; 0 ; 1).

## 6. Placer un point à partir de ses coordonnées

C'est le chemin inverse : on part des trois nombres et on retrouve le point sur la figure.

::: methode Placer M (x ; y ; z)
::: etapes
1. Depuis O, j'avance de x le long du premier axe : j'obtiens un point de l'axe.
2. Depuis ce point, j'avance de y parallèlement au second axe : je suis sur le plan de la base.
3. Depuis ce point, je monte de z parallèlement au troisième axe : je suis en M.
:::
:::

::: exemple Placer P (4 ; 1 ; 2) dans le pavé 5 × 3 × 2
4 le long de [AB], puis 1 parallèlement à [AD], puis 2 vers le haut. La cote 2 est la hauteur du pavé : P est **sur la face du dessus**, mais ce n'est pas un sommet.
:::

::: piege Sur une figure en perspective, on ne mesure pas à la règle
Un pavé dessiné en perspective déforme les longueurs sur les axes de profondeur. On lit les coordonnées grâce aux graduations et aux parallèles, jamais en mesurant sur le papier.
:::

## 7. Points sur une face, sur une arête, à l'intérieur

Les coordonnées disent tout de suite où se trouve un point par rapport au pavé de dimensions 5 × 3 × 2.

::: retenir Lire la position dans les coordonnées
- Une coordonnée vaut 0 ou la dimension correspondante : le point est **sur une face**.
- Deux coordonnées valent 0 ou la dimension : le point est **sur une arête**.
- Les trois : c'est un **sommet**.
- Aucune : le point est **à l'intérieur** du pavé, à condition que chaque coordonnée soit comprise entre 0 et la dimension.
:::

::: exemple Quatre points
- Q (5 ; 2 ; 1) : abscisse 5, la longueur : Q est sur la face BCGF.
- R (0 ; 0 ; 1) : deux coordonnées nulles : R est sur l'arête [AE].
- S (2 ; 1 ; 1) : aucune coordonnée au bord : S est à l'intérieur.
- T (6 ; 1 ; 1) : abscisse 6 > 5 : T est à l'extérieur du pavé.
:::

## 8. Les pièges à éviter

::: piege Les quatre erreurs les plus fréquentes
1. Écrire les coordonnées dans le désordre : la cote est toujours la troisième.
2. Oublier la cote et n'écrire que deux nombres pour un point de l'espace.
3. Confondre le sommet du dessus et celui du dessous : ils ont la même abscisse et la même ordonnée, seule la cote change.
4. Mesurer sur le dessin en perspective au lieu de lire les graduations.
:::

::: retenir Ce qu'il faut retenir
- Plan : (abscisse ; ordonnée). Espace : (abscisse ; ordonnée ; cote).
- Dans un pavé droit dont l'origine est un sommet, chaque coordonnée d'un sommet vaut 0 ou une dimension.
- Milieu : moyenne de chaque coordonnée.
- Les coordonnées disent si le point est un sommet, sur une arête, sur une face ou à l'intérieur.
:::
