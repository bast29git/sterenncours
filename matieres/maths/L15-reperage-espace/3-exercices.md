resume: 16 exercices progressifs, du repère du plan aux points à l'intérieur d'un pavé droit, avec un corrigé détaillé pas à pas pour chacun.

  - Représenter
  - Raisonner
  - Communiquer
objectifs:
  - Lire et écrire des coordonnées dans le plan puis dans l'espace
  - Donner les coordonnées des sommets et des milieux d'un pavé droit
  - Dire où se trouve un point à partir de ses coordonnées

::: plan
- **Exercices 1 à 6** : niveau *Application* : plan, cote, sommets du pavé
- **Exercices 7 à 11** : niveau *Entraînement* : milieux, centres de faces, placer un point
- **Exercices 12 à 15** : niveau *Approfondissement* : position d'un point, autres origines
- **Exercice 16** : sujet de type devoir, noté sur 20
:::

::: materiel
- Une règle
- Des feuilles quadrillées pour dessiner un pavé en perspective
- La fiche de révision `2-revision`, pour les huit sommets
:::

::: info Le repère de support, en tête de chaque exercice
**💻 sur écran** : les quatre premiers exercices, faits **ensemble** pendant la séance, corrigés à voix haute juste après.
**✍️ à la main** : tous les autres, faits **seule**, sur papier, dans le cahier à imprimer de la leçon.
:::

::: info Le pavé de référence
Sauf indication contraire, le pavé ABCDEFGH a pour dimensions AB = 5, AD = 3, AE = 2. L'origine est A, l'axe des abscisses suit [AB], l'axe des ordonnées suit [AD], l'axe des cotes suit [AE]. E est au-dessus de A, F au-dessus de B, G au-dessus de C, H au-dessus de D.
:::

## Niveau Application : exercices 1 à 6

::: exercice 1 | application | 3 min | ecran
Dans un repère du plan, placer les points P (2 ; 4), Q (4 ; 2) et R (0 ; 3). Lequel est sur l'axe des ordonnées ? Pourquoi ?

::: corrige
P : 2 vers la droite, 4 vers le haut. Q : 4 vers la droite, 2 vers le haut. R : 0 vers la droite, 3 vers le haut.
**R est sur l'axe des ordonnées** parce que son abscisse vaut **0** : il n'est pas décalé vers la droite. P et Q ne sont pas au même endroit : l'ordre des deux nombres compte.
:::
:::

::: exercice 2 | application | 3 min | ecran
Un point de l'espace a pour coordonnées (3 ; 1 ; 4). Donner son abscisse, son ordonnée et sa cote. Que représente la cote ?

::: corrige
Abscisse : **3**. Ordonnée : **1**. Cote : **4**.
La cote est la **hauteur** du point au-dessus du plan formé par les deux premiers axes.
:::
:::

::: exercice 3 | application | 4 min | ecran
Écrire les coordonnées des sommets A, B, C et D de la base du pavé de référence.

::: corrige
A est l'origine : **(0 ; 0 ; 0)**.
B est au bout de la longueur : **(5 ; 0 ; 0)**.
C a parcouru la longueur et la largeur : **(5 ; 3 ; 0)**.
D est au bout de la largeur : **(0 ; 3 ; 0)**.
Les quatre ont une cote **0** : ils sont sur la base.
:::
:::

::: exercice 4 | application | 4 min | ecran
Écrire les coordonnées des sommets E, F, G et H du dessus du pavé de référence.

::: corrige
Chaque sommet du dessus a les mêmes abscisse et ordonnée que le sommet du dessous, et une cote égale à la hauteur, 2.
E **(0 ; 0 ; 2)**, F **(5 ; 0 ; 2)**, G **(5 ; 3 ; 2)**, H **(0 ; 3 ; 2)**.
:::
:::

::: exercice 5 | application | 4 min | main
Une caisse de papier de l'atelier de Myne a la forme d'un pavé. Un pavé a pour dimensions 8 × 4 × 6, origine en A, mêmes conventions que le pavé de référence. Donner les coordonnées de C, de E et de G.

::: corrige
C : longueur et largeur, au sol : **(8 ; 4 ; 0)**.
E : au-dessus de A, à la hauteur 6 : **(0 ; 0 ; 6)**.
G : le sommet opposé à A : **(8 ; 4 ; 6)**.
:::
:::

::: exercice 6 | application | 4 min | main
Dans le pavé de référence, quel sommet a pour coordonnées (0 ; 3 ; 2) ? Et (5 ; 0 ; 0) ? Justifier en une phrase chacun.

::: corrige
(0 ; 3 ; 2) : abscisse 0, ordonnée 3 (la largeur), cote 2 (la hauteur) : c'est le sommet au-dessus de D, donc **H**.
(5 ; 0 ; 0) : abscisse 5 (la longueur), ordonnée 0, cote 0 : c'est **B**, au bout de la longueur, sur la base.
:::
:::

## Niveau Entraînement : exercices 7 à 11

::: exercice 7 | entrainement | 5 min | main
Dans le pavé de référence, I est le milieu de [EF]. Donner ses coordonnées.

::: corrige
E (0 ; 0 ; 2) et F (5 ; 0 ; 2).
Moyenne de chaque coordonnée : abscisse (0 + 5) ÷ 2 = **2,5** ; ordonnée (0 + 0) ÷ 2 = **0** ; cote (2 + 2) ÷ 2 = **2**.
I **(2,5 ; 0 ; 2)**.
:::
:::

::: exercice 8 | entrainement | 6 min | main
Donner les coordonnées du centre de la face ABCD, puis du centre de la face du dessus EFGH.

::: corrige
Centre de ABCD : mi-longueur, mi-largeur, cote 0 : **(2,5 ; 1,5 ; 0)**.
Centre de EFGH : mêmes abscisse et ordonnée, cote 2 : **(2,5 ; 1,5 ; 2)**.
On peut aussi calculer le milieu de la diagonale [AC] : (0 + 5) ÷ 2 = 2,5 et (0 + 3) ÷ 2 = 1,5.
:::
:::

::: exercice 9 | entrainement | 6 min | main
Yuzu guide sa sœur dans le grenier de la maison de l'ogre. Décrire, étape par étape, le chemin depuis A pour placer le point P (4 ; 1 ; 2) dans le pavé de référence. Ce point est-il un sommet ?

::: corrige
1. Depuis A, avancer de **4** le long de [AB].
2. Puis de **1** parallèlement à [AD].
3. Puis monter de **2** parallèlement à [AE].
La cote 2 est la hauteur : P est sur la **face du dessus** EFGH. Ce n'est **pas un sommet**, car l'abscisse 4 n'est ni 0 ni 5 et l'ordonnée 1 n'est ni 0 ni 3.
:::
:::

::: exercice 10 | entrainement | 6 min | main
Le point K a pour coordonnées (5 ; 3 ; 1) dans le pavé de référence. Sur quelle arête se trouve-t-il ? Quelle est sa position sur cette arête ?

::: corrige
Abscisse 5 = longueur et ordonnée 3 = largeur : deux coordonnées au bord, K est sur une **arête** verticale. Cette arête relie C (5 ; 3 ; 0) et G (5 ; 3 ; 2) : c'est [CG].
Cote 1, à mi-chemin entre 0 et 2 : K est le **milieu de [CG]**.
:::
:::

::: exercice 11 | entrainement | 7 min | main
Sterenn range des feutres à alcool dans une boîte de 12 cm sur 8 cm sur 4 cm. L'origine est un coin du fond. Un feutre est posé au fond, au milieu de la boîte. Donner les coordonnées de son milieu. Un second feutre est posé exactement au-dessus du premier, sur lui. Donner les coordonnées de son milieu si un feutre a 1 cm d'épaisseur.

::: corrige
Premier feutre au fond, au milieu : mi-longueur 6, mi-largeur 4, et son milieu est à mi-épaisseur au-dessus du fond : cote 0,5. Milieu : **(6 ; 4 ; 0,5)**.
Second feutre posé dessus : mêmes abscisse et ordonnée, cote 0,5 + 1 = **1,5**. Milieu : **(6 ; 4 ; 1,5)**.
Seule la cote change quand on empile.
:::
:::

## Niveau Approfondissement : exercices 12 à 15

::: exercice 12 | approfondissement | 7 min | main
Pour chaque point, dire s'il est un sommet, sur une arête, sur une face, à l'intérieur ou à l'extérieur du pavé de référence : M (5 ; 1 ; 2), N (2 ; 2 ; 1), P (0 ; 0 ; 1,5), Q (3 ; 4 ; 1).

::: corrige
M (5 ; 1 ; 2) : abscisse 5 et cote 2 au bord, ordonnée 1 pas au bord : deux coordonnées au bord, M est sur une **arête**, l'arête [FG].
N (2 ; 2 ; 1) : aucune coordonnée au bord, toutes entre 0 et la dimension : N est **à l'intérieur**.
P (0 ; 0 ; 1,5) : deux coordonnées nulles : P est sur l'**arête** [AE].
Q (3 ; 4 ; 1) : ordonnée 4 > 3 : Q est **à l'extérieur** du pavé.
:::
:::

::: exercice 13 | approfondissement | 8 min | main
On change d'origine : on place l'origine en G, l'axe des abscisses le long de [GH], l'axe des ordonnées le long de [GF], l'axe des cotes le long de [GC] vers le bas. Donner les nouvelles coordonnées de G, H, F et C dans le pavé de référence.

::: corrige
G est la nouvelle origine : **(0 ; 0 ; 0)**.
H est au bout de [GH], qui mesure 5 : **(5 ; 0 ; 0)**.
F est au bout de [GF], qui mesure 3 : **(0 ; 3 ; 0)**.
C est au bout de [GC], qui mesure 2 : **(0 ; 0 ; 2)**.
Le pavé n'a pas bougé : seules les coordonnées changent quand l'origine change.
:::
:::

::: exercice 14 | approfondissement | 8 min | main
Dans le pavé de référence, on considère les points R (5 ; 0 ; 1) et S (5 ; 3 ; 1). Sur quelle face sont-ils ? Quelle est la longueur de [RS] ? Le segment [RS] est parallèle à quelle arête ?

::: corrige
R et S ont une abscisse 5 : ils sont sur la face **BCGF**. Ils sont à la cote 1, à mi-hauteur.
R et S ne diffèrent que par l'ordonnée : 0 et 3. La longueur de [RS] est 3 − 0 = **3**.
[RS] est parallèle à l'arête [BC] (et à [FG]), qui va aussi dans la direction des ordonnées.
:::
:::

::: exercice 15 | approfondissement | 9 min | main
Maomao range ses remèdes dans une boîte cubique. Un cube a des arêtes de 4 cm, origine en A avec les conventions habituelles. Donner les coordonnées du centre du cube. Puis calculer la distance de ce centre au centre de la face du dessus.

::: corrige
Le cube a pour dimensions 4 × 4 × 4. Son centre est à mi-chemin dans les trois directions : **(2 ; 2 ; 2)**.
Le centre de la face du dessus est **(2 ; 2 ; 4)**.
Les deux points ont mêmes abscisse et ordonnée ; seule la cote change, de 2 à 4. Distance : 4 − 2 = **2 cm**, la moitié de l'arête.
:::
:::

## Sujet de type devoir

::: exercice 16 | approfondissement | 30 min | main
**Devoir sur 20, en 30 minutes, à la main.** Le pavé ABCDEFGH a pour dimensions AB = 6, AD = 4, AE = 3, origine en A, conventions habituelles.

**Question 1 (4 points).** Écrire les coordonnées de B, D, E et G.

**Question 2 (4 points).** Le point J a pour coordonnées (6 ; 4 ; 1,5). Sur quelle arête est-il ? Est-il le milieu de cette arête ? Justifier.

**Question 3 (6 points).** Calculer les coordonnées du milieu de [AG], puis celles du centre de la face EFGH. Ces deux points ont-ils la même cote ?

**Question 4 (6 points).** Dire si chacun des points suivants est à l'intérieur, sur une face, ou à l'extérieur du pavé, en justifiant : T (3 ; 2 ; 3), U (1 ; 5 ; 1), V (2 ; 2 ; 2).

::: corrige
**Question 1 : 4 points** (1 point par sommet)
B **(6 ; 0 ; 0)** ; D **(0 ; 4 ; 0)** ; E **(0 ; 0 ; 3)** ; G **(6 ; 4 ; 3)**.

**Question 2 : 4 points**
Abscisse 6 = AB et ordonnée 4 = AD : deux coordonnées au bord, J est sur l'arête verticale [CG] (2 points). La cote 1,5 est la moitié de la hauteur 3 : J est le **milieu de [CG]** (2 points).

**Question 3 : 6 points**
Milieu de [AG] avec A (0 ; 0 ; 0) et G (6 ; 4 ; 3) : (3 ; 2 ; 1,5) (3 points). C'est le centre du pavé.
Centre de EFGH : (3 ; 2 ; 3) (2 points).
Non, les cotes sont différentes : 1,5 et 3 ; le second point est juste au-dessus du premier (1 point).

**Question 4 : 6 points** (2 points par point)
T (3 ; 2 ; 3) : la cote 3 vaut la hauteur, les deux autres coordonnées sont entre 0 et la dimension : T est **sur la face du dessus**.
U (1 ; 5 ; 1) : l'ordonnée 5 dépasse la largeur 4 : U est **à l'extérieur**.
V (2 ; 2 ; 2) : aucune coordonnée au bord, toutes dans les limites : V est **à l'intérieur**.
:::
:::
