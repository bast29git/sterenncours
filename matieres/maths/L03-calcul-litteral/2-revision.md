## 1. Les conventions d'écriture

::: grille
| Écriture longue | Écriture simplifiée |
|---|---|
| `5 × x` | `5x` |
| `1 × y` | `y` |
| `−1 × b` | `−b` |
| `3 × (x + 2)` | `3(x + 2)` |
| `x × x` | `x²` |
:::

::: formule-cle
Le nombre s'écrit **avant** la lettre : `3a`, jamais `a3`.
On ne supprime **jamais** le `×` entre deux nombres.
:::

## 2. Réduire

::: formule La règle
On additionne les nombres devant les termes qui ont la **même partie littérale**.
`3x + 5x = 8x`
:::

::: piege Ce qu'on ne peut pas regrouper
`3x + 2` reste `3x + 2`. Ces deux termes ne sont pas semblables.
`3x` et `3x²` ne sont pas semblables non plus.
:::

::: exemple Le geste en une ligne
`4x + 3 + 2x − 7 = 6x − 4`
`2x² + 5x − x² + 3x = x² + 8x`
:::

## 3. Développer : les deux formules

::: formule Distributivité simple
`k(a + b) = ka + kb`
`k(a − b) = ka − kb`
**Deux produits**, un par terme de la parenthèse.
:::

::: formule Double distributivité
`(a + b)(c + d) = ac + ad + bc + bd`
**Quatre produits**, toujours.
:::

::: exemple Les gestes en une ligne
`3(x + 4) = 3x + 12`
`x(x + 3) = x² + 3x`
`(x + 2)(x + 5) = x² + 5x + 2x + 10 = x² + 7x + 10`
`(2x + 1)(3x − 5) = 6x² − 10x + 3x − 5 = 6x² − 7x − 5`
:::

## 4. Le piège du signe moins

::: formule-cle
Un **moins devant une parenthèse** change **tous** les signes à l'intérieur.
`7 − (x + 2) = 7 − x − 2 = 5 − x`
`−3(2x − 4) = −6x + 12`
:::

::: piege La faute la plus fréquente
`7 − (x + 2)` ne fait **pas** `7 − x + 2`.
Le moins porte sur toute la parenthèse, donc aussi sur le `+2`.
:::

## 5. Factoriser

::: formule La règle
`ka + kb = k(a + b)`
On écrit le **facteur commun** devant, et ce qui reste dans la parenthèse.
:::

::: grille
| Type de facteur commun | Exemple | Résultat |
|---|---|---|
| Numérique | `6x + 15` | `3(2x + 5)` |
| Littéral | `x² + 7x` | `x(x + 7)` |
| Mixte | `4x² − 6x` | `2x(2x − 3)` |
| Parenthèse | `(x+1)(x+5) + (x+1)(2x−3)` | `(x + 1)(3x + 2)` |
:::

::: piege Le terme qui vaut 1
`5x + 5 = 5(x + 1)`, et non `5(x)`.
`x² + x = x(x + 1)`, et non `x(x)`.
Quand un terme est égal au facteur commun, ce qui reste vaut **1**.
:::

## 6. Vérifier son travail

::: formule Les trois contrôles
**Après un développement** : compter les produits. Simple → 2. Double → 4.
**Après une factorisation** : redévelopper et retrouver le départ.
**Dans tous les cas** : tester avec `x = 2`.
:::

::: exemple Le test numérique
`(x + 3)(x − 1) = x² + 2x − 3` ?
Pour `x = 2` : gauche `5 × 1 = 5`, droite `4 + 4 − 3 = 5`. Concordant.
:::

::: piege Le test détecte, il ne prouve pas
Deux valeurs différentes → il y a une erreur, c'est certain.
Deux valeurs égales → c'est probablement juste. On évite `x = 0` et `x = 1`, qui masquent des erreurs.
:::

## 8. Les huit pièges

::: piege 1. Réduire ce qui ne se réduit pas
`3x + 2` est déjà réduit. On ne peut pas additionner un terme en `x` et un nombre seul.
:::

::: piege 2. Oublier un terme en développant
`3(x + 4) = 3x + 12`, et non `3x + 4`. Le facteur multiplie **les deux** termes.
:::

::: piege 3. Le moins devant la parenthèse
`7 − (x + 2) = 5 − x`. Tous les signes changent.
:::

::: piege 4. Deux produits au lieu de quatre
`(x + 2)(x + 5)` donne **quatre** produits. Les compter avant de réduire.
:::

::: piege 5. Le carré d'un négatif
`(−2)² = 4`, alors que `−2² = −4`. Toujours substituer entre parenthèses.
:::

::: piege 6. La factorisation qui perd un terme
`5x + 5 = 5(x + 1)`. Le second terme laisse un `1`, pas un vide.
:::

::: piege 7. L'écriture
On écrit `3a`, pas `a3`. Et on garde le `×` entre deux nombres.
:::

::: piege 8. Développer et réduire en même temps
On développe d'abord, on recopie tous les termes, **ensuite** on réduit. C'est ainsi qu'on ne perd rien.
:::

## 9. Auto-test

Réponds sans regarder la fiche de cours. Les réponses sont juste en dessous.

::: exercice 1 | application | 8 min | ecran
1. Simplifie l'écriture de `1 × x × x`.
2. Réduis `5x − 2 + 3x + 7`.
3. Développe `4(x + 3)`.
4. Développe `−2(x − 5)`.
5. Développe `6 − (x + 1)`.
6. Développe et réduis `(x + 4)(x + 2)`.
7. Factorise `8x + 12`.
8. Factorise `x² − 5x`.
9. Factorise `6x² + 9x`.
10. Calcule `x² − 4x` pour `x = −1`.

::: corrige
1. `x²`.
2. `8x + 5`.
3. `4x + 12`.
4. `−2x + 10`. Le facteur négatif change le signe des deux termes.
5. `6 − x − 1 = 5 − x`.
6. `x² + 2x + 4x + 8 = x² + 6x + 8`.
7. `4(2x + 3)`, puisque `8 = 4 × 2` et `12 = 4 × 3`.
8. `x(x − 5)`.
9. `3x(2x + 3)`. Facteur commun `3` pour les nombres, `x` pour les lettres.
10. `(−1)² − 4 × (−1) = 1 + 4 = 5`.
:::
