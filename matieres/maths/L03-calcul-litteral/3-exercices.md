## Série A : écriture, réduction, substitution

::: exercice 1 | application | 4 min | ecran
Simplifie l'écriture de chaque expression.

1. `4 × a`
2. `x × y`
3. `1 × t`
4. `−1 × m`
5. `b × b`
6. `3 × (x + 1)`

::: corrige
1. `4a`
2. `xy`
3. `t`
4. `−m`
5. `b²`
6. `3(x + 1)`
:::
:::

::: exercice 2 | application | 4 min | ecran
Ces écritures sont incorrectes. Corrige-les.

1. `a5`
2. `3 × 7 = 37`
3. `1x`
4. `x × x = 2x`

::: corrige
1. `5a`. Le nombre s'écrit avant la lettre.
2. `3 × 7 = 21`. On ne supprime jamais le signe `×` entre deux nombres.
3. `x`. Le coefficient `1` ne s'écrit pas.
4. `x × x = x²`. Multiplier une lettre par elle-même donne un **carré**, pas un doublement. `2x` signifierait `x + x`.
:::
:::

::: exercice 3 | application | 5 min | ecran
Réduis chaque expression.

1. `7x + 2x`
2. `9a − 4a`
3. `5x + 3 − 2x + 8`
4. `4y − 7 − y + 2`
5. `3x² + 2x − x² + 5x`

::: corrige
1. `9x`
2. `5a`
3. `3x + 11`
4. `3y − 5`. Attention : `−y` vaut `−1y`, donc `4y − y = 3y`.
5. `2x² + 7x`
:::
:::

::: exercice 4 | application | 4 min | ecran
Ces expressions sont-elles réductibles ? Réponds par oui ou non et justifie.

1. `4x + 5x`
2. `4x + 5`
3. `4x + 5x²`
4. `4x + 5y`

::: corrige
1. **Oui** : même partie littérale `x`. Résultat `9x`.
2. **Non** : `4x` a une partie littérale, `5` n'en a pas. L'expression est déjà réduite.
3. **Non** : `x` et `x²` ne sont pas la même partie littérale.
4. **Non** : `x` et `y` sont deux lettres différentes.
:::
:::

::: exercice 5 | entrainement | 5 min | main
Calcule la valeur de chaque expression pour `x = 4`.

1. `3x + 5`
2. `x² − 2x`
3. `2x² + x − 6`

::: corrige
1. `3 × (4) + 5 = 12 + 5 = 17`
2. `(4)² − 2 × (4) = 16 − 8 = 8`
3. `2 × (4)² + (4) − 6 = 2 × 16 + 4 − 6 = 32 + 4 − 6 = 30`
:::
:::

::: exercice 6 | entrainement | 6 min | main
Calcule la valeur de chaque expression pour `x = −3`. Écris les parenthèses lors de la substitution.

1. `x + 7`
2. `x²`
3. `−x`
4. `x² − 4x`
5. `2x² + 3x − 1`

::: corrige
1. `(−3) + 7 = 4`
2. `(−3)² = 9`. Le carré d'un nombre négatif est positif.
3. `−(−3) = 3`. L'opposé d'un nombre négatif est positif.
4. `(−3)² − 4 × (−3) = 9 − (−12) = 9 + 12 = 21`
5. `2 × (−3)² + 3 × (−3) − 1 = 2 × 9 − 9 − 1 = 18 − 9 − 1 = 8`

Remarque : sans parenthèses, on écrirait `−3²`, ce qui vaut `−9` et conduirait à des résultats faux dans les questions 2, 4 et 5.
:::
:::

## Série B : distributivité simple

::: exercice 7 | application | 5 min | main
Développe.

1. `5(x + 2)`
2. `3(x − 7)`
3. `4(2x + 1)`
4. `x(x + 6)`
5. `2x(3x − 5)`

::: corrige
1. `5x + 10`
2. `3x − 21`
3. `8x + 4`
4. `x² + 6x`
5. `6x² − 10x`
:::
:::

::: exercice 8 | application | 5 min | main
Développe, en soignant les signes.

1. `−2(x + 4)`
2. `−5(x − 3)`
3. `−(x + 9)`
4. `−3(2x − 1)`

::: corrige
1. `−2x − 8`
2. `−5x + 15`. Moins par moins donne plus.
3. `−x − 9`. Le signe moins seul équivaut à `−1 ×`.
4. `−6x + 3`
:::
:::

::: exercice 9 | entrainement | 6 min | main
Développe et réduis.

1. `8 − (x + 3)`
2. `10 − (2x − 5)`
3. `3(x + 1) + 2(x + 4)`
4. `6(x + 2) − 3(x − 1)`

::: corrige
1. `8 − x − 3 = 5 − x`
2. `10 − 2x + 5 = 15 − 2x`
3. `3x + 3 + 2x + 8 = 5x + 11`
4. `6x + 12 − 3x + 3 = 3x + 15`

Le point délicat des questions 1, 2 et 4 est le signe moins devant la parenthèse : il change **tous** les signes à l'intérieur.
:::
:::

::: exercice 10 | entrainement | 6 min | main
Ces développements sont faux. Corrige-les et explique l'erreur en une ligne.

1. `4(x + 3) = 4x + 3`
2. `7 − (x + 2) = 7 − x + 2`
3. `−2(x − 5) = −2x − 10`

::: corrige
1. `4(x + 3) = 4x + 12`. Le facteur `4` doit multiplier **les deux** termes de la parenthèse, pas seulement le premier.
2. `7 − (x + 2) = 7 − x − 2 = 5 − x`. Le signe moins s'applique à toute la parenthèse, donc le `+2` devient `−2`.
3. `−2(x − 5) = −2x + 10`. Moins par moins donne plus : `(−2) × (−5) = +10`.
:::
:::

::: exercice 11 | approfondissement | 7 min | main
Maomao compare deux façons d'écrire la même recette de remède. On considère l'expression `A = 5(x + 2) − 3(x − 4)`.

1. Développe et réduis `A`.
2. Calcule `A` pour `x = 3`, en utilisant l'expression réduite.
3. Vérifie ton résultat en calculant `A` pour `x = 3` avec l'expression de départ.
4. Que peux-tu conclure ?

::: corrige
1. `5(x + 2) = 5x + 10` et `−3(x − 4) = −3x + 12`.
   Donc `A = 5x + 10 − 3x + 12 = 2x + 22`.
2. Pour `x = 3` : `A = 2 × 3 + 22 = 6 + 22 = 28`.
3. Avec l'expression de départ : `5(3 + 2) − 3(3 − 4) = 5 × 5 − 3 × (−1) = 25 + 3 = 28`.
4. Les deux calculs donnent **`28`** : le développement est très probablement correct. C'est la méthode de vérification à utiliser systématiquement. Attention cependant, un test ne **prouve** rien : il détecte les erreurs, il ne garantit pas l'exactitude.
:::
:::

## Série C : double distributivité et factorisation

::: exercice 12 | application | 6 min | main
Développe et réduis.

1. `(x + 1)(x + 3)`
2. `(x + 5)(x + 2)`
3. `(x − 4)(x + 6)`
4. `(x − 2)(x − 7)`

::: corrige
1. `x² + 3x + x + 3 = x² + 4x + 3`
2. `x² + 2x + 5x + 10 = x² + 7x + 10`
3. `x² + 6x − 4x − 24 = x² + 2x − 24`
4. `x² − 7x − 2x + 14 = x² − 9x + 14`. Moins par moins donne plus pour le dernier produit.
:::
:::

::: exercice 13 | entrainement | 7 min | main
Développe et réduis.

1. `(2x + 1)(x + 4)`
2. `(3x − 2)(x + 5)`
3. `(2x + 3)(2x − 3)`
4. `(x + 4)²`

::: corrige
1. `2x² + 8x + x + 4 = 2x² + 9x + 4`
2. `3x² + 15x − 2x − 10 = 3x² + 13x − 10`
3. `4x² − 6x + 6x − 9 = 4x² − 9`. Les deux termes du milieu s'annulent exactement.
4. `(x + 4)² = (x + 4)(x + 4) = x² + 4x + 4x + 16 = x² + 8x + 16`.
   Attention : `(x + 4)²` ne vaut **pas** `x² + 16`. Il faut écrire le produit en toutes lettres avant de développer.
:::
:::

::: exercice 14 | application | 5 min | main
Factorise.

1. `3x + 12`
2. `10x − 15`
3. `x² + 4x`
4. `7x² − 7x`

::: corrige
1. `3(x + 4)`
2. `5(2x − 3)`
3. `x(x + 4)`
4. `7x(x − 1)`
:::
:::

::: exercice 15 | entrainement | 6 min | main
Factorise, puis vérifie en redéveloppant.

1. `6x² + 9x`
2. `12x − 8`
3. `5x + 5`
4. `x² − x`

::: corrige
1. Facteur commun : `3` pour les nombres, `x` pour les lettres, donc `3x`.
   `6x² + 9x = 3x(2x + 3)`. Vérification : `3x × 2x + 3x × 3 = 6x² + 9x`. Correct.
2. Facteur commun `4`.
   `12x − 8 = 4(3x − 2)`. Vérification : `12x − 8`. Correct.
3. Facteur commun `5`.
   `5x + 5 = 5(x + 1)`. Vérification : `5x + 5`. Correct.
   Le second terme laisse un `1`, pas un vide : écrire `5(x)` serait faux.
4. Facteur commun `x`.
   `x² − x = x(x − 1)`. Vérification : `x² − x`. Correct.
:::
:::

::: exercice 16 | entrainement | 7 min | main
Factorise ces expressions dont le facteur commun est une parenthèse.

1. `(x + 2)(x + 7) + (x + 2)(3x − 1)`
2. `(2x − 5)(x + 1) − (2x − 5)(x − 4)`

::: corrige
1. Le facteur commun est `(x + 2)`.
   `= (x + 2)[(x + 7) + (3x − 1)]`
   `= (x + 2)(x + 7 + 3x − 1)`
   `= (x + 2)(4x + 6)`
2. Le facteur commun est `(2x − 5)`.
   `= (2x − 5)[(x + 1) − (x − 4)]`
   `= (2x − 5)(x + 1 − x + 4)`
   `= (2x − 5) × 5`
   `= 5(2x − 5)`
   Le crochet vaut `5`, un nombre constant : le `x` disparaît. Ce n'est pas une erreur, c'est bien le résultat.
:::
:::

::: exercice 17 | approfondissement | 8 min | main
Lutz, l'élève de l'atelier de papier, écrit : « Développer et factoriser, c'est la même chose puisqu'on obtient toujours le même résultat. »

1. Cette affirmation est-elle exacte ? Explique.
2. Prends l'expression `4x + 20` et montre le lien entre les deux opérations.
3. Dans quel cas préfère-t-on la forme développée ? Et la forme factorisée ?

::: corrige
1. Elle est **inexacte**, mais elle contient une part de vérité. Les deux formes représentent bien la **même quantité** pour toute valeur de `x` : c'est en cela que l'élève n'a pas tort. Mais développer et factoriser sont des **opérations inverses** : l'une transforme un produit en somme, l'autre une somme en produit. Ce ne sont donc pas les mêmes gestes, et elles ne servent pas aux mêmes usages.
2. `4x + 20` est une **somme**. Le facteur commun est `4`, donc `4x + 20 = 4(x + 5)`, qui est un **produit**.
   Inversement, en développant `4(x + 5)`, on retrouve `4x + 20`.
   Pour `x = 3` : `4 × 3 + 20 = 32` et `4 × (3 + 5) = 4 × 8 = 32`. Les deux formes donnent bien la même valeur.
3. On préfère la forme **développée** pour comparer ou additionner des expressions, et pour repérer rapidement le terme en `x²`, le terme en `x` et le nombre seul.
   On préfère la forme **factorisée** pour calculer mentalement, et surtout pour résoudre des équations : un produit est nul si et seulement si l'un de ses facteurs est nul. C'est cette propriété qui sera utilisée en 3ᵉ.
:::
:::

## Série D : problèmes et devoir type

::: exercice 18 | entrainement | 8 min | main
Myne découpe une feuille de papier rectangulaire. Un rectangle a pour longueur `x + 3` et pour largeur `4`.

1. Exprime son périmètre en fonction de `x`, sous forme réduite.
2. Exprime son aire en fonction de `x`, sous forme développée.
3. Calcule le périmètre et l'aire pour `x = 5`.
4. Vérifie l'aire en calculant directement les dimensions pour `x = 5`.

::: corrige
1. Périmètre `= 2 × (x + 3) + 2 × 4 = 2x + 6 + 8 = 2x + 14`.
2. Aire `= 4 × (x + 3) = 4x + 12`.
3. Pour `x = 5` : périmètre `= 2 × 5 + 14 = 24`. Aire `= 4 × 5 + 12 = 32`.
4. Pour `x = 5`, la longueur vaut `5 + 3 = 8` et la largeur `4`.
   Aire directe : `8 × 4 = 32`. Périmètre direct : `2 × 8 + 2 × 4 = 16 + 8 = 24`.
   Les deux méthodes concordent.
:::
:::

::: exercice 19 | approfondissement | 10 min | main
Dans l'atelier de papier, on assemble deux planches à sécher. On considère un carré de côté `x`, auquel on ajoute un rectangle de dimensions `x` et `5` accolé sur un côté.

1. Fais un schéma de la figure obtenue.
2. Exprime l'aire totale de deux façons : en additionnant les deux aires, puis en considérant la figure comme un seul rectangle.
3. Que constates-tu ?
4. Quelle propriété du cours cette figure illustre-t-elle ?
5. Calcule l'aire pour `x = 6` avec les deux expressions.

::: corrige
1. Le schéma attendu montre un carré de côté `x` et, accolé à sa droite, un rectangle de largeur `5` et de hauteur `x`. L'ensemble forme un grand rectangle de hauteur `x` et de base `x + 5`.
2. **Première façon**, en additionnant : aire du carré `= x × x = x²`, aire du rectangle `= x × 5 = 5x`. Total : `x² + 5x`.
   **Seconde façon**, comme un seul rectangle : hauteur `x`, base `x + 5`. Aire `= x(x + 5)`.
3. On constate que `x(x + 5) = x² + 5x`. Les deux expressions décrivent la même surface, donc elles sont égales pour toute valeur de `x`.
4. Cette figure illustre la **distributivité simple**, et donc à la fois le développement, en allant de `x(x + 5)` vers `x² + 5x`, et la **factorisation**, en allant dans l'autre sens. La factorisation revient ici à reconnaître que deux morceaux ont la même hauteur `x`, donc qu'on peut les recoller en un seul rectangle.
5. Pour `x = 6` : `x² + 5x = 36 + 30 = 66`. Et `x(x + 5) = 6 × 11 = 66`. Les deux donnent bien `66`.
:::

::: exercice 20 | approfondissement | 25 min | main
**Devoir type.** Traite les quatre parties, en rédigeant tes calculs.

**Partie A : écrire et réduire** (5 points)
a. Simplifie l'écriture de `1 × a × a` et de `−1 × b`.
b. Réduis `6x − 4 + 2x + 9 − 3x`.
c. Réduis `5x² + 3x − 2x² − 8x`.
d. Calcule `x² − 5x + 2` pour `x = −2`. Détaille chaque étape.

**Partie B : développer** (5 points)
a. `7(x + 3)`
b. `−4(2x − 1)`
c. `9 − (x + 6)`
d. `3(x + 5) − 2(x − 1)`

**Partie C : double distributivité** (5 points)
a. `(x + 3)(x + 8)`
b. `(x − 5)(x + 2)`
c. `(2x + 1)(3x − 4)`
d. Vérifie le résultat de la question c pour `x = 2`.

**Partie D : factoriser** (5 points)
a. `9x + 21`
b. `x² − 6x`
c. `8x² + 12x`
d. `(x + 3)(x − 1) + (x + 3)(2x + 5)`
e. Vérifie la question c en redéveloppant.

::: corrige
**Partie A**

a. `1 × a × a = a²`. `−1 × b = −b`.

b. `6x + 2x − 3x = 5x` et `−4 + 9 = 5`.
Résultat : **`5x + 5`**.

c. `5x² − 2x² = 3x²` et `3x − 8x = −5x`.
Résultat : **`3x² − 5x`**.

d. Pour `x = −2` :
`(−2)² − 5 × (−2) + 2`
`= 4 − (−10) + 2`
`= 4 + 10 + 2`
`= 16`

**Partie B**

a. `7(x + 3) = 7x + 21`

b. `−4(2x − 1) = −8x + 4`. Moins par moins donne plus.

c. `9 − (x + 6) = 9 − x − 6 = 3 − x`

d. `3(x + 5) = 3x + 15` et `−2(x − 1) = −2x + 2`.
Somme : `3x + 15 − 2x + 2 = x + 17`

**Partie C**

a. `(x + 3)(x + 8) = x² + 8x + 3x + 24 = x² + 11x + 24`

b. `(x − 5)(x + 2) = x² + 2x − 5x − 10 = x² − 3x − 10`

c. `(2x + 1)(3x − 4) = 6x² − 8x + 3x − 4 = 6x² − 5x − 4`

d. Vérification pour `x = 2`.
Expression de départ : `(2 × 2 + 1)(3 × 2 − 4) = 5 × 2 = 10`.
Expression développée : `6 × 2² − 5 × 2 − 4 = 24 − 10 − 4 = 10`.
Les deux valeurs coïncident : le développement est correct.

**Partie D**

a. `9 = 3 × 3` et `21 = 3 × 7`, donc facteur commun `3`.
`9x + 21 = 3(3x + 7)`

b. Facteur commun `x`.
`x² − 6x = x(x − 6)`

c. Pour les nombres, `8` et `12` ont `4` en commun. Pour les lettres, `x²` et `x` ont `x`. Facteur commun `4x`.
`8x² + 12x = 4x(2x + 3)`

d. Le facteur commun est `(x + 3)`.
`= (x + 3)[(x − 1) + (2x + 5)]`
`= (x + 3)(x − 1 + 2x + 5)`
`= (x + 3)(3x + 4)`

e. Vérification de la question c : `4x(2x + 3) = 4x × 2x + 4x × 3 = 8x² + 12x`.
On retrouve exactement l'expression de départ : la factorisation est correcte.

**Barème indicatif**
Partie A : 5 points (1 pour les écritures, 1,5 pour les deux réductions, 2,5 pour la substitution détaillée).
Partie B : 5 points (1,25 par développement).
Partie C : 5 points (1,25 par item, dont la vérification).
Partie D : 5 points (1 par factorisation, 1 pour la vérification).
