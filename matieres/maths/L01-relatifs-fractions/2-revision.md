## 1. Les quatre règles en une page

::: formule-cle
**Soustraire, c'est ajouter l'opposé.**
`a - b = a + (-b)`
:::

::: formule-cle
**Diviser, c'est multiplier par l'inverse.**
`a/b ÷ c/d = a/b × d/c`
:::

::: formule-cle
**On n'additionne que des fractions de même dénominateur.**
`a/c + b/c = (a + b)/c`
:::

::: formule-cle
**On multiplie les fractions directement, ligne par ligne.**
`a/b × c/d = (a × c)/(b × d)`
:::

## 2. Les tableaux de signes

::: grille
| Addition | Résultat |
|---|---|
| positif + positif | positif, on additionne les distances |
| négatif + négatif | négatif, on additionne les distances |
| signes différents | on **soustrait** les distances, et on garde le signe du nombre le plus loin de zéro |
:::

::: grille
| Produit ou quotient | Résultat |
|---|---|
| deux signes identiques | **positif** |
| deux signes différents | **négatif** |
| plusieurs facteurs, nombre pair de `-` | **positif** |
| plusieurs facteurs, nombre impair de `-` | **négatif** |
:::

## 3. La méthode du dénominateur commun

::: methode En quatre gestes
::: etapes
1. Le plus grand dénominateur est-il dans la **table** du plus petit ? Si oui, c'est lui le dénominateur commun.
2. Sinon, je prends le **produit** des deux dénominateurs : cela marche toujours.
3. Je transforme chaque fraction : je multiplie son numérateur **et** son dénominateur par le même nombre.
4. J'additionne les numérateurs, je garde le dénominateur, je simplifie.
:::
:::

::: exemple Le geste en une ligne
`3/4 + 5/12` : `12` est dans la table de `4`, donc dénominateur `12`.
`3/4 = 9/12`, donc `9/12 + 5/12 = 14/12 = 7/6`.
:::

## 4. Les mots-clés

::: motscles
- Nombre relatif
- Distance à zéro
- Opposé
- Inverse
- Numérateur
- Dénominateur
- Dénominateur commun
- Simplifier
- Priorités opératoires
:::

::: definition Les cinq mots à ne pas confondre
L'**opposé** de `3/5` est `-3/5`. On change le **signe**.
L'**inverse** de `3/5` est `5/3`. On **retourne** la fraction.
Le **numérateur** est **en haut**.
Le **dénominateur** est **en bas**, c'est lui qui **dénombre** les parts.
**Simplifier** ne change pas la valeur de la fraction, seulement son écriture.
:::

## 5. Les six pièges

::: piege 1. Additionner les dénominateurs
`1/2 + 1/3` ne fait pas `2/5`. Le résultat est `5/6`.
Contrôle : le résultat d'une addition de deux nombres positifs est plus grand que chacun d'eux. `2/5` est plus petit que `1/2` : c'est donc forcément faux.
:::

::: piege 2. Appliquer la règle des signes à une addition
`(-3) + (-4) = -7`, et non `+7`. Deux moins ne donnent un plus que dans un **produit**, un **quotient**, ou une **soustraction** de nombre négatif.
:::

::: piege 3. Retourner la première fraction au lieu de la seconde
Dans `a ÷ b`, c'est `b` qui se retourne. La fraction qui bouge est celle qui **suit** le signe de division.
:::

::: piege 4. Oublier les priorités
`7 - 3 × 6` vaut `-11`, pas `24`. La multiplication passe avant la soustraction, toujours.
:::

::: piege 5. Chercher un dénominateur commun pour multiplier
Inutile. Pour un **produit**, on multiplie directement numérateurs entre eux et dénominateurs entre eux.
:::

::: piege 6. Rendre un résultat non simplifié
`14/12` n'est pas faux, mais ce n'est pas terminé. On attend `7/6`.
:::

## 6. Auto-test

Réponds sans regarder la fiche de cours. Les réponses sont juste en dessous.

::: exercice 1 | application | 8 min | ecran
1. `(-7) + (-5) = ?`
2. `(-12) + (+4) = ?`
3. `(+6) - (-9) = ?`
4. `(-8) × (+3) = ?`
5. `(-36) ÷ (-4) = ?`
6. `2/5 + 1/5 = ?`
7. `1/3 + 1/4 = ?`
8. `2/3 × 6/7 = ?`
9. `5/6 ÷ 2/3 = ?`
10. `10 - 2 × 4 = ?`

::: corrige
1. `-12`. Même signe : on additionne `7 + 5 = 12`, on garde le `-`.
2. `-8`. Signes différents : `12 - 4 = 8`, et le plus loin de zéro est `-12`, donc négatif.
3. `+15`. Soustraire `-9`, c'est ajouter `+9` : `6 + 9 = 15`.
4. `-24`. Signes différents dans un produit : négatif. `8 × 3 = 24`.
5. `+9`. Signes identiques dans un quotient : positif. `36 ÷ 4 = 9`.
6. `3/5`. Même dénominateur : on additionne les numérateurs, `2 + 1 = 3`.
7. `7/12`. Dénominateur commun `12` : `4/12 + 3/12 = 7/12`.
8. `4/7`. `2 × 6 = 12` et `3 × 7 = 21`, soit `12/21`, qui se simplifie par `3` : `4/7`.
9. `5/4`. On multiplie par l'inverse : `5/6 × 3/2 = 15/12`, qui se simplifie par `3` : `5/4`.
10. `2`. La multiplication d'abord : `2 × 4 = 8`, puis `10 - 8 = 2`.
:::
