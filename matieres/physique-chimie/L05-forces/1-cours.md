## 1. Ce qu'une force peut faire

::: definition Action mécanique
Une **action mécanique** est ce qu'exerce un objet sur un autre et qui est capable de :
- le **mettre en mouvement** ou l'**arrêter** ;
- **modifier** son mouvement, en vitesse ou en direction ;
- le **déformer**.
:::

::: definition Force
Une **force** est la modélisation d'une action mécanique. C'est l'outil que le physicien utilise pour décrire cette action par un nombre et une direction.
:::

::: exemple Les trois effets
Un joueur frappe un ballon immobile : il le **met en mouvement**.
Un gardien arrête un ballon lancé : il l'**arrête**.
Un joueur dévie un ballon de la tête : il **modifie la direction** du mouvement.
Un pied enfonce le ballon au moment du contact : il le **déforme**.

Une même action peut produire plusieurs de ces effets à la fois.
:::

::: retenir Une force a toujours deux objets
Une force n'existe jamais seule : il y a toujours un objet qui l'**exerce** et un objet qui la **subit**.
On la nomme donc toujours ainsi : « force exercée par **A** sur **B** ».
:::

## 2. Action de contact, action à distance

::: grille
| Type d'action | Définition | Exemples |
|---|---|---|
| **De contact** | les deux objets se touchent | pousser, tirer, frotter, soutenir |
| **À distance** | les objets ne se touchent pas | gravitation, magnétisme, électricité |
:::

::: exemple Six actions à classer
La main qui pousse une porte : **contact**.
La Terre qui attire une pomme : **distance**.
Un aimant qui attire un trombone : **distance**.
Le sol qui soutient une table : **contact**.
L'air qui freine un cycliste : **contact**.
La Terre qui retient la Lune : **distance**.
:::

::: piege L'air est un contact
On oublie souvent que l'air touche les objets. La résistance de l'air est donc une action **de contact**, même si elle est invisible.
De même, l'eau exerce une action de contact sur un nageur.
:::

::: info Les trois interactions à distance du programme
La **gravitation** : tous les objets qui ont une masse s'attirent.
Le **magnétisme** : les aimants attirent le fer, le nickel, le cobalt.
L'**électricité** : les charges électriques s'attirent ou se repoussent.
Ces trois actions traversent le vide, ce que ne peut faire aucune action de contact.
:::

## 3. Inventorier les actions sur un objet

::: methode Faire le bilan des actions
::: etapes
1. Je choisis clairement l'**objet d'étude**, et je l'entoure mentalement.
2. Je cherche tous les objets qui le **touchent** : ce sont les actions de contact.
3. Je cherche les actions **à distance**, en pratique presque toujours le poids.
4. Je dresse un **tableau** : qui exerce, sur quoi, de quel type.
:::
:::

::: exemple Un livre posé sur une table
Objet d'étude : le livre.

| Action exercée par | Type | Nom |
|---|---|---|
| La **Terre** | à distance | le poids |
| La **table** | contact | la réaction du support |

Il n'y a que **deux** actions : le livre ne touche que la table, et la seule action à distance notable est celle de la Terre.
:::

::: piege Ne pas mélanger les objets
Dans l'exemple du livre, la force exercée par le livre **sur la table** existe aussi, mais elle ne figure pas dans le bilan.
Un bilan recense uniquement les forces qui s'exercent **sur l'objet d'étude**, jamais celles qu'il exerce lui-même.
C'est l'erreur la plus fréquente de tout le chapitre.
:::

## 4. Représenter une force

::: definition Représentation d'une force
Une force se représente par une **flèche**, appelée vecteur, qui porte **quatre** informations.
:::

::: formule Les quatre caractéristiques
1. Le **point d'application** : où la force s'exerce, c'est l'origine de la flèche.
2. La **direction** : la droite sur laquelle elle agit, verticale, horizontale, oblique.
3. Le **sens** : vers le haut ou vers le bas, vers la gauche ou la droite, indiqué par la pointe.
4. La **valeur**, ou intensité : mesurée en **newtons**, symbole `N`, représentée par la longueur de la flèche.
:::

::: definition Newton
Le **newton**, de symbole `N`, est l'unité de force.
`1 N` correspond environ au poids d'une masse de `100 g`, soit celui d'une petite pomme.
:::

::: exemple Quelques ordres de grandeur
Le poids d'un téléphone de `200 g` : environ `2 N`.
Le poids d'un élève de `50 kg` : environ `500 N`.
La force nécessaire pour ouvrir une porte : quelques newtons.
La poussée d'un moteur de fusée : plusieurs millions de newtons.
:::

## 5. La masse

::: definition Masse
La **masse** d'un objet est la quantité de matière qu'il contient.
Elle se mesure avec une **balance**, en **kilogrammes**, symbole `kg`.
:::

::: retenir Ce qui caractérise la masse
La masse est une propriété **de l'objet lui-même**.
Elle ne change **pas** selon le lieu : un objet de `2 kg` a une masse de `2 kg` sur Terre, sur la Lune et dans l'espace.
:::

::: exemple Les unités de masse
`1 kg = 1 000 g`
`1 t = 1 000 kg`
`1 g = 1 000 mg`
Un élève pèse typiquement entre `40` et `60 kg`, une voiture environ `1,2 t`.
:::

## 6. Le poids

::: definition Poids
Le **poids** d'un objet est la **force** d'attraction gravitationnelle exercée par un astre sur cet objet.
Il se mesure avec un **dynamomètre**, en **newtons**, symbole `N`.
:::

::: formule Les quatre caractéristiques du poids
**Point d'application** : le centre de gravité de l'objet.
**Direction** : la verticale du lieu.
**Sens** : vers le bas, c'est-à-dire vers le centre de l'astre.
**Valeur** : `P = m × g`.
:::

::: retenir Ce qui caractérise le poids
Le poids **dépend du lieu**. Le même objet a un poids différent sur Terre, sur la Lune ou sur Mars.
C'est une **force**, donc elle se mesure en newtons, jamais en kilogrammes.
:::

::: piege Le langage courant est trompeur
On dit « je pèse 50 kilos », ce qui mélange les deux notions.
En physique, `50 kg` est une **masse**. Le poids correspondant vaut environ `500 N`.
Une balance de salle de bains mesure en réalité un **poids**, puis l'affiche converti en masse, en supposant qu'on est sur Terre.
:::

## 7. La relation entre les deux

::: formule La relation à connaître
`P = m × g`

`P` : le poids, en **newtons** `N`
`m` : la masse, en **kilogrammes** `kg`
`g` : l'intensité de la pesanteur, en **newtons par kilogramme** `N/kg`

Sur Terre, `g ≈ 9,8 N/kg`, que l'on arrondit souvent à `10 N/kg`.
:::

::: formule Les deux formules dérivées
`m = P ÷ g`
`g = P ÷ m`
:::

::: exemple Trois calculs
Un élève de `50 kg` sur Terre : `P = 50 × 9,8 = 490 N`.
Un sac dont le poids vaut `147 N` : `m = 147 ÷ 9,8 = 15 kg`.
Un objet de `2 kg` dont le poids vaut `7,4 N` sur un astre : `g = 7,4 ÷ 2 = 3,7 N/kg`, ce qui correspond à Mars.
:::

::: piege Les unités du résultat
Un poids se donne toujours en **newtons**, une masse toujours en **kilogrammes**.
Écrire « le poids vaut `50 kg` » est une faute de physique, pas une maladresse.
Contrôler l'unité du résultat détecte la quasi-totalité des erreurs de formule.
:::

## 8. Sur la Lune et ailleurs

::: grille
| Astre | `g` en `N/kg` | Poids d'une masse de 60 kg |
|---|---|---|
| **Terre** | 9,8 | 588 N |
| **Lune** | 1,6 | 96 N |
| **Mars** | 3,7 | 222 N |
| **Jupiter** | 24,8 | 1 488 N |
| **Soleil** | 274 | 16 440 N |
:::

::: exemple Le cas de la Lune
Un astronaute et son équipement ont une masse totale de `120 kg`.
Sur Terre : `P = 120 × 9,8 = 1 176 N`.
Sur la Lune : `P = 120 × 1,6 = 192 N`.

Sa **masse** n'a pas changé : il contient toujours la même quantité de matière.
Son **poids** a été divisé par environ six, ce qui explique les déplacements en bonds caractéristiques des images de mission lunaire.
:::

::: piege En apesanteur, la masse ne disparaît pas
Dans une station spatiale, les objets flottent : on parle d'impesanteur.
Leur **masse** est pourtant inchangée. Pousser une caisse de `100 kg` y demande exactement le même effort que sur Terre pour la mettre en mouvement, parce que c'est la masse qui résiste au changement de mouvement.
Ce qui disparaît, c'est la sensation de poids, pas la matière.
:::

## 9. Forces qui se compensent

::: definition Forces qui se compensent
Deux forces se **compensent** si elles ont la **même direction**, des **sens opposés** et la **même valeur**.
Leur effet combiné est alors nul.
:::

::: retenir Le principe d'inertie, énoncé simplement
Si les forces qui s'exercent sur un objet se **compensent**, alors :
l'objet **immobile** reste immobile ;
l'objet en mouvement **continue en ligne droite à vitesse constante**.
:::

::: exemple Trois situations où les forces se compensent
Un livre posé sur une table : poids vers le bas, réaction du support vers le haut, valeurs égales. Le livre reste immobile.
Un parachutiste en chute stabilisée : poids vers le bas, résistance de l'air vers le haut, valeurs égales. Il tombe à **vitesse constante**.
Une voiture à vitesse constante sur une route droite : la poussée du moteur compense exactement les frottements.
:::

::: piege Forces compensées ne veut pas dire immobile
Le parachutiste tombe, parfois vite. Ses forces se compensent pourtant.
Ce qui est nul, ce n'est pas la vitesse : c'est la **variation** de vitesse.
Des forces compensées maintiennent un mouvement, elles ne l'arrêtent pas.
:::

## 10. Forces qui ne se compensent pas

::: retenir La règle
Si les forces ne se compensent **pas**, le mouvement est **modifié** : la vitesse change, ou la direction change, ou les deux.
:::

::: grille
| Situation | Forces | Effet |
|---|---|---|
| Une pomme qui tombe | poids seul, rien ne le compense | la vitesse **augmente** |
| Une voiture qui freine | frottements vers l'arrière, non compensés | la vitesse **diminue** |
| Un ballon dévié de la tête | force du joueur | la **direction** change |
| Un satellite en orbite | attraction terrestre non compensée | la **direction** change en permanence |
:::

::: exemple Le parachutiste, les deux phases
**Au début du saut**, la vitesse est faible, donc la résistance de l'air aussi. Le poids l'emporte largement : les forces ne se compensent pas et la vitesse **augmente**.
**Plus la vitesse augmente**, plus la résistance de l'air augmente. À un moment, elle devient égale au poids : les forces se compensent, et la vitesse devient **constante**. C'est la vitesse limite, environ `200 km/h` en chute libre à plat.
**À l'ouverture du parachute**, la surface augmente brutalement : la résistance de l'air devient bien supérieure au poids, et la vitesse **diminue** fortement, jusqu'à une nouvelle vitesse limite d'environ `20 km/h`.

Trois phases, trois situations de forces différentes. C'est l'exemple le plus complet du chapitre.
:::

::: info Le satellite, un cas contre-intuitif
Un satellite en orbite est en **chute permanente** vers la Terre : la seule force qui s'exerce sur lui est son poids.
S'il ne tombe pas sur nous, c'est qu'il avance assez vite pour que la Terre « se dérobe » sous lui à mesure qu'il tombe.
Sa vitesse est constante en valeur, mais sa **direction change en permanence** : le mouvement est donc bien modifié, exactement comme la règle le prévoit.
:::

## 11. Quelques forces courantes

::: grille
| Force | Exercée par | Direction et sens | Remarque |
|---|---|---|---|
| **Poids** | la Terre | verticale, vers le bas | `P = m × g` |
| **Réaction du support** | le sol, la table | perpendiculaire au support | compense le poids sur un plan horizontal |
| **Tension d'un fil** | le fil | le long du fil | dirigée vers le point d'attache |
| **Frottements** | l'air, le sol, l'eau | opposée au mouvement | freine toujours |
| **Poussée d'un moteur** | le moteur | dans le sens du mouvement | met en mouvement ou maintient |
| **Force magnétique** | un aimant | le long de l'axe des pôles | action à distance |
:::

::: exemple Un objet suspendu à un fil
Objet d'étude : l'objet suspendu.
Deux forces seulement : le **poids**, vertical vers le bas, et la **tension du fil**, verticale vers le haut.
Si l'objet est immobile, ces deux forces se compensent : la tension du fil est égale au poids.
C'est le principe du **dynamomètre**, qui mesure une force en mesurant l'allongement d'un ressort.
:::

::: retenir Les frottements freinent toujours
Une force de frottement est toujours dirigée **dans le sens opposé au mouvement**.
Elle ne peut donc jamais accélérer un objet. C'est pour cela qu'un objet lancé sur une table finit toujours par s'arrêter : rien ne compense les frottements.
:::

## 12. Les pièges à éviter

::: grille
| Piège | Ce qui est faux | Ce qui est juste |
|---|---|---|
| Le bilan des forces | inclure la force exercée **par** l'objet | seules celles qui s'exercent **sur** lui |
| L'air | il n'exerce aucune action | c'est une action **de contact** |
| Poids et masse | ce sont deux mots pour la même chose | l'un est une **force**, l'autre une **quantité de matière** |
| Unités | un poids en kilogrammes | un poids en **newtons** |
| Sur la Lune | la masse diminue | seul le **poids** diminue |
| Impesanteur | la masse disparaît | elle est **inchangée** |
| Forces compensées | l'objet est immobile | il peut avancer à **vitesse constante** |
| Frottements | ils peuvent accélérer | ils s'opposent **toujours** au mouvement |
:::

::: retenir
Trois phrases suffisent à retenir le chapitre.
**Une force a toujours quatre caractéristiques et deux objets : celui qui l'exerce et celui qui la subit.**
**La masse est une quantité de matière en kilogrammes, le poids est une force en newtons.**
**Si les forces se compensent, le mouvement ne change pas ; sinon, il change.**
:::
