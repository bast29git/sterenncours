## Série A : reconnaître et conjuguer

::: exercice 1 | application | 5 min | ecran
Indique le type de chaque phrase : 0, 1 ou 2.

a. `If you mix blue and yellow, you get green.`
b. `If she calls, I will tell her.`
c. `If I were taller, I would play basketball.`
d. `Water freezes if the temperature drops below 0 °C.`
e. `I would buy that jacket if it were cheaper.`
f. `If you finish your homework, you can watch a film.`

::: corrige
a. **Type 0.** Vérité générale, toujours vraie. Le test du `when` fonctionne : `When you mix blue and yellow, you get green.`
b. **Type 1.** `if` + présent, `will` + base verbale. La situation est possible.
c. **Type 2.** `if` + prétérit, `would` + base verbale. Je ne suis pas plus grande.
d. **Type 0.** Loi physique. Le `if` est ici au milieu, donc pas de virgule.
e. **Type 2.** `were` dans la partie `if`, `would` dans le résultat. La veste n'est pas moins chère.
f. **Type 1.** Le résultat est `can`, pas `will`, mais la structure reste `if` + présent avec une situation possible. Le type 1 admet `can`, `may`, `might`, `should` ou un impératif.
:::
:::

::: exercice 2 | application | 8 min | ecran
Complète avec le temps correct.

1. `If it ... (snow) tomorrow, we ... (build) a snowman.`
2. `If you ... (heat) chocolate, it ... (melt).`
3. `If I ... (have) a boat, I ... (sail) to Ouessant.`
4. `She ... (be) happy if you ... (invite) her.`
5. `If they ... (leave) now, they ... (arrive) on time.`
6. `If I ... (know) the answer, I ... (tell) you.`

::: corrige
1. `If it **snows** tomorrow, we **will build** a snowman.` Type 1 : possible.
2. `If you **heat** chocolate, it **melts**.` Type 0 : toujours vrai.
3. `If I **had** a boat, I **would sail** to Ouessant.` Type 2 : je n'ai pas de bateau.
4. `She **will be** happy if you **invite** her.` Type 1. Le `if` est au milieu : pas de virgule.
5. `If they **leave** now, they **will arrive** on time.` Type 1.
6. `If I **knew** the answer, I **would tell** you.` Type 2 : je ne la connais pas. Sous-entendu : donc je ne peux pas te la dire.

**Le contrôle à faire à chaque fois.** Regarde d'abord la partie après le `if` : si elle est au présent, le résultat prend `will` ; si elle est au prétérit, le résultat prend `would`. Les deux parties vont toujours ensemble.
:::
:::

::: exercice 3 | application | 8 min | ecran
Corrige les six phrases. Chacune contient exactement une erreur.

1. `If it will rain, we will cancel the trip.`
2. `If I would have time, I would help you.`
3. `If you heat ice it melts.`
4. `If I was you, I would say no.`
5. `Unless you don't study, you will fail.`
6. `If she would come, I will be happy.`

::: corrige
1. `If it **rains**, we will cancel the trip.` Jamais `will` après `if`.
2. `If I **had** time, I would help you.` Jamais `would` après `if`.
3. `If you heat ice**,** it melts.` La phrase commence par `if` : la virgule est obligatoire.
4. `If I **were** you, I would say no.` À l'écrit scolaire, `were` à toutes les personnes.
5. `Unless you **study**, you will fail.` `unless` contient déjà la négation.
6. `If she **came**, I **would** be happy.` Attention : cette phrase avait deux problèmes liés. Si l'on garde `will`, il faut écrire `If she **comes**, I will be happy` (type 1). Si l'on veut le type 2, il faut `If she came, I would be happy`. Les deux corrections sont acceptables, mais il faut choisir un type et le tenir **des deux côtés**.
:::
:::

::: exercice 4 | application | 5 min | ecran
Relie chaque début à la fin qui convient.

::: grille
| Début | | Fin |
|---|---|---|
| 1. If you press this button, | | a. I would call the police. |
| 2. If you press this button, | | b. the machine stops. |
| 3. If I saw a thief, | | c. I will call you back. |
| 4. If I have time later, | | d. you will break it. |
:::

Certaines fins peuvent convenir à plusieurs débuts : justifie ton choix.

::: corrige
- **1 avec b** : `If you press this button, the machine stops.` Type 0, vérité générale sur le fonctionnement de la machine.
- **2 avec d** : `If you press this button, you will break it.` Type 1, avertissement sur une conséquence future possible.
- **3 avec a** : `If I saw a thief, I would call the police.` Type 2, situation imaginée.
- **4 avec c** : `If I have time later, I will call you back.` Type 1.

**Ce que montre le doublon 1 et 2.** Les deux débuts sont identiques au mot près : c'est la **fin** qui décide du type. Le même `if you press this button` peut annoncer une règle de fonctionnement (type 0) ou un avertissement (type 1). Le type n'est jamais dans le `if` seul : il se lit sur la phrase entière.
:::
:::

::: exercice 5 | application | 8 min | ecran
Complète avec `will`, `would`, `can` ou `might`, selon le sens indiqué entre parenthèses.

1. `If you ask him, he ... help you.` (prédiction neutre)
2. `If you ask him, he ... help you.` (c'est possible, sans certitude)
3. `If you finish early, you ... go out.` (permission)
4. `If I spoke Italian, I ... work in Rome.` (capacité imaginée)
5. `If I won the lottery, I ... buy a house.` (résultat imaginé)

::: corrige
1. `he **will** help you.` Prédiction neutre : `will`.
2. `he **might** help you.` Possibilité : `might`, ou `may`.
3. `you **can** go out.` Permission : `can`.
4. `I **could** work in Rome.` Capacité imaginée : `could`, forme de `can` au conditionnel. Ici `would` serait aussi accepté, mais `could` rend mieux l'idée de capacité.
5. `I **would** buy a house.` Résultat imaginé : `would`.

**Ce qu'il faut retenir.** Le résultat d'un type 1 n'est pas obligatoirement `will`, et celui d'un type 2 pas obligatoirement `would`. Ce qui fixe le type, c'est le temps de la partie `if` : présent pour le type 1, prétérit pour le type 2.
:::
:::

::: exercice 6 | application | 5 min | ecran
Vrai ou faux ? Justifie chaque réponse en une phrase.

1. On peut mettre `will` après `if`.
2. `If I were you` est correct à toutes les personnes.
3. La virgule est obligatoire quand la phrase commence par `if`.
4. Le prétérit du conditional 2 parle du passé.

::: corrige
1. **Faux.** Le `if` absorbe le futur : on écrit `if it rains`, jamais `if it will rain`. Le français fait exactement pareil.
2. **Vrai.** Au conditional 2, `be` se met à `were` à toutes les personnes : `if I were`, `if he were`, `if it were`.
3. **Vrai.** `If you come, I will be happy.` Quand le `if` est au milieu, il n'y a pas de virgule.
4. **Faux.** Il marque la **distance avec le réel**, pas le passé, exactement comme l'imparfait français dans « si j'avais ».
:::
:::

Fin de la série A. Six exercices faits. Reprends dans un moment.

## Série B : virgule, were, unless, choix du type

::: exercice 7 | entrainement | 8 min | ecran
Réécris chaque phrase dans l'autre sens, en adaptant la ponctuation.

1. `If you come early, we will have time to talk.`
2. `I will help you if you ask me.`
3. `If I were rich, I would buy a boat.`
4. `The ice melts if you leave it in the sun.`

::: corrige
1. `We will have time to talk if you come early.` La virgule disparaît.
2. `If you ask me, I will help you.` La virgule apparaît.
3. `I would buy a boat if I were rich.` La virgule disparaît.
4. `If you leave it in the sun, the ice melts.` La virgule apparaît.

**La règle en une ligne.** La virgule ne dépend ni du type ni du sens : elle dépend uniquement de la **position du `if`**. En tête de phrase, virgule ; au milieu, pas de virgule.
:::
:::

::: exercice 8 | entrainement | 10 min | ecran
Donne un conseil avec `If I were you, I would...` pour chacune de ces situations.

1. `My phone is broken.`
2. `I have a test tomorrow and I haven't studied.`
3. `I argued with my best friend.`
4. `I am always tired in the morning.`
5. `I don't understand this exercise.`

::: corrige
1. `If I were you, I would take it to a repair shop.`
2. `If I were you, I would start revising tonight instead of watching television.`
3. `If I were you, I would apologise and talk to her.`
4. `If I were you, I would go to bed earlier and leave my phone in another room.`
5. `If I were you, I would ask the teacher tomorrow morning.`

**Les trois points à vérifier dans chacune de tes réponses.**
- `were` et non `was`.
- La virgule après `you`.
- `would` suivi de la **base verbale** sans `to` : `I would take`, jamais `I would to take`.
:::
:::

::: exercice 9 | entrainement | 8 min | ecran
Transforme chaque phrase en employant `unless`.

1. `If you don't leave now, you will be late.`
2. `I won't come if you don't invite me.`
3. `If she doesn't apologise, I won't talk to her.`
4. `We will go out if it doesn't rain.`

::: corrige
1. `**Unless** you leave now, you will be late.`
2. `I won't come **unless** you invite me.`
3. `**Unless** she apologises, I won't talk to her.`
4. `We will go out **unless** it rains.`

**Le mécanisme.** `unless` = `if... not`. On supprime donc la négation de la partie `if`, et le reste de la phrase ne change pas. L'erreur la plus fréquente consiste à garder la négation, ce qui inverse le sens : `unless you don't leave` signifierait « sauf si tu ne pars pas ».
:::
:::

::: exercice 10 | entrainement | 8 min | ecran
Choisis entre `if` et `in case`, puis explique ta réponse en une phrase.

1. `Take your umbrella ... it rains.`
2. `... it rains, I will take my umbrella.`
3. `Save your document ... the computer crashes.`
4. `... you see her, tell her to call me.`

::: corrige
1. `Take your umbrella **in case** it rains.` Tu prends le parapluie **maintenant**, par précaution, sans savoir s'il pleuvra.
2. `**If** it rains, I will take my umbrella.` Tu ne le prendras **que** s'il pleut : l'action dépend de la condition.
3. `Save your document **in case** the computer crashes.` On sauvegarde **avant** et sans attendre la panne, c'est une précaution.
4. `**If** you see her, tell her to call me.` L'action, transmettre le message, n'a lieu que si la condition est réalisée.

**La règle pour trancher.** Avec `if`, l'action a lieu **après** et **seulement si** la condition se réalise. Avec `in case`, l'action a lieu **avant**, pour se protéger d'une éventualité.
:::
:::

::: exercice 11 | entrainement | 10 min | ecran
Complète avec le mot qui convient : `unless`, `as long as`, `in case`, `even if`.

1. `You can borrow my bike ... you bring it back before six.`
2. `I will go to the beach ... it is cold.`
3. `Take some water with you ... you get thirsty.`
4. `We won't finish on time ... everybody helps.`
5. `You can stay ... you are quiet.`

::: corrige
1. `You can borrow my bike **as long as** you bring it back before six.` Condition à respecter.
2. `I will go to the beach **even if** it is cold.` Le froid ne change pas ma décision.
3. `Take some water with you **in case** you get thirsty.` Précaution prise maintenant.
4. `We won't finish on time **unless** everybody helps.` = si tout le monde n'aide pas.
5. `You can stay **as long as** you are quiet.` Condition à respecter.

**Le tri en une phrase.** `as long as` et `provided that` posent une condition à respecter ; `unless` dit « sauf si » ; `in case` dit « par précaution » ; `even if` dit que la condition ne change rien.
:::
:::

::: exercice 12 | entrainement | 10 min | ecran
Pour chaque situation, écris une phrase hypothétique du type qui convient, et indique le type choisi.

1. Tu expliques que le chocolat fond quand on le chauffe.
2. Tu préviens un ami qu'il va rater son bus s'il ne se dépêche pas.
3. Tu imagines ce que tu ferais avec un million d'euros.
4. Tu dis ce que tu feras s'il fait beau samedi.
5. Tu expliques que tu habiterais au bord de la mer si tu pouvais choisir.

::: corrige
1. `If you heat chocolate, it melts.` **Type 0** : vérité générale.
2. `If you don't hurry, you will miss your bus.` **Type 1** : situation réelle et possible. On accepte aussi `Unless you hurry, you will miss your bus.`
3. `If I had a million euros, I would travel around the world.` **Type 2** : je n'ai pas cette somme.
4. `If the weather is nice on Saturday, I will go to the beach.` **Type 1**.
5. `If I could choose, I would live by the sea.` **Type 2** : je ne peux pas choisir aujourd'hui.

**Le contrôle.** Relis chaque phrase et demande-toi si le type choisi dit bien ce que tu voulais dire. Écrire `If I had a million euros` indique clairement que tu ne l'as pas ; écrire `If I have a million euros` laisserait entendre que c'est une possibilité réelle.
:::
:::

::: exercice 13 | entrainement | 10 min | main
Lis ce dialogue et complète les cinq trous.

> **A.** I'm tired of the city.
> **B.** Where ... (live) you if you ... (can) choose?
> **A.** If I ... (can) choose, I ... (live) by the sea.
> **B.** If I ... (be) you, I would go there next summer.
> **A.** If I ... (save) enough money, I ... (go) in July.

Puis explique pourquoi la dernière réplique change de type.

::: corrige
**Le dialogue complété.**

> **A.** I'm tired of the city.
> **B.** Where **would you live** if you **could** choose?
> **A.** If I **could** choose, I **would live** by the sea.
> **B.** If I **were** you, I would go there next summer.
> **A.** If I **save** enough money, I **will go** in July.

**Pourquoi la dernière réplique change de type.**
Les trois premières répliques sont au **type 2** : elles décrivent une situation imaginaire, puisque A ne peut pas choisir où vivre aujourd'hui.
La dernière passe au **type 1** parce que A parle désormais d'un projet **réalisable** : économiser de l'argent et partir en juillet est possible.
Ce glissement du type 2 au type 1 signale le passage du **rêve** au **projet**. C'est un effet de sens très utile : sans changer un seul mot de vocabulaire, le changement de type fait comprendre que la conversation vient de devenir concrète.
:::
:::

## Série C : traduction, transformation, rédaction

::: exercice 14 | approfondissement | 10 min | main
Traduis en anglais.

1. Si tu arrives avant sept heures, nous irons au cinéma.
2. Si j'étais toi, je lui téléphonerais.
3. Si on laisse de la glace au soleil, elle fond.
4. Si j'avais une voiture, je te conduirais à la gare.
5. Je ne viendrai pas si tu ne m'invites pas.

::: corrige
1. `If you arrive before seven, we will go to the cinema.` Type 1. Virgule après `seven`.
2. `If I were you, I would call her.` Type 2. `were`, virgule, `would` + base verbale.
3. `If you leave ice in the sun, it melts.` Type 0 : c'est toujours vrai.
4. `If I had a car, I would drive you to the station.` Type 2.
5. `I won't come if you don't invite me.` Type 1, `if` au milieu donc pas de virgule. On accepte aussi `I won't come unless you invite me.`

**Les trois vérifications à faire sur une traduction.**
- Le temps après `if` : présent pour 0 et 1, prétérit pour 2.
- L'absence de `will` et de `would` après `if`.
- La virgule, présente si la phrase commence par `if`, absente sinon.
:::
:::

::: exercice 15 | approfondissement | 10 min | main
Traduis en anglais. Attention : les cinq phrases ne sont pas du même type.

1. Si l'eau gèle, elle prend plus de place.
2. Si je parlais espagnol, je travaillerais à Madrid.
3. Si tu as faim, prends une pomme.
4. Prends un manteau au cas où il ferait froid.
5. Nous sortirons sauf s'il pleut.

::: corrige
1. `If water freezes, it takes up more space.` **Type 0** : loi physique.
2. `If I spoke Spanish, I would work in Madrid.` **Type 2** : je ne parle pas espagnol.
3. `If you are hungry, take an apple.` **Type 1** avec un **impératif** comme résultat. Le type 1 n'impose pas `will`.
4. `Take a coat in case it is cold.` Construction avec `in case` : l'action est immédiate, la précaution vaut pour une éventualité.
5. `We will go out unless it rains.` `unless` remplace `if... not`.

**La difficulté de cet exercice.** Le français ne signale pas toujours le type par le temps employé : « si tu as faim » et « si tu avais faim » se ressemblent à l'oreille. Le repère fiable est le **sens** : est-ce réel, possible, ou imaginaire ?
:::
:::

::: exercice 16 | approfondissement | 10 min | ecran
Voici cinq phrases correctes en anglais. Pour chacune, explique ce qu'elle dit de la réalité.

1. `If I have time tonight, I will call you.`
2. `If I had time tonight, I would call you.`
3. `If she is at home, she will answer.`
4. `If she were at home, she would answer.`
5. `If you touch that wire, you get an electric shock.`

::: corrige
1. Le locuteur a une **chance réelle** d'avoir du temps ce soir. Il ne promet pas, mais il n'exclut rien.
2. Le locuteur sait déjà qu'il **n'aura pas** de temps. La phrase est presque une excuse : elle explique pourquoi il n'appellera pas.
3. Le locuteur **ignore** si elle est chez elle. C'est une hypothèse ouverte.
4. Le locuteur sait qu'elle **n'est pas** chez elle. Souvent, la phrase sert à conclure quelque chose : elle ne répond pas, donc elle n'est pas là.
5. Vérité **générale** : cela se produit à chaque fois, pour tout le monde. C'est un avertissement de portée universelle, pas une prédiction sur une personne.

**Ce que montre la comparaison 1 et 2, puis 3 et 4.** Les phrases sont identiques au temps près, et pourtant elles disent l'inverse l'une de l'autre sur la réalité. Le choix du type n'est donc pas un détail de grammaire : c'est **l'information principale** de la phrase.
:::
:::

::: exercice 17 | approfondissement | 12 min | main
Écris cinq phrases personnelles, une de chaque catégorie.

1. Une vérité générale sur toi (type 0).
2. Un projet réel pour le week-end prochain (type 1).
3. Un rêve (type 2).
4. Un conseil à une amie (avec `If I were you`).
5. Une précaution (avec `in case`).

::: corrige
**Cinq exemples possibles. Les tiennes seront différentes, ce qui compte est la structure.**

1. `If I go to bed late, I am tired all day.` Type 0 : cela se produit à chaque fois.
2. `If the weather is nice on Saturday, I will go for a walk with my dog.` Type 1 : projet réalisable.
3. `If I could live anywhere, I would live in a house by the sea.` Type 2 : imaginaire.
4. `If I were you, I would talk to her before the weekend.` Conseil.
5. `I will take my charger with me in case my phone runs out of battery.` Précaution.

**Grille pour t'auto-corriger.**
- Phrase 1 : les deux verbes au présent, aucun `will`.
- Phrase 2 : présent après `if`, `will` dans le résultat, virgule si la phrase commence par `if`.
- Phrase 3 : prétérit après `if`, `would` dans le résultat.
- Phrase 4 : `were`, virgule, `would` + base verbale sans `to`.
- Phrase 5 : `in case` suivi d'un verbe au **présent**, jamais de `will`.
:::
:::

::: exercice 18 | approfondissement | 12 min | main
Rédige un paragraphe de **six à huit phrases** sur le sujet suivant :

`Screens and sleep: what happens, what you can do, and what you would do in an ideal world.`

Ton texte doit contenir au moins **un type 0**, **deux types 1**, **deux types 2** et un conseil avec `If I were you`.

::: corrige
**Un paragraphe possible parmi d'autres.**

> If teenagers use their phones late at night, they sleep badly. *(type 0)*
> If I stop looking at my screen after ten o'clock, I will feel much better in the morning. *(type 1)*
> If I put my phone in another room, I will not check it every ten minutes. *(type 1)*
> If I had no phone at all, I would probably read more books. *(type 2)*
> If my friends sent fewer messages at night, I would sleep longer. *(type 2)*
> If I were you, I would try it for one week and see what happens. *(conseil)*
> It is not easy, but it works.

**Grille pour t'auto-corriger.**
- Les six structures demandées sont présentes et repérables.
- Aucun `will` ni `would` n'apparaît après un `if`.
- Chaque phrase commençant par `If` porte une virgule.
- `were` est employé avec `If I were you`.
- Le texte fait entre six et huit phrases et reste compréhensible de bout en bout.

**Le conseil de méthode.** Écris d'abord tes phrases en français, note le type de chacune, puis traduis. Tu éviteras ainsi de choisir un type par hasard au moment de la rédaction.
:::
:::

::: exercice 19 | approfondissement | 12 min | main
Prépare une prise de parole de **une minute** répondant à cette question :

`What would you do if you could change one thing about your school?`

Prépare **six phrases** : deux au type 2 pour dire ce que tu changerais, deux au type 1 pour dire ce qui est réellement possible, une avec `unless` ou `as long as`, et une phrase de conclusion.

::: corrige
**Une préparation possible parmi d'autres.**

> If I could change one thing about my school, I would change the timetable. *(type 2)*
> If lessons started at nine instead of eight, students would be much more awake. *(type 2)*
> If we asked the head teacher, he will probably say that it is complicated. *(attention, voir la remarque)*
> If we write a clear proposal, we will at least get an answer. *(type 1)*
> It would work as long as the buses changed their times too. *(condition)*
> So the real question is not what I would like, but what we can actually try. *(conclusion)*

**Attention à la troisième phrase.** Telle qu'elle est écrite, elle mélange un `if` + prétérit avec `will`, ce qui est fautif. Deux corrections possibles :
- type 1 : `If we ask the head teacher, he will probably say that it is complicated.`
- type 2 : `If we asked the head teacher, he would probably say that it is complicated.`
Il faut choisir, et tenir le même type **des deux côtés** de la virgule. C'est l'erreur la plus fréquente à l'oral, parce qu'on construit la fin de la phrase après avoir commencé le début.

**Conseils pour l'oral.**
- Utilise les contractions : `I'd`, `we'd`, `wouldn't`, `we'll`.
- Marque une petite pause à la virgule : elle s'entend.
- Prépare tes six phrases par écrit, puis parle **sans lire**, en t'appuyant seulement sur six mots-clés notés sur une ligne.
:::
:::

## Exercice 20 : sujet de type devoir

::: exercice 20 | approfondissement | 45 min | main
**Durée : 45 minutes. Barème sur 20 points.**

### Part A: recognise the type, sur 4 points

Indique le type de chaque phrase : 0, 1 ou 2. *(0,5 point par item)*

1. `If you drop a glass, it breaks.`
2. `If he calls, I will answer.`
3. `If I were you, I would wait.`
4. `Ice melts if you put it in the sun.`
5. `If we left now, we would arrive before dark.`

### Part A, sur 4 points

1. **Type 0.** Vérité générale.
2. **Type 1.** `if` + présent, `will`.
3. **Type 2.** `were`, `would`.
4. **Type 0.** `if` au milieu, pas de virgule.
5. **Type 2.** `left` est un prétérit, `would` dans le résultat.
6. **Type 1.** Le résultat est `can`, mais la condition reste réalisable.
7. **Type 2.** Je ne parle pas chinois.
8. **Type 1.** La neige est possible.

### Part B, sur 6 points

1. `If it **is** sunny tomorrow, we **will go** to the beach.` *(0,5 par verbe.)*
2. `If you **mix** red and white, you **get** pink.` Type 0.
3. `If I **had** more time, I **would learn** the guitar.` Type 2.
4. `She **will call** you if she **needs** help.` Type 1, pas de virgule.
5. `If I **were** you, I **would accept** the offer.` Type 2, `were` obligatoire à l'écrit.
6. `If they **don't hurry**, they **will miss** the train.` Type 1.

### Part C, sur 5 points

1. `If it **is** cold, I will stay at home.` **Jamais `will` après `if`.**
2. `If I **had** a bike, I would ride to school.` **Jamais `would` après `if`.**

5. `Unless you **call** me, I won't come.` **`unless` contient déjà la négation.**
