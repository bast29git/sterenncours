## 1. Ce qu'est une phrase hypothétique

::: definition Phrase hypothétique
Une **phrase hypothétique** comporte deux parties : une **condition**, introduite par `if`, et un **résultat**.
On les appelle en anglais la `if-clause` et la `main clause`.
:::

::: formule La forme générale

```
if + condition  ,  résultat
résultat  if + condition
```

L'ordre est libre. Ce qui change, c'est uniquement la **ponctuation**, que nous verrons au point 5.
:::

::: retenir Trois types, trois usages
Le choix du type ne dépend pas du temps grammatical français, mais de ce que la phrase **dit du réel**.

1. **Conditional 0** : c'est toujours vrai.
2. **Conditional 1** : c'est possible, cela peut arriver.
3. **Conditional 2** : ce n'est pas le cas, j'imagine.
:::

::: aide La question à se poser
Avant de choisir, demande-toi : **est-ce que cela peut réellement arriver ?**
Oui, toujours → type 0. Oui, peut-être → type 1. Non, c'est imaginaire → type 2.
:::

## 2. Conditional 0 : les vérités générales

::: formule La structure

```
if + present simple  ,  present simple
```
:::

::: exemple Des vérités qui ne changent pas
- `If you heat water to 100 °C, it boils.` Si on chauffe l'eau à 100 °C, elle bout.
- `If it rains, the ground gets wet.` S'il pleut, le sol devient mouillé.
- `Plants die if you don't water them.` Les plantes meurent si on ne les arrose pas.
:::

::: retenir Ce que le type 0 exprime
Une **loi générale**, une habitude, une règle automatique. Le résultat se produit **à chaque fois**, sans exception.
C'est pourquoi on peut presque toujours remplacer `if` par `when` sans changer le sens.
:::

::: aide Le test du `when`

```
If you heat ice, it melts.
When you heat ice, it melts.     ← même sens : c'est bien un type 0
```

Si le remplacement par `when` fonctionne, tu es dans le conditional 0.
:::

::: exemple Des règles personnelles
- `If I drink coffee at night, I can't sleep.` Si je bois du café le soir, je n'arrive pas à dormir.
- `My dog barks if someone rings the bell.` Mon chien aboie si quelqu'un sonne.

Ce ne sont pas des lois de la physique, mais des régularités : le type 0 convient.
:::

## 3. Conditional 1 : le réel à venir

::: formule La structure

```
if + present simple  ,  will + base verbale
```

Jamais `will` dans la partie `if`.
:::

::: exemple Des situations possibles
- `If it rains tomorrow, we will stay at home.` S'il pleut demain, nous resterons à la maison.
- `If you study, you will pass the test.` Si tu travailles, tu réussiras le contrôle.
- `She will be angry if you are late.` Elle sera fâchée si tu es en retard.
:::

::: piege Le faux ami du futur français
En français, on dit « si je **viendrai** » ? Non, on dit « si je **viens** ». L'anglais suit exactement la même logique :

```
❌ If it will rain, we will stay at home.
✅ If it rains, we will stay at home.
```

Le français et l'anglais font ici la **même chose**. C'est plus facile qu'il n'y paraît.
:::

::: grille
| Variante du résultat | Valeur | Exemple |
|---|---|---|
| `will` | prédiction neutre | `If you ask, he will help you.` |
| `may` ou `might` | possibilité | `If you ask, he might help you.` |
| `can` | capacité | `If you finish early, you can go out.` |
| impératif | consigne | `If you see her, tell her to call me.` |
| `must` ou `should` | obligation, conseil | `If you feel sick, you should rest.` |
:::

::: retenir Le type 1 n'est pas réservé au futur
Le résultat peut être un conseil, un ordre ou une permission. Ce qui compte est que la condition reste **réalisable**.
:::

## 4. Conditional 2 : l'imaginaire

::: formule La structure

```
if + past simple  ,  would + base verbale
```

Jamais `would` dans la partie `if`.
:::

::: exemple Des situations irréelles
- `If I had a million euros, I would travel the world.` Si j'avais un million d'euros, je voyagerais dans le monde entier.
- `If I were you, I would apologise.` Si j'étais toi, je m'excuserais.
- `She would be happier if she lived by the sea.` Elle serait plus heureuse si elle vivait au bord de la mer.
:::

::: retenir Le prétérit ne dit pas le passé ici
Dans `If I had a million euros`, le prétérit `had` ne parle **pas du passé**. Il marque la **distance avec le réel** : je n'ai pas cette somme.
C'est exactement ce que fait l'imparfait français dans « si j'avais » : lui non plus ne parle pas du passé.
:::

::: aide La correspondance avec le français

```
anglais :  if + prétérit      →  would + base verbale
français : si + imparfait     →  conditionnel présent
```

`If I had time, I would come.` → Si j'**avais** le temps, je **viendrais**.
:::

::: grille
| Variante du résultat | Valeur | Exemple |
|---|---|---|
| `would` | résultat imaginé | `If I won, I would celebrate.` |
| `could` | capacité imaginée | `If I spoke Spanish, I could work there.` |
| `might` | possibilité imaginée | `If she asked, he might say yes.` |
:::

## 5. L'ordre des propositions et la virgule

::: formule La règle de la virgule

```
if + condition  ,  résultat        ← virgule obligatoire
résultat  if + condition           ← pas de virgule
```
:::

::: exemple La même phrase dans les deux sens
- `If you come early, we will have time to talk.`
- `We will have time to talk if you come early.`

Le sens est identique. Seule la ponctuation change.
:::

::: aide Pourquoi cette règle existe
La virgule signale que la phrase a commencé par une **subordonnée**. Quand la subordonnée est à la fin, le lecteur n'a pas besoin de ce signal : la virgule disparaît.
C'est une règle mécanique : tu n'as pas à réfléchir au sens, seulement à la position du `if`.
:::

::: piege L'erreur la plus fréquente à l'écrit
Oublier la virgule quand la phrase **commence** par `if`. C'est une faute comptée en évaluation, alors qu'elle est entièrement évitable : dès que tu écris `If` en début de phrase, place mentalement la virgule avant de continuer.
:::

## 6. Le cas de `were`

::: formule La règle

```
au conditional 2, be se met à were à TOUTES les personnes
```
:::

::: grille
| Personne | Forme attendue |
|---|---|
| `I` | `if I were` |
| `you` | `if you were` |
| `he`, `she`, `it` | `if he were`, `if she were`, `if it were` |
| `we`, `they` | `if we were`, `if they were` |
:::

::: exemple L'expression à connaître par cœur
`If I were you, I would...` Si j'étais toi, je...

C'est la façon la plus courante de donner un conseil en anglais. Apprends-la comme un bloc.
:::

::: info Ce que tu entendras aussi
Dans l'anglais parlé courant, `if I was` s'entend très souvent et n'est pas considéré comme une faute à l'oral. En **écriture scolaire**, on attend `were` : c'est la forme correcte et c'est celle qui est évaluée.
:::

::: exemple Trois conseils avec `were`
- `If I were you, I would talk to her.`
- `If I were in your position, I would wait.`
- `If he were more careful, he would make fewer mistakes.`
:::

## 7. Jamais de `will` ni de `would` après `if`

::: formule La règle qui évite la moitié des fautes

```
❌ if + will       ❌ if + would
✅ if + présent    ✅ if + prétérit
```
:::

::: exemple Les corrections
- ❌ `If you will come, I will be happy.` → ✅ `If you come, I will be happy.`
- ❌ `If I would have money, I would buy it.` → ✅ `If I had money, I would buy it.`
:::

::: aide Une image pour retenir
Le `if` **absorbe** le futur et le conditionnel. Il ne les laisse jamais entrer dans sa partie de phrase : ils restent de l'autre côté de la virgule.
:::

::: info Une exception rare, à connaître seulement
`If you will follow me, please` existe, mais `will` y exprime la **politesse**, pas le futur : c'est l'équivalent de « si vous voulez bien me suivre ». Cette tournure est réservée à un registre très formel. En 4ème, tu peux considérer la règle comme absolue.
:::

## 8. Les alternatives à `if`

::: grille
| Mot | Sens | Exemple |
|---|---|---|
| `unless` | sauf si, à moins que | `I won't go unless you come with me.` |
| `as long as` | à condition que | `You can borrow it as long as you return it.` |
| `provided that` | à condition que, plus formel | `We will start provided that everyone is ready.` |
| `in case` | au cas où | `Take an umbrella in case it rains.` |
| `even if` | même si | `I will go even if it rains.` |
:::

::: retenir `unless` contient déjà la négation
`unless` signifie `if... not`. On ne met donc **pas** de négation derrière.

```
❌ unless you don't come
✅ unless you come        = if you don't come
```
:::

::: exemple La transformation
- `If you don't hurry, you will miss the bus.`
- `Unless you hurry, you will miss the bus.`

Les deux phrases disent la même chose.
:::

::: piege `in case` n'est pas `if`
`If it rains, I will take an umbrella.` : je prends le parapluie **seulement s'il pleut**.
`I will take an umbrella in case it rains.` : je le prends **maintenant**, par précaution, au cas où.
La différence est réelle et souvent testée.
:::

Fin de la séance 2. Quatre points vus : la virgule, `were`, l'interdiction de `will` et `would`, les alternatives à `if`.

## 9. Choisir le bon type

::: methode Comment choisir en trois secondes
1. La phrase décrit-elle quelque chose qui arrive **toujours** ? → **type 0**.
2. Décrit-elle quelque chose qui **peut arriver** ? → **type 1**.
3. Décrit-elle quelque chose qui **n'est pas le cas** ? → **type 2**.
:::

::: grille
| Situation | Type | Exemple |
|---|---|---|
| L'eau bout à 100 °C | **0** | `If you heat water to 100 °C, it boils.` |
| Il pleuvra peut-être demain | **1** | `If it rains tomorrow, we will stay in.` |
| Je ne suis pas millionnaire | **2** | `If I were rich, I would buy a boat.` |
| Je bois du café tous les soirs | **0** | `If I drink coffee, I can't sleep.` |
| Tu travailles peut-être ce soir | **1** | `If you work tonight, you will succeed.` |
| Je ne parle pas japonais | **2** | `If I spoke Japanese, I would live in Tokyo.` |
:::

::: exemple La même situation, deux types
- `If I have time tonight, I will call you.` → j'ai une chance réelle d'avoir du temps.
- `If I had time tonight, I would call you.` → je sais déjà que je n'en aurai pas.

Le choix du type **change le message**. Ce n'est pas une question de style.
:::

::: aide Une erreur de type est une erreur de sens
Dire `If I were tired, I would go to bed` alors que tu es réellement fatiguée fait comprendre à ton interlocuteur que tu ne l'es **pas**. C'est pourquoi ce point compte davantage qu'une simple règle de grammaire.
:::

## 10. Les emplois courants du conditional 2

::: grille
| Emploi | Formule | Exemple |
|---|---|---|
| Donner un conseil | `If I were you, I would...` | `If I were you, I would apologise.` |
| Rêver, imaginer | `If I had..., I would...` | `If I had a garden, I would grow vegetables.` |
| Exprimer un regret sur le présent | `If I..., I would...` | `If I lived closer, I would see you more often.` |
| Demander poliment | `Would you mind...?` | `Would you mind opening the window?` |
| Se projeter | `What would you do if...?` | `What would you do if you won the lottery?` |
:::

::: exemple Un dialogue complet
> **A.** I'm so tired of this town.
> **B.** Where would you live if you could choose?
> **A.** If I could choose, I would live by the sea.
> **B.** If I were you, I would go there next summer at least.
> **A.** If I save enough money, I will go in July.

Remarque la dernière réplique : on passe au **type 1**, parce que l'économie d'argent est un projet **réel**.
:::

::: retenir Le glissement du type 2 vers le type 1
Passer du type 2 au type 1 dans une conversation signale que l'on passe du **rêve** au **projet**. C'est un effet de sens très utile à l'oral comme à l'écrit.
:::

## 11. Rédiger et parler

::: methode Structurer un paragraphe avec des hypothèses
1. **Poser** une situation générale avec un type 0.
2. **Envisager** une suite réelle avec un type 1.
3. **Imaginer** une autre possibilité avec un type 2.
4. **Conclure** par un conseil avec `If I were...`.
:::

::: exemple Un paragraphe modèle
> If people use their phone late at night, they sleep badly. *(type 0)*
> If I stop using mine after ten, I will feel better in the morning. *(type 1)*
> If I had no phone at all, I would probably read more books. *(type 2)*
> If I were you, I would leave it in another room at night. *(conseil)*

Quatre phrases, trois types, un conseil final. C'est exactement ce qu'on attend en 4ème.
:::

::: grille
| Formule utile à l'oral | Traduction |
|---|---|
| `What would you do if...?` | Que ferais-tu si... ? |
| `I would rather...` | Je préférerais... |
| `It would be better if...` | Ce serait mieux si... |
| `In that case, I would...` | Dans ce cas, je... |
| `Otherwise, I will...` | Sinon, je... |
:::

::: aide Prononciation : les formes contractées
- `I would` se dit souvent `I'd`.
- `he would` se dit `he'd`, `they would` se dit `they'd`.
- `would not` se dit `wouldn't`.
- `I will` se dit `I'll`, `will not` se dit `won't`.

Entraîne-toi à dire `If I were you, I'd wait` d'une seule traite : c'est ainsi qu'on l'entend réellement.
:::

## 12. Les pièges à éviter

::: piege 1. `will` après `if`
❌ `If it will rain` → ✅ `If it rains`. Le français fait pareil : on ne dit pas « s'il pleuvra ».
:::

::: piege 2. `would` après `if`
❌ `If I would have money` → ✅ `If I had money`.
:::

::: piege 3. La virgule oubliée
Quand la phrase commence par `if`, la virgule est **obligatoire** avant le résultat.
:::

::: piege 4. `was` au lieu de `were`
À l'écrit scolaire, on attend `if I were`, `if he were`, à toutes les personnes.
:::

::: piege 5. Le prétérit pris pour du passé
Dans `if I had a car`, `had` marque la **distance avec le réel**, pas le passé. Comme l'imparfait français.
:::

::: piege 6. Double négation avec `unless`
`unless` contient déjà `not`. ❌ `unless you don't come` → ✅ `unless you come`.
:::

::: piege 7. `in case` confondu avec `if`
`in case` veut dire « par précaution, au cas où », et l'action a lieu **maintenant**.
:::

::: piege 8. Choisir le type au hasard
Le type choisi **dit quelque chose du réel**. Un type 2 employé à la place d'un type 1 fait comprendre que la situation est impossible.
:::

::: retenir Les trois structures en une image

```
type 0 :  if + présent   ,  présent            → toujours vrai
type 1 :  if + présent   ,  will + verbe       → possible
type 2 :  if + prétérit  ,  would + verbe      → imaginaire
```

Et une règle unique qui vaut pour les trois : **ni `will` ni `would` après `if`**.
:::
