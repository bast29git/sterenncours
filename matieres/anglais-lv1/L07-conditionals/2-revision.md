## 1. Les trois structures

::: formule-cle
```
type 0 :  if + present simple  ,  present simple
type 1 :  if + present simple  ,  will + base verbale
type 2 :  if + past simple     ,  would + base verbale
```
:::

::: grille
| Type | Ce qu'il exprime | Exemple |
|---|---|---|
| **0** | une vérité générale, toujours vraie | `If you heat ice, it melts.` |
| **1** | une situation réelle, possible | `If it rains, we will stay in.` |
| **2** | une situation imaginaire | `If I were rich, I would travel.` |
:::

::: retenir La correspondance avec le français
```
type 1 : si + présent     →  futur
type 2 : si + imparfait   →  conditionnel présent
```
Le français et l'anglais font exactement la même chose.
:::

## 2. Choisir le bon type

::: formule-cle
Une seule question : **est-ce que cela peut réellement arriver ?**
Toujours → **0**. Peut-être → **1**. Non, j'imagine → **2**.
:::

::: retenir Le test du `when`
Si tu peux remplacer `if` par `when` sans changer le sens, c'est un **type 0**.
`If you heat ice, it melts.` = `When you heat ice, it melts.`
:::

::: grille
| Situation | Type |
|---|---|
| L'eau bout à 100 °C | **0** |
| Il pleuvra peut-être demain | **1** |
| Je ne suis pas millionnaire | **2** |
| Mon chien aboie quand on sonne | **0** |
| Je ne parle pas japonais | **2** |
:::

::: piege Le type choisi dit quelque chose du réel
`If I have time, I will call you.` → j'ai une chance d'en avoir.
`If I had time, I would call you.` → je sais que je n'en aurai pas.
Une erreur de type est une **erreur de sens**, pas seulement de grammaire.
:::

## 3. La virgule

::: formule-cle
```
If + condition  ,  résultat        ← virgule obligatoire
résultat  if + condition           ← pas de virgule
```
:::

::: retenir Une règle mécanique
Dès que tu écris `If` en début de phrase, place mentalement la virgule avant de continuer. C'est une faute entièrement évitable.
:::

## 4. Le cas de `were`

::: formule-cle
Au conditional 2, `be` se met à **`were` à toutes les personnes** :
`if I were`, `if he were`, `if she were`, `if it were`.
:::

::: retenir La formule à connaître par cœur
`If I were you, I would...` C'est la façon la plus courante de donner un conseil en anglais. Apprends-la comme un bloc.
:::

::: info À l'oral
`if I was` s'entend très souvent et n'est pas considéré comme fautif dans la langue parlée. En écriture scolaire, on attend `were`.
:::

## 5. Ni `will` ni `would` après `if`

::: formule-cle
```
❌ if + will       ❌ if + would
✅ if + présent    ✅ if + prétérit
```
Le `if` **absorbe** le futur et le conditionnel : ils restent de l'autre côté de la virgule.
:::

::: grille
| Faux | Juste |
|---|---|
| `If you will come, I will be happy.` | `If you come, I will be happy.` |
| `If I would have money, I would buy it.` | `If I had money, I would buy it.` |
| `If it will rain, we will stay in.` | `If it rains, we will stay in.` |
:::

## 6. Les alternatives à `if`

::: grille
| Mot | Sens | Exemple |
|---|---|---|
| `unless` | sauf si, à moins que | `I won't go unless you come.` |
| `as long as` | à condition que | `You can borrow it as long as you return it.` |
| `provided that` | à condition que, formel | `We will start provided that everyone is ready.` |
| `in case` | au cas où, par précaution | `Take an umbrella in case it rains.` |
| `even if` | même si | `I will go even if it rains.` |
:::

::: piege `unless` contient déjà la négation
`unless` = `if... not`. ❌ `unless you don't come` → ✅ `unless you come`.
:::

::: piege `in case` n'est pas `if`
`If it rains, I will take an umbrella.` → je le prends **seulement s'il pleut**.
`I will take an umbrella in case it rains.` → je le prends **maintenant**, par précaution.
:::

## 7. Les emplois du conditional 2

::: grille
| Emploi | Formule | Exemple |
|---|---|---|
| Conseiller | `If I were you, I would...` | `If I were you, I would apologise.` |
| Rêver | `If I had..., I would...` | `If I had a garden, I would grow vegetables.` |
| Regretter le présent | `If I..., I would...` | `If I lived closer, I would see you more often.` |
| Demander poliment | `Would you mind...?` | `Would you mind opening the window?` |
| Se projeter | `What would you do if...?` | `What would you do if you won the lottery?` |
:::

::: retenir Du rêve au projet
Passer du type 2 au type 1 dans une conversation signale qu'on passe du **rêve** au **projet**.
`If I could, I would live by the sea.` puis `If I save enough, I will go in July.`
:::

## 8. Les formules à réutiliser

::: motscles
- `If I were you, I would...`
- `What would you do if...?`
- `I would rather...`
- `It would be better if...`
- `In that case, I would...`
- `Otherwise, I will...`
- `As long as...`
- `Unless...`
- `In case...`
- `Even if...`
:::

::: aide Prononciation
`I would` → `I'd`, `he would` → `he'd`, `would not` → `wouldn't`, `I will` → `I'll`, `will not` → `won't`.
Entraîne-toi à dire `If I were you, I'd wait` d'une seule traite.
:::

## 10. Les huit pièges

::: piege 1. `will` après `if`
❌ `If it will rain` → ✅ `If it rains`.
:::

::: piege 2. `would` après `if`
❌ `If I would have money` → ✅ `If I had money`.
:::

::: piege 3. La virgule oubliée
Quand la phrase commence par `if`, la virgule est obligatoire.
:::

::: piege 4. `was` au lieu de `were`
À l'écrit scolaire : `if I were`, `if he were`, à toutes les personnes.
:::

::: piege 5. Le prétérit pris pour du passé
Dans `if I had a car`, `had` marque la distance avec le réel, comme l'imparfait français.
:::

::: piege 6. Double négation avec `unless`
❌ `unless you don't come` → ✅ `unless you come`.
:::

::: piege 7. `in case` confondu avec `if`
`in case` veut dire « par précaution », et l'action a lieu maintenant.
:::

::: piege 8. Choisir le type au hasard
Un type 2 employé à la place d'un type 1 fait comprendre que la situation est impossible.
:::

## 11. Auto-test

Réponds sans regarder la fiche de cours. Les réponses sont juste en dessous.

::: exercice 1 | application | 10 min | ecran
1. Donne les trois structures, en une ligne chacune.
2. Quelle question permet de choisir le type ?
3. Complète : `If it ... (rain) tomorrow, we ... (stay) at home.`
4. Complète : `If I ... (be) you, I ... (talk) to her.`
5. Complète : `If you heat water to 100 °C, it ... (boil).`
6. Corrige : `If I would have a car, I would drive you.`
7. Où place-t-on la virgule ? Donne la règle en une phrase.
8. Transforme avec `unless` : `If you don't hurry, you will miss the bus.`
9. Quelle différence y a-t-il entre `if it rains` et `in case it rains` ?
10. Traduis : « Si j'avais plus de temps, je lirais davantage. »

::: corrige
1. Les trois structures sont les suivantes.

```
type 0 :  if + present simple  ,  present simple
type 1 :  if + present simple  ,  will + base verbale
type 2 :  if + past simple     ,  would + base verbale
```

2. **Est-ce que cela peut réellement arriver ?** Toujours → type 0 ; peut-être → type 1 ; non, j'imagine → type 2.
3. `If it **rains** tomorrow, we **will stay** at home.` Type 1 : la pluie est possible. Pas de `will` après `if`.
4. `If I **were** you, I **would talk** to her.` Type 2 : je ne suis pas toi. `were` à toutes les personnes.
5. `If you heat water to 100 °C, it **boils**.` Type 0 : c'est toujours vrai. Le test du `when` fonctionne.
6. `If I **had** a car, I would drive you.` Jamais `would` après `if` : c'est le prétérit qui porte la condition.
7. Quand la phrase **commence** par `if`, une virgule sépare la condition du résultat. Quand le `if` est au milieu, il n'y a **pas** de virgule.
8. `**Unless** you hurry, you will miss the bus.` Attention : pas de négation après `unless`, qui contient déjà `not`.
9. `If it rains, I will take an umbrella.` signifie que je prends le parapluie **seulement s'il pleut**. `I will take an umbrella in case it rains.` signifie que je le prends **maintenant**, par précaution, au cas où il pleuvrait.
10. `If I **had** more time, I **would read** more.` Type 2 : `if` + prétérit, puis `would` + base verbale.
:::

- Je sais choisir le type à partir de la situation
- Je place la virgule au bon endroit
- Je n'écris jamais `will` ni `would` après `if`
- Je sais employer `unless`, `as long as` et `in case`
