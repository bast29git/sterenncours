## 1. Le prétérit simple

::: formule La construction
Verbes réguliers : **base verbale + `-ed`**, à toutes les personnes.
`work` → `worked`. `live` → `lived`. `study` → `studied`. `stop` → `stopped`.
:::

::: formule-cle
Au prétérit, **toutes les personnes** ont la même forme. Pas de `s`.
Seul **`be`** fait exception : `I was`, `you were`, `he was`, `we were`, `they were`.
:::

::: grille
| Règle orthographique | Exemple |
|---|---|
| verbe en `-e` | `live` → `lived` |
| consonne + `y` | `study` → `studied` |
| voyelle + `y` | `play` → `played` |
| une syllabe à consonne finale | `stop` → `stopped` |
:::

## 2. Les vingt verbes irréguliers

::: grille
| be → **was/were** | have → **had** | go → **went** | do → **did** | say → **said** |
|---|---|---|---|---|
| see → **saw** | come → **came** | take → **took** | give → **gave** | get → **got** |
| make → **made** | know → **knew** | think → **thought** | find → **found** | tell → **told** |
| leave → **left** | feel → **felt** | run → **ran** | write → **wrote** | begin → **began** |
:::

::: formule-cle
Les cinq à connaître absolument : **be, have, go, do, say**.
Un récit au passé sans eux est impossible à écrire.
:::

## 3. Négation et question

::: formule La règle
Négation : sujet + **`didn't`** + **base verbale**.
Question : **`Did`** + sujet + **base verbale**.
:::

::: piege Le double passé
`She didn't went` et `Did she went?` sont **faux**.
Le passé est déjà marqué par `did` : le verbe reprend sa forme de base.
`She didn't go.` `Did she go?`
:::

::: formule-cle
Le verbe **`be`** n'utilise pas `did` : `Was she tired?`, `She wasn't tired.`
:::

## 4. Le prétérit continu

::: formule La construction
**`was` ou `were` + verbe en `-ing`**
`I was walking`, `they were walking`.
:::

::: grille
| Emploi | Exemple |
|---|---|
| Action en cours | `At 8 p.m. I was watching a film.` |
| Décor du récit | `It was raining and the wind was blowing.` |
| Action interrompue | `I was reading when the phone rang.` |
| Deux actions parallèles | `She was cooking while he was working.` |
:::

::: formule-cle
Le **continu** pose le **décor**. Le **simple** raconte les **événements**.
:::

::: piege Les verbes d'état
`know`, `believe`, `understand`, `want`, `like`, `love`, `hate`, `need`, `seem` ne se mettent **pas** au continu.
On dit `I knew`, jamais `I was knowing`.
:::

## 5. Combiner les deux temps

::: formule Le schéma type
Action **longue** au **continu** + action **courte** au **simple**.
`I was walking home when it started to rain.`
:::

::: grille
| Connecteur | Temps qui suit |
|---|---|
| **when** | prétérit **simple** |
| **while** | prétérit **continu** |
:::

::: exemple Les deux angles d'une même scène
`When the phone rang, I was reading.`
`While I was reading, the phone rang.`
:::

::: formule-cle
L'ordre des propositions ne change rien. Ce qui compte, c'est **quel verbe est à quel temps**.
:::

## 6. Les connecteurs de récit

::: grille
| Fonction | Connecteurs |
|---|---|
| Commencer | one day, once, at first |
| Ordonner | first, then, after that, later, soon |
| Situer | at that moment, meanwhile, as soon as |
| Opposer | but, however, although |
| Expliquer | because, since, so |
| Conclure | in the end, finally, at last |
:::

::: piege Trois faux amis
`Actually` = **en fait**, et non « actuellement », qui se dit `currently`.
`Eventually` = **finalement**, et non « éventuellement ».
`Finally` = **pour finir**, dans une énumération.
:::

::: retenir La structure d'un récit
1. Situation de départ, au **continu**.
2. Élément déclencheur, au **simple**.
3. Péripéties, avec des **connecteurs**.
4. Point culminant.
5. Fin, souvent avec `in the end`.
:::

## 8. Les huit pièges

::: piege 1. Le double passé
`She didn't went` est faux. Après `did`, la **base verbale**.
:::

::: piege 2. La question
`Did she went?` est faux. On écrit `Did she go?`
:::

::: piege 3. Le verbe be
Il n'utilise jamais `did`. `Was she tired?`, pas `Did she be tired?`
:::

::: piege 4. Le `s` du prétérit
Aucune personne ne prend de `s` : `he worked`, comme `I worked`.
:::

::: piege 5. Le repère de temps
`I have seen him yesterday` est faux. Un repère précis dans le passé impose le **prétérit**.
:::

::: piege 6. Les verbes d'état
`I was knowing` est faux. On dit `I knew`.
:::

::: piege 7. While
Après `while`, on emploie normalement le **continu** : `While I was reading...`
:::

::: piege 8. Les faux amis
`Actually` veut dire « en fait », `eventually` « finalement ». Ni l'un ni l'autre ne signifie ce que le français suggère.
:::

## 9. Auto-test

Réponds sans regarder la fiche de cours. Les réponses sont juste en dessous.

::: exercice 1 | application | 8 min | ecran
1. Mets au prétérit : `I (go) to Paris last summer.`
2. Mets au prétérit : `She (study) all evening.`
3. Mets à la forme négative : `He worked yesterday.`
4. Mets à la forme interrogative : `They took the bus.`
5. Donne le prétérit de `think`, `write`, `leave`.
6. Complète : `I ______ (read) when the phone rang.`
7. Complète : `While she ______ (cook), he set the table.`
8. Corrige : `I was knowing the answer.`
9. Que signifie `actually` ?
10. Cite trois connecteurs pour ordonner un récit.

::: corrige
1. `I went to Paris last summer.`
2. `She studied all evening.` Consonne plus `y` : le `y` devient `i`.
3. `He didn't work yesterday.` Après `didn't`, la base verbale.
4. `Did they take the bus?` Après `did`, la base verbale.
5. `thought`, `wrote`, `left`.
6. `I was reading when the phone rang.` Action longue interrompue par une action courte.
7. `While she was cooking, he set the table.` Après `while`, le continu.
8. `I knew the answer.` `know` est un verbe d'état : il ne se met pas au continu.
9. « **En fait**, en réalité ». Ce n'est pas « actuellement », qui se dit `currently`.
10. Trois au choix : `first`, `then`, `after that`, `next`, `later`, `soon`.
:::
