## 1. À quoi sert le pretérito perfecto

::: definition Pretérito perfecto
Le **pretérito perfecto** raconte une action passée qui a un **lien avec le présent** : elle vient de se produire, ou elle appartient à une période encore en cours.
`Hoy **he comido** en el instituto.` → Aujourd'hui, j'ai mangé au lycée.
:::

::: retenir Le point essentiel
Il se traduit presque toujours par le **passé composé** français.
La différence avec le français porte sur le **choix du temps**, pas sur la traduction : l'espagnol réserve le pretérito perfecto aux périodes **non terminées**.
:::

::: formule
La question à se poser :
**la période dont je parle est-elle finie ?**
`hoy`, `esta semana`, `este año` → période **en cours** → pretérito perfecto.
`ayer`, `la semana pasada`, `en 2020` → période **terminée** → un autre temps, étudié au chapitre suivant.
:::

## 2. Conjuguer haber

::: formule
**La construction**
`haber` au présent + **participe passé**

`He comido.` · `Has comido.` · `Ha comido.`
:::

::: grille
| Personne | `haber` | Exemple |
|---|---|---|
| yo | **he** | `He hablado.` |
| tú | **has** | `Has hablado.` |
| él, ella, usted | **ha** | `Ha hablado.` |
| nosotros | **hemos** | `Hemos hablado.` |
| vosotros | **habéis** | `Habéis hablado.` |
| ellos, ellas, ustedes | **han** | `Han hablado.` |
:::

::: piege `haber` n'est pas `tener`
`haber` est un **auxiliaire** : il ne s'emploie jamais seul pour dire « avoir » au sens de posséder.
Pour posséder, c'est `tener` : `Tengo un libro`, jamais `He un libro`.
:::

::: piege Le `h` ne se prononce pas
`he`, `has`, `ha` se prononcent sans le `h`, qui est toujours muet en espagnol.
Attention cependant : on l'écrit **toujours**.
:::

## 3. Le participe passé régulier

::: formule
**Verbes en `-ar`** → radical + **`-ado`**
`hablar` → `hablado`, `estudiar` → `estudiado`

**Verbes en `-er` et `-ir`** → radical + **`-ido`**
`comer` → `comido`, `vivir` → `vivido`
:::

::: grille
| Infinitif | Groupe | Participe |
|---|---|---|
| `hablar` | -ar | `hablado` |
| `jugar` | -ar | `jugado` |
| `trabajar` | -ar | `trabajado` |
| `comer` | -er | `comido` |
| `beber` | -er | `bebido` |
| `vivir` | -ir | `vivido` |
| `salir` | -ir | `salido` |
| `dormir` | -ir | `dormido` |
:::

::: retenir Deux terminaisons seulement
`-ado` pour le premier groupe, `-ido` pour les deux autres.
Il n'y a pas d'autre cas régulier. Tout le reste est irrégulier et figure dans la liste ci-dessous.
:::

## 4. Les huit irréguliers

::: grille
| Infinitif | Sens | Participe |
|---|---|---|
| `hacer` | faire | **hecho** |
| `decir` | dire | **dicho** |
| `ver` | voir | **visto** |
| `escribir` | écrire | **escrito** |
| `volver` | revenir | **vuelto** |
| `poner` | mettre | **puesto** |
| `abrir` | ouvrir | **abierto** |
| `romper` | casser | **roto** |
:::

::: retenir Le repère de forme
Six des huit finissent par **`-to`** : `visto`, `escrito`, `vuelto`, `puesto`, `abierto`, `roto`.
Les deux autres finissent par **`-cho`** : `hecho`, `dicho`.
Aucun ne finit par `-ado` ni `-ido`.
:::

::: piege Les composés suivent le simple
`devolver`, rendre, suit `volver` : `devuelto`.
`describir`, décrire, suit `escribir` : `descrito`.
`componer`, composer, suit `poner` : `compuesto`.
Si tu reconnais un verbe connu à l'intérieur, applique son participe.
:::

::: piege Le participe ne s'accorde jamais
Après `haber`, le participe reste **invariable**.
`Ella ha comido`, `Ellas han comido`, `Nosotros hemos comido` : `comido` ne change jamais.
C'est plus simple qu'en français, où l'accord dépend du complément.
:::

## 5. Les marqueurs temporels

::: grille
| Marqueur | Traduction |
|---|---|
| `hoy` | aujourd'hui |
| `esta mañana` | ce matin |
| `esta semana` | cette semaine |
| `este mes` | ce mois-ci |
| `este año` | cette année |
| `ya` | déjà |
| `todavía no` | pas encore |
| `nunca` | jamais |
| `alguna vez` | une fois, déjà |
| `últimamente` | dernièrement |
| `hace un rato` | il y a un moment |
:::

::: formule
**Le repère décisif**
Tous ces marqueurs désignent une période **qui n'est pas terminée** au moment où l'on parle.
`Hoy` n'est pas fini tant que la journée dure. `Este año` non plus.
C'est pourquoi ils appellent le pretérito perfecto.
:::

::: exemple Le même fait, deux périodes
`Hoy he ido al cine.` → aujourd'hui, la journée n'est pas finie.
`Ayer fui al cine.` → hier est terminé, on emploie un autre temps.

La différence ne porte pas sur l'action, qui est identique, mais sur la **période**.
:::

## 6. Les trois emplois

::: grille
| Emploi | Ce que cela signifie | Exemple |
|---|---|---|
| **Période en cours** | dans une journée, une semaine ou une année non finie | `Este año he viajado mucho.` |
| **Passé très proche** | ça vient de se produire | `He terminado hace un momento.` |
| **Expérience de vie** | au moins une fois, sans dire quand | `Nunca he estado en México.` |
:::

::: exemple Les trois emplois expliqués
**Période en cours** : `Esta semana he estudiado tres horas al día.` La semaine n'est pas finie.
**Passé proche** : `¡He aprobado el examen!` Le résultat vient d'arriver.
**Expérience** : `¿Alguna vez has comido paella?` Peu importe quand, la question porte sur l'expérience.
:::

::: retenir Le fil commun
Dans les trois cas, le passé **touche encore le présent**.
Si la période est close et datée, l'espagnol change de temps.
:::

## 7. La négation et les pronoms

::: formule
**La négation** : `no` se place **devant `haber`**
`No he comido.` · `No hemos terminado.`

**Les pronoms** : ils se placent **devant `haber`** aussi
`Lo he visto.` · `Te lo he dicho.` · `Me he levantado.`
:::

::: grille
| Type de phrase | Structure | Exemple |
|---|---|---|
| Affirmative | `haber` + participe | `He comido.` |
| Négative | `no` + `haber` + participe | `No he comido.` |
| Avec pronom | pronom + `haber` + participe | `Lo he comido.` |
| Négative avec pronom | `no` + pronom + `haber` + participe | `No lo he comido.` |
:::

::: piege L'ordre des mots
Tout se place **avant** l'auxiliaire, dans cet ordre : `no`, puis le pronom, puis `haber`, puis le participe.
`No te lo he dicho.` et jamais `No he te lo dicho.`
:::

## 8. Ce qu'il ne faut jamais séparer

::: piege `haber` et le participe sont soudés
On n'insère **jamais** rien entre les deux.
`Siempre he pensado eso.` et non `He siempre pensado eso.`
Le français accepte « j'ai toujours pensé » ; l'espagnol, non.
:::

::: exemple Où placer l'adverbe
`Siempre he pensado eso.` → l'adverbe avant l'auxiliaire.
`He pensado siempre en eso.` → ou après le participe.
Mais jamais au milieu.
:::

::: retenir La règle en une phrase
`haber` + participe forment un **bloc** que rien ne coupe : ni un adverbe, ni un pronom, ni la négation.
Tout ce qui les accompagne se place **avant** le bloc, ou **après** lui.
:::

## 9. Raconter une journée

::: methode Raconter ta journée en cinq phrases
1. Le lever : `Esta mañana me he levantado a las siete.`
2. Le trajet : `He ido al instituto en autobús.`
3. Une activité : `Hemos tenido tres horas de clase.`
4. Le repas : `He comido con mis amigos.`
5. L'après-midi : `Esta tarde he hecho los deberes.`
:::

::: exemple Un récit complet
« `Hoy me he levantado a las siete y media. He desayunado rápido porque he salido tarde de casa. He cogido el autobús de las ocho y he llegado al instituto justo a tiempo. Esta mañana hemos tenido matemáticas e inglés. He comido en la cafetería con Marta. Esta tarde he hecho los deberes y he visto un capítulo de mi serie. Todavía no he terminado el trabajo de español.` »

Compte : neuf pretéritos perfectos, dont deux irréguliers, `hecho` et `visto`, une négation avec `todavía no`, et un verbe pronominal, `me he levantado`.
:::

::: aide Les verbes utiles pour une journée
`levantarse` se lever, `desayunar` prendre le petit déjeuner, `salir` sortir, `coger` prendre, `llegar` arriver, `comer` manger, `hacer los deberes` faire ses devoirs, `acostarse` se coucher.
:::

## 10. Raconter une expérience

::: formule
**Les formules de l'expérience**
`¿Alguna vez has ...?` → As-tu déjà ... ?
`Nunca he ...` → Je n'ai jamais ...
`Ya he ...` → J'ai déjà ...
`Todavía no he ...` → Je n'ai pas encore ...
:::

::: exemple Un échange type
`— ¿Alguna vez has visto una corrida?`
`— No, nunca la he visto. ¿Y tú?`
`— Yo tampoco. Pero ya he estado en Sevilla dos veces.`

Remarque `nunca la he visto` : le pronom `la` se glisse entre `nunca` et `he`, toujours avant l'auxiliaire.
:::

::: piege `nunca` suffit
`Nunca he estado allí.` Une seule négation.
Si `nunca` passe après le verbe, il faut alors `no` devant : `No he estado nunca allí.` Les deux tournures existent, mais on n'écrit jamais `Nunca no he estado`.
:::

## 11. Poser des questions au passé

::: grille
| Question | Traduction |
|---|---|
| `¿Qué has hecho hoy?` | Qu'as-tu fait aujourd'hui ? |
| `¿Dónde has estado?` | Où es-tu allé ? |
| `¿Con quién has comido?` | Avec qui as-tu mangé ? |
| `¿Has terminado ya?` | As-tu déjà fini ? |
| `¿Alguna vez has probado ...?` | As-tu déjà goûté ... ? |
:::

::: formule
**L'ordre dans la question**
Mot interrogatif + `haber` + participe + reste
`¿Qué **has hecho** esta tarde?`
Le sujet, quand il est exprimé, se place **après** le participe : `¿Qué ha dicho Marta?`
:::

::: aide Pour relancer un échange
`¿Y tú?` → Et toi ?
`¿De verdad?` → Vraiment ?
`Yo también.` → Moi aussi.
`Yo tampoco.` → Moi non plus.
Ces quatre formules suffisent à tenir un dialogue sans blanc.
:::

## 12. Les pièges à éviter

::: piege 1. `haber` et `tener`
`haber` est un auxiliaire, `tener` exprime la possession. `Tengo un libro`, jamais `He un libro`.
:::

::: piege 2. L'accord du participe
Après `haber`, le participe est **invariable** : `Ellas han comido`, jamais `comidas`.
:::

::: piege 3. Le bloc insécable
Rien ne s'insère entre `haber` et le participe. `Siempre he pensado`, jamais `He siempre pensado`.
:::

::: piege 4. La place des pronoms
Ils passent **devant** `haber` : `Lo he visto`, jamais `He lo visto`.
:::

::: piege 5. Les marqueurs
`hoy`, `esta semana`, `este año` appellent le pretérito perfecto. `ayer`, `en 2020` appellent un autre temps.
:::

::: piege 6. Les irréguliers
Aucun participe irrégulier ne finit en `-ado` ni `-ido`. `hecho`, `dicho`, `visto`, `escrito`, `vuelto`, `puesto`, `abierto`, `roto`.
:::

::: piege 7. Le `h` muet
On ne le prononce pas, mais on l'écrit toujours : `he`, `has`, `ha`, `hemos`, `habéis`, `han`.
:::

::: piege 8. `nunca`
Une seule négation : `Nunca he estado allí` ou `No he estado nunca allí`, jamais les deux formes mêlées.
:::

::: cocher
- Je conjugue haber au présent aux six personnes
- Je forme le participe régulier en -ado et -ido
- Je connais les huit participes irréguliers
- Je place la négation et les pronoms devant haber
- Je sais raconter ma journée en cinq phrases
:::
