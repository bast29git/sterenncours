## 1. La construction inversée

::: formule La construction
`pronom` + `gusta` ou `gustan` + **ce qui plaît**

`Me gusta el chocolate.` Littéralement : « le chocolat me plaît ».
:::

::: formule-cle
La personne est **complément**, jamais sujet.
Le sujet du verbe, c'est **la chose aimée**.
:::

::: retenir La traduction intermédiaire
Pour ne jamais se tromper, traduire d'abord par **« plaire »**.
« J'aime les films » → « les films **me plaisent** » → `me gustan las películas`.
:::

## 2. Les six pronoms

::: grille
| Personne | Pronom |
|---|---|
| à moi | **me** |
| à toi | **te** |
| à lui, à elle, à vous de politesse | **le** |
| à nous | **nos** |
| à vous | **os** |
| à eux, à elles | **les** |
:::

::: formule-cle
Le pronom se place **avant** le verbe et ne change **jamais** selon le genre.
`le` sert pour lui comme pour elle.
:::

## 3. La règle d'accord

::: formule Le test unique
Le mot qui suit est-il un **nom au pluriel** ?
Oui → `gustan`. Dans tous les autres cas → `gusta`.
:::

::: grille
| Phrase | Accord |
|---|---|
| `Me gusta el libro.` | singulier |
| `Me gustan los libros.` | **pluriel** |
| `Me gusta leer.` | singulier |
| `Me gusta leer y escribir.` | singulier, malgré deux infinitifs |
| `Me gustan el cine y el teatro.` | **pluriel**, deux noms |
:::

::: piege La négation
`No me gusta el café.` L'ordre est toujours **`no` + pronom + verbe**.
`Me no gusta` est faux.
:::

::: piege La forme tonique
`A mí **me** gusta`, avec les deux. La forme tonique s'**ajoute**, elle ne remplace jamais le pronom.
Elle sert à insister ou à lever l'ambiguïté de `le`.
:::

## 4. Les verbes de la même famille

::: grille
| Verbe | Sens | Exemple |
|---|---|---|
| **encantar** | adorer | `Me encanta el cine.` |
| **interesar** | intéresser | `Me interesa la historia.` |
| **apetecer** | avoir envie de | `Me apetece un café.` |
| **molestar** | déranger | `Me molesta el ruido.` |
| **doler** | faire mal | `Me duele la cabeza.` |
| **parecer** | sembler | `Me parece interesante.` |
| **faltar** | manquer | `Me faltan dos euros.` |
:::

::: formule-cle
Tous se construisent **exactement comme `gustar`**, accord compris.
`Me duelen los pies` : pluriel, parce que les pieds sont deux.
:::

## 5. Les six niveaux d'intensité

::: grille
| Intensité | Formule |
|---|---|
| très fort | `me encanta` |
| fort | `me gusta mucho` |
| moyen | `me gusta` |
| faible | `me gusta un poco` |
| négatif | `no me gusta` |
| très négatif | `no me gusta nada` |
| rejet | `odio` |
:::

::: piege Encantar ne se renforce pas
`Me encanta mucho` est un pléonasme. `Me encanta` suffit.
:::

## 6. Accord et désaccord

::: grille
| Phrase de départ | Je suis d'accord | Je ne le suis pas |
|---|---|---|
| **positive** | `a mí también` | `a mí no` |
| **négative** | `a mí tampoco` | `a mí sí` |
:::

::: exemple Les quatre cas
`Me gusta el cine. → A mí también.`
`Me gusta el fútbol. → A mí no.`
`No me gusta el café. → A mí tampoco.`
`No me gusta bailar. → A mí sí.`
:::

::: retenir Les formules d'opinion
`Creo que`, `pienso que`, `me parece que`, `en mi opinión`, `para mí`, `estoy de acuerdo con`.
Une seule par phrase : on varie, on n'empile pas.
:::

::: formule La structure d'une opinion en cinq phrases
1. `En mi opinión, ...`
2. `porque ...`
3. `Por ejemplo, ...`
4. `Sin embargo, ...`
5. `Por eso creo que ...`
:::

## 8. Les huit pièges

::: piege 1. Le sujet
`Yo gusto el chocolate` signifierait « je plais au chocolat ». On dit `me gusta el chocolate`.
:::

::: piege 2. L'accord
`Me gusta los libros` est faux. Devant un nom pluriel : `me **gustan**`.
:::

::: piege 3. Les infinitifs
`Me gustan leer y escribir` est faux. Deux infinitifs laissent le verbe au **singulier**.
:::

::: piege 4. La négation
`Me no gusta` est faux. L'ordre est `no` + pronom + verbe.
:::

::: piege 5. La forme tonique
`A mí gusta` est faux. Le pronom reste **obligatoire** : `a mí me gusta`.
:::

::: piege 6. Encantar
`Me encanta mucho` est un pléonasme : `encantar` contient déjà l'intensité.
:::

::: piege 7. También et tampoco
`también` après une phrase **positive**, `tampoco` après une phrase **négative**. Jamais l'inverse.
:::

::: piege 8. Largo
Il signifie « **long** », et non « large », qui se dit `ancho`.
:::

## 9. Auto-test

Réponds sans regarder la fiche de cours. Les réponses sont juste en dessous.

::: exercice 1 | application | 8 min | ecran
1. Traduis : « J'aime le chocolat. »
2. Traduis : « J'aime les livres. »
3. Traduis : « J'aime lire et écrire. »
4. Traduis : « Je n'aime pas le café. »
5. Complète : `A mi hermana ……… gusta el cine.`
6. Complète : `……… duelen los pies.` (à moi)
7. Réponds : `Me gusta el fútbol. → ………` (tu es d'accord)
8. Réponds : `No me gusta madrugar. → ………` (tu n'es pas d'accord)
9. Comment dit-on « j'adore » ?
10. Cite trois formules pour donner son opinion.

::: corrige
1. `Me gusta el chocolate.`
2. `Me gustan los libros.` Nom pluriel, donc `gustan`.
3. `Me gusta leer y escribir.` Deux infinitifs, mais **singulier**.
4. `No me gusta el café.` La négation précède le pronom.
5. `le`. On peut préciser : `A mi hermana le gusta el cine.`
6. `Me duelen los pies.` Pluriel, parce que les pieds sont deux.
7. `A mí también.` Phrase positive et accord.
8. `A mí sí.` Phrase négative et désaccord.
9. `Me encanta.`
10. Trois au choix : `creo que`, `pienso que`, `me parece que`, `en mi opinión`, `para mí`.
:::
