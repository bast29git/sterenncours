## 1. Les deux conjugaisons

::: grille
| Personne | `ser` | `estar` |
|---|---|---|
| yo | **soy** | **estoy** |
| tú | **eres** | **estás** |
| él, ella, usted | **es** | **está** |
| nosotros | **somos** | **estamos** |
| vosotros | **sois** | **estáis** |
| ellos, ellas, ustedes | **son** | **están** |
:::

::: formule-cle
Les **accents écrits** de `estás`, `está`, `estáis`, `están` sont obligatoires.
Les oublier est une faute d'orthographe comptée comme telle.
:::

## 2. La règle de choix

::: formule Les quatre questions
1. **Un lieu ?** → `estar`, toujours.
2. **Un état passager, une humeur, une santé ?** → `estar`.
3. **Ce que la chose est, durablement ?** → `ser`.
4. **Heure, date, matière, possession, profession, nationalité ?** → `ser`.
:::

::: formule-cle
`ser` dit **ce que c'est**. `estar` dit **où c'est** et **comment ça va**.
:::

## 3. Le tableau des emplois

::: grille
| Emploi | Verbe | Exemple |
|---|---|---|
| Nationalité | `ser` | `Soy francesa.` |
| Profession | `ser` | `Es médico.` |
| Matière | `ser` | `Es de madera.` |
| Possession | `ser` | `Es de Marta.` |
| Heure | `ser` | `Son las tres.` |
| Physique, caractère | `ser` | `Es alta y simpática.` |
| **Lieu** | `estar` | `Está en la cocina.` |
| Humeur | `estar` | `Está contenta.` |
| Santé | `estar` | `Estoy enferma.` |
| État du moment | `estar` | `La sopa está fría.` |
:::

::: piege L'exception des événements
Un lieu prend `estar` : `La fiesta está en mi casa` est faux.
Un **événement** prend `ser` : `La fiesta es en mi casa`, parce qu'il **a lieu**.
:::

## 4. Hay ou está

::: grille
| | `hay` | `está` |
|---|---|---|
| Sens | quelque chose **existe** | **où** se trouve une chose connue |
| Suivi de | indéfini, nombre, quantité | défini, nom propre, possessif |
| Invariable | **oui**, toujours | non : `está` ou `están` |
| Exemple | `Hay una farmacia aquí.` | `La farmacia está aquí.` |
:::

::: formule-cle
`hay` n'est **jamais** suivi de `el`, `la`, `los`, `las`.
`Hay el libro` est impossible : on dit `El libro está aquí`.
:::

::: exemple L'ordre naturel d'une description
`En mi habitación hay un escritorio.` On introduit.
`El escritorio está delante de la ventana.` On situe.
:::

## 5. Les adjectifs qui changent de sens

::: grille
| Adjectif | `ser` | `estar` |
|---|---|---|
| `aburrido` | ennuyeux | qui s'ennuie |
| `listo` | intelligent | prêt |
| `malo` | méchant | malade |
| `bueno` | gentil | savoureux |
| `rico` | riche | délicieux |
| `verde` | vert | pas mûr |
| `vivo` | vif | vivant |
| `orgulloso` | orgueilleux | fier |
:::

::: formule-cle
`El profesor es aburrido` : il est ennuyeux.
`El profesor está aburrido` : il s'ennuie.
:::

## 6. Le lexique de la description

::: grille
| Physique et caractère (`ser`) | État (`estar`) | Position (`estar`) |
|---|---|---|
| alto, bajo | cansado | encima de |
| moreno, rubio | contento, triste | debajo de |
| simpático | enfadado | al lado de |
| trabajador | nervioso | delante de |
| tímido | preocupado | detrás de |
:::

::: formule-cle
L'âge se dit avec **`tener`** : `Tiene quince años`.
Jamais `es` ni `está`.
:::

## 8. Les huit pièges

::: piege 1. Le lieu
`Madrid está en España`, jamais `es`. Même pour ce qui ne bouge pas.
:::

::: piege 2. L'état du moment
`Estoy cansada`, jamais `soy cansada`. La fatigue est passagère.
:::

::: piege 3. La réponse à la question sur la santé
`¿Cómo estás?` appelle `Estoy bien`, jamais `Soy bien`.
:::

::: piege 4. L'article après hay
`Hay el libro` est impossible. `hay` ne supporte que l'indéfini, le nombre ou la quantité.
:::

::: piege 5. L'invariabilité de hay
`hay` ne se conjugue pas : `Hay tres sillas`, au singulier comme au pluriel.
:::

::: piege 6. L'âge
`Tiene quince años`, avec `tener`. Ni `es`, ni `está`.
:::

::: piege 7. Les accents
`está` et `están` portent un accent écrit. `esta` sans accent est un démonstratif, un autre mot.
:::

::: piege 8. Listo
`Estoy listo` veut dire « je suis prêt ». `Soy listo` veut dire « je suis intelligent ».
:::

## 9. Auto-test

Réponds sans regarder la fiche de cours. Les réponses sont juste en dessous.

::: exercice 1 | application | 8 min | ecran
1. Conjugue `ser` à la première et à la troisième personne du singulier.
2. Conjugue `estar` à la deuxième personne du singulier, avec l'accent.
3. Complète : `Barcelona ……… en Cataluña.`
4. Complète : `Hoy ……… muy cansada.`
5. Complète : `Mi hermano ……… muy simpático.`
6. Complète : `……… las cuatro y media.`
7. Complète : `En mi calle ……… una farmacia.`
8. Complète : `La farmacia ……… al lado del banco.`
9. Traduis : `El profesor está aburrido.`
10. Comment dit-on « elle a quatorze ans » ?

::: corrige
1. `soy` et `es`.
2. `estás`, avec un accent sur le `a`.
3. `está`. C'est un lieu.
4. `estoy`. C'est un état passager.
5. `es`. C'est un trait de caractère durable.
6. `Son`. L'heure se dit avec `ser`, au pluriel à partir de deux heures.
7. `hay`. On signale l'existence d'une pharmacie qu'on n'a pas encore nommée.
8. `está`. On situe une pharmacie déjà connue.
9. « Le professeur **s'ennuie**. » Avec `ser`, la phrase voudrait dire qu'il est ennuyeux.
10. `Tiene catorce años.` L'âge se dit avec `tener`.
:::
