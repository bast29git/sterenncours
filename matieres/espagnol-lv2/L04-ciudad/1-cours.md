## 1. Les lieux de la ville

::: grille
| Espagnol | Français |
|---|---|
| `la calle` | la rue |
| `la plaza` | la place |
| `la avenida` | l'avenue |
| `el barrio` | le quartier |
| `el ayuntamiento` | la mairie |
| `la estación` | la gare |
| `la parada de autobús` | l'arrêt de bus |
| `el museo` | le musée |
| `la biblioteca` | la bibliothèque |
| `el mercado` | le marché |
| `la tienda` | le magasin |
| `el banco` | la banque |
| `la farmacia` | la pharmacie |
| `el hospital` | l'hôpital |
| `el parque` | le parc |
| `el puente` | le pont |
| `la esquina` | le coin de rue |
| `el semáforo` | le feu tricolore |
| `la acera` | le trottoir |
| `el cruce` | le carrefour |
:::

::: piege Les faux amis de la ville
`la librería` est la **librairie**, pas la bibliothèque, qui se dit `la biblioteca`.
`el éxito` signifie le **succès**, pas la sortie, qui se dit `la salida`.
:::

## 2. Les transports

::: grille
| Espagnol | Français |
|---|---|
| `el autobús` | le bus |
| `el metro` | le métro |
| `el tren` | le train |
| `el coche` | la voiture |
| `la bici` ou `la bicicleta` | le vélo |
| `el tranvía` | le tramway |
| `a pie` | à pied |
| `el billete` | le ticket |
| `el andén` | le quai |
| `la línea` | la ligne |
:::

::: formule
**Dire comment on se déplace**
`en` + moyen de transport : `en autobús`, `en metro`, `en coche`, `en bici`
**Sauf** à pied : `a pie`, avec `a` et non `en`.
:::

::: piege `en bici` et `a pie`
Tous les transports prennent `en`, sauf la marche qui prend `a`.
`Voy en metro` mais `Voy a pie`.
:::

## 3. Situer : les prépositions de lieu

::: grille
| Espagnol | Français |
|---|---|
| `al lado de` | à côté de |
| `enfrente de` | en face de |
| `delante de` | devant |
| `detrás de` | derrière |
| `entre ... y ...` | entre ... et ... |
| `cerca de` | près de |
| `lejos de` | loin de |
| `a la derecha de` | à droite de |
| `a la izquierda de` | à gauche de |
| `al final de` | au bout de |
| `en la esquina de` | au coin de |
:::

::: formule
**La contraction obligatoire**
`de` + `el` donne **`del`** : `al lado **del** museo`, jamais `de el museo`.
`a` + `el` donne **`al`** : `Voy **al** parque`, jamais `a el parque`.
:::

::: piege La contraction ne concerne que `el`
`del` et `al` ne se forment qu'avec l'article masculin singulier `el`.
On dit `al lado de la plaza`, `de los museos`, `de las tiendas` : aucune contraction.
:::

## 4. Demander son chemin

::: formule
**Les trois questions utiles**
`¿Dónde está ...?` → Où se trouve ... ?
`¿Cómo se va a ...?` → Comment va-t-on à ... ?
`¿Hay un ... por aquí?` → Y a-t-il un ... par ici ?
:::

::: exemple Demander poliment
`Perdone, ¿dónde está la estación, por favor?`
`Perdona, ¿cómo se va al museo?`

`Perdone` s'adresse à une personne qu'on vouvoie, `perdona` à une personne qu'on tutoie.
En Espagne, on tutoie facilement une personne de son âge.
:::

::: piege `¿Dónde está?` et `¿Dónde hay?`
`¿Dónde está la farmacia?` → une pharmacie **précise**, que je cherche.
`¿Dónde hay una farmacia?` → **n'importe quelle** pharmacie.
C'est la distinction entre `estar` et `hay` vue en L02.
:::

🔁 **Point de pause.** Reprends après cinq minutes. La suite change de sujet : on passe au verbe.

## 5. À quoi sert l'impératif

::: definition Impératif
L'**impératif** sert à donner un ordre, une consigne, un conseil ou une indication de chemin.
`Gira a la derecha.` → Tourne à droite.
:::

::: retenir Les deux formes utiles en 4ᵉ
`tú` : quand on tutoie une personne. `Gira.`
`usted` : quand on vouvoie une personne. `Gire.`
Ce sont les deux seules formes à maîtriser cette année.
:::

## 6. L'impératif affirmatif régulier

::: formule
**Forme `tú`** : on prend la **3ᵉ personne du singulier du présent**, sans le `s`.
`hablar` → `él habla` → `¡Habla!`
`comer` → `él come` → `¡Come!`
`subir` → `él sube` → `¡Sube!`
:::

::: grille
| Infinitif | Présent, `él` | Impératif `tú` | Impératif `usted` |
|---|---|---|---|
| `hablar` | habla | **habla** | **hable** |
| `girar` | gira | **gira** | **gire** |
| `comer` | come | **come** | **coma** |
| `beber` | bebe | **bebe** | **beba** |
| `subir` | sube | **sube** | **suba** |
| `escribir` | escribe | **escribe** | **escriba** |
:::

::: formule
**Forme `usted`** : on **échange la voyelle**.
Verbes en `-ar` → terminaison en **`-e`** : `hable`, `gire`.
Verbes en `-er` et `-ir` → terminaison en **`-a`** : `coma`, `suba`.
:::

::: retenir Le moyen de retenir l'échange
Les verbes en `-ar` prennent la voyelle des verbes en `-er`, et inversement.
C'est un échange de voyelles, rien de plus.
:::

## 7. Les huit irréguliers

::: grille
| Infinitif | Sens | Impératif `tú` | Impératif `usted` |
|---|---|---|---|
| `ir` | aller | **ve** | **vaya** |
| `venir` | venir | **ven** | **venga** |
| `hacer` | faire | **haz** | **haga** |
| `decir` | dire | **di** | **diga** |
| `poner` | mettre | **pon** | **ponga** |
| `salir` | sortir | **sal** | **salga** |
| `tener` | avoir | **ten** | **tenga** |
| `ser` | être | **sé** | **sea** |
:::

::: retenir Le moyen mnémotechnique
Les formes en `tú` sont toutes **très courtes**, souvent d'une syllabe : `ve`, `ven`, `haz`, `di`, `pon`, `sal`, `ten`, `sé`.
Les formes en `usted` se construisent presque toutes sur la 1ʳᵉ personne du présent : `tengo` → `tenga`, `pongo` → `ponga`, `salgo` → `salga`.
:::

::: piege `ve` a deux sens
`ve` est l'impératif de `ir`, aller, **et** celui de `ver`, voir.
Le contexte tranche : `Ve al museo` = va au musée. `Ve la película` = regarde le film.
:::

## 8. L'impératif négatif

::: formule
**Négatif `tú`** : `no` + la forme de `usted` + `s`
`¡Gira!` → `¡No gires!`
`¡Come!` → `¡No comas!`

**Négatif `usted`** : `no` + la forme de `usted`, inchangée
`¡Gire!` → `¡No gire!`
:::

::: grille
| Verbe | Affirmatif `tú` | Négatif `tú` | Négatif `usted` |
|---|---|---|---|
| `girar` | gira | **no gires** | **no gire** |
| `comer` | come | **no comas** | **no coma** |
| `subir` | sube | **no subas** | **no suba** |
| `ir` | ve | **no vayas** | **no vaya** |
| `hacer` | haz | **no hagas** | **no haga** |
:::

::: piege Le négatif ne se forme jamais sur l'affirmatif
On ne dit **jamais** `no gira` pour « ne tourne pas ».
Le négatif se construit sur la forme de `usted`, à laquelle on ajoute un `s` pour le tutoiement.
C'est la difficulté principale de ce chapitre.
:::

::: exemple Les quatre formes d'un même verbe
`girar`, tourner :
Affirmatif `tú` : `¡Gira!`
Affirmatif `usted` : `¡Gire!`
Négatif `tú` : `¡No gires!`
Négatif `usted` : `¡No gire!`
:::

## 9. Les verbes du déplacement

::: grille
| Espagnol | Français |
|---|---|
| `girar` | tourner |
| `torcer` | tourner, plus rare |
| `seguir` | continuer, suivre |
| `cruzar` | traverser |
| `coger` | prendre |
| `bajar` | descendre |
| `subir` | monter |
| `pasar por` | passer par |
| `llegar a` | arriver à |
| `estar a ... minutos` | être à ... minutes |
:::

::: formule
**Les expressions toutes faites**
`Sigue todo recto.` → Continue tout droit.
`Gira a la derecha.` → Tourne à droite.
`Gira a la izquierda.` → Tourne à gauche.
`Cruza la plaza.` → Traverse la place.
`Coge la primera calle.` → Prends la première rue.
`Está a diez minutos.` → C'est à dix minutes.
:::

::: piege `seguir` change de voyelle
`seguir` est un verbe à diphtongue : `e` devient `i`.
`él sigue`, donc impératif `tú` : `sigue`. Et impératif `usted` : `siga`.
:::

## 10. Le dialogue type

::: exemple Demander et indiquer un chemin
`A. Perdone, ¿dónde está el museo, por favor?`
`B. Siga todo recto hasta el semáforo. Luego gire a la izquierda. El museo está al final de la calle, enfrente del parque.`
`A. ¿Está lejos?`
`B. No, está a cinco minutos a pie.`
`A. Muchas gracias.`
`B. De nada.`
:::

::: methode Indiquer un chemin en quatre étapes
1. Donne la **première direction** : `Siga todo recto.`
2. Donne un **repère** : `hasta el semáforo`, `hasta la plaza`.
3. Donne la **deuxième direction** : `Luego gire a la derecha.`
4. Situe l'**arrivée** : `Está al lado del banco.`
:::

::: aide Les mots qui enchaînent les étapes
`primero` → d'abord
`luego` ou `después` → ensuite
`por fin` ou `al final` → enfin
`hasta` → jusqu'à
Sans ces mots, l'itinéraire devient une liste, pas un parcours.
:::

## 11. Écrire un itinéraire

::: methode Rédiger un itinéraire en cinq lignes
1. Annonce le point de départ : `Sal de la estación.`
2. Première direction avec un repère.
3. Deuxième direction avec un repère.
4. Une précision de distance ou de durée.
5. La position finale avec une préposition de lieu.
:::

::: exemple Un itinéraire rédigé
« `Sal de la estación y cruza la plaza. Sigue todo recto por la avenida principal hasta el segundo semáforo. Luego gira a la derecha y coge la primera calle a la izquierda. Está a unos siete minutos a pie. La biblioteca está al final de la calle, al lado del ayuntamiento y enfrente del mercado.` »

Compte : cinq impératifs, trois prépositions de lieu, deux repères, une durée.
:::

::: aide Si tu bloques à l'écrit
Écris d'abord l'itinéraire **en français**, en cinq étapes numérotées.
Traduis ensuite chaque étape séparément.
Vérifie en dernier que chaque verbe est bien à l'impératif et non à l'infinitif.
:::

## 12. Les pièges à éviter

::: piege 1. L'impératif négatif
`¡No gires!` et jamais `¡No gira!`. Le négatif se construit sur la forme de `usted`.
:::

::: piege 2. Les contractions
`de` + `el` = `del`, `a` + `el` = `al`. Jamais `de el` ni `a el`.
:::

::: piege 3. `en` et `a` pour les transports
`en autobús`, `en coche`, mais `a pie`.
:::

::: piege 4. `librería` et `biblioteca`
`la librería` est la **librairie**. La bibliothèque se dit `la biblioteca`.
:::

::: piege 5. `¿Dónde está?` et `¿Dónde hay?`
`está` pour un lieu précis que je cherche, `hay` pour n'importe lequel.
:::

::: piege 6. L'infinitif à la place de l'impératif
`Girar a la derecha` n'est pas une consigne mais un infinitif. On dit `Gira` ou `Gire`.
:::

::: piege 7. Les irréguliers courts
`ve`, `ven`, `haz`, `di`, `pon`, `sal`, `ten`, `sé`. Il faut les connaître par cœur.
:::

::: piege 8. Les accents
`está` porte un accent, `esta` sans accent signifie « cette ». `aquí`, `después`, `avenida` : vérifie chaque accent.
:::

::: cocher
- Je connais vingt mots de la ville et dix de transport
- Je forme l'impératif affirmatif en tú et en usted
- Je forme l'impératif négatif sans le calquer sur l'affirmatif
- Je connais les huit irréguliers
- Je sais demander et indiquer un chemin en cinq étapes
:::
