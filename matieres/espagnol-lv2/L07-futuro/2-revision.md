## 1. Les trois formes

::: grille
| Forme | Construction | Valeur | Exemple |
|---|---|---|---|
| **Présent** | présent + marqueur | programmé, certain | `Mañana voy al cine.` |
| **`Ir a` + infinitif** | `voy a`, `vas a`, `va a`... | intention, décision | `Voy a ir al cine.` |
| **Futur simple** | infinitif + terminaison | prédiction, promesse, lointain | `Iré al cine.` |
:::

::: piege Le `a` est obligatoire
❌ `Voy estudiar` → ✅ `Voy a estudiar`. Le français, lui, n'en met pas.
:::

## 2. Le futur simple régulier

::: formule-cle
```
infinitif COMPLET + é, ás, á, emos, éis, án
```
Une seule série de terminaisons pour tous les verbes, en `-ar`, `-er` et `-ir`.
:::

::: grille
| Personne | `hablar` | `comer` | `vivir` |
|---|---|---|---|
| `yo` | `hablaré` | `comeré` | `viviré` |
| `tú` | `hablarás` | `comerás` | `vivirás` |
| `él`, `ella`, `usted` | `hablará` | `comerá` | `vivirá` |
| `nosotros` | `hablaremos` | `comeremos` | `viviremos` |
| `vosotros` | `hablaréis` | `comeréis` | `viviréis` |
| `ellos`, `ellas`, `ustedes` | `hablarán` | `comerán` | `vivirán` |
:::

::: retenir Les accents
Cinq formes sur six portent un accent écrit. Seule `-emos` n'en a pas. C'est la faute la plus fréquente à l'écrit.
:::

## 3. Les douze irréguliers

::: grille
| Groupe | Verbes et radicaux |
|---|---|
| **Voyelle qui tombe** | `caber` → `cabr-`, `haber` → `habr-`, `poder` → `podr-`, `querer` → `querr-`, `saber` → `sabr-` |
| **`d` qui apparaît** | `poner` → `pondr-`, `salir` → `saldr-`, `tener` → `tendr-`, `valer` → `valdr-`, `venir` → `vendr-` |
| **Radical raccourci** | `decir` → `dir-`, `hacer` → `har-` |
:::

::: formule-cle
Seul le **radical** change. Les **terminaisons** restent `é, ás, á, emos, éis, án`.
`tendré, tendrás, tendrá, tendremos, tendréis, tendrán`.
:::

::: retenir Les composés suivent
`obtener` → `obtendré`, `componer` → `compondré`, `deshacer` → `desharé`.
:::

::: piege `habrá` au singulier
`Habrá dos exámenes.` et jamais `habrán`.
:::

## 4. Choisir la forme

::: formule-cle
1. **Programmé**, heure ou date fixée → **présent**.
2. **Intention**, décision prise → **`ir a`** + infinitif.
3. **Prédiction**, promesse, lointain → **futur simple**.
:::

::: grille
| Situation | Forme | Exemple |
|---|---|---|
| Horaire de train | présent | `El tren sale a las ocho.` |
| Projet pour ce soir | `ir a` | `Voy a ver una película.` |
| Promesse | futur simple | `Te ayudaré.` |
| Prédiction météo | futur simple | `Mañana lloverá.` |
| Décision immédiate | `ir a` | `Vale, voy a llamarla ahora.` |
:::

::: retenir À l'oral
`Ir a` + infinitif domine largement. Si tu hésites, c'est presque toujours acceptable.
:::

## 5. Le futur de probabilité

::: formule-cle
```
futur simple = hypothèse sur le PRÉSENT
```
`Serán las tres.` → Il doit être trois heures.
`Estará en el instituto.` → Elle doit être au lycée.
:::

::: retenir Comment le traduire
Par « il doit », « sans doute », « ce doit être ». Le verbe est au futur, la phrase parle du présent.
:::

## 6. Les marqueurs temporels

::: grille
| Espagnol | Français |
|---|---|
| `mañana`, `pasado mañana` | demain, après-demain |
| `esta tarde`, `esta noche` | cet après-midi, ce soir |
| `la semana que viene`, `la próxima semana` | la semaine prochaine |
| `el año que viene` | l'an prochain |
| `dentro de dos días` | dans deux jours |
| `pronto`, `luego`, `más tarde` | bientôt, ensuite, plus tard |
| `algún día` | un jour |
:::

::: piege `dentro de` et `en`
`Volveré dentro de dos días.` → dans deux jours.
`Lo haré en dos días.` → en deux jours, c'est-à-dire la durée nécessaire.
:::

## 7. `Cuando` et `si`

::: formule-cle
```
si + présent de l'INDICATIF        →  Si llueve, no saldré.
cuando + présent du SUBJONCTIF     →  Cuando llueva, no saldré.
```
Jamais de futur après `si` ni après `cuando`.
:::

::: grille
| Français | Espagnol |
|---|---|
| quand tu arriveras | `cuando llegues` |
| quand je serai grande | `cuando sea mayor` |
| dès que tu pourras | `en cuanto puedas` |
| jusqu'à ce que tu finisses | `hasta que termines` |
| s'il pleut | `si llueve` |
| si tu as le temps | `si tienes tiempo` |
:::

::: retenir Trois `cuando`, trois modes
`Cuando llego, ceno.` habitude, indicatif présent.
`Cuando llegué, no había nadie.` passé, indicatif.
`Cuando llegue, te llamo.` avenir, **subjonctif**.
:::

## 8. Les formules de projets

::: motscles
- `Tengo la intención de + infinitif`
- `Pienso + infinitif`
- `Me gustaría + infinitif`
- `Quiero + infinitif`
- `Espero + infinitif`
- `Tengo ganas de + infinitif`
- `Estoy pensando en + infinitif`
- `Mi sueño es + infinitif`
- `Algún día...`
- `¿Qué vas a hacer...?`
- `¿Tienes planes para...?`
:::

::: formule-cle
Un paragraphe de projets : marqueur temporel, intention avec `voy a` ou `pienso`, justification avec `porque`, condition avec `si` ou moment avec `cuando`, projet lointain au futur simple.
:::

## 10. Les huit pièges

::: piege 1. Le `a` de `ir a`
❌ `Voy estudiar` → ✅ `Voy a estudiar`.
:::

::: piege 2. L'infinitif entier
`hablar` + `é` = `hablaré`. On n'enlève rien.
:::

::: piege 3. Les accents
Cinq formes sur six en portent un. Seule `-emos` n'en a pas.
:::

::: piege 4. `habrá` au singulier
Jamais `habrán`.
:::

::: piege 5. Futur après `si`
❌ `Si lloverá` → ✅ `Si llueve`.
:::

::: piege 6. Indicatif après `cuando` pour l'avenir
❌ `Cuando llegarás` → ✅ `Cuando llegues`.
:::

::: piege 7. `si` et `cuando`
`si` + indicatif, `cuando` + subjonctif.
:::

::: piege 8. Le futur de probabilité
`Serán las tres` = il doit être trois heures.
:::

## 11. Auto-test

Réponds sans regarder la fiche de cours. Les réponses sont juste en dessous.

::: exercice 1 | application | 10 min | ecran
1. Donne les six terminaisons du futur simple.
2. Conjugue `viajar` au futur, à toutes les personnes.
3. Donne le radical du futur de : `tener`, `poder`, `hacer`, `decir`, `salir`, `saber`.
4. Traduis : « Je vais étudier ce soir. »
5. Traduis : « Il doit être dix heures. »
6. Complète : `Si ... (llover), no ... (salir, nosotros).`
7. Complète : `Cuando ... (llegar, tú), te ... (llamar, yo).`
8. Quelle différence de construction y a-t-il entre `si` et `cuando` ?
9. Traduis : « dans trois jours » et « la semaine prochaine », de deux façons.
10. Écris une phrase de projet avec `pienso` et une avec `algún día`.

::: corrige
1. `-é, -ás, -á, -emos, -éis, -án`. Une seule série pour tous les verbes.
2. `viajaré, viajarás, viajará, viajaremos, viajaréis, viajarán`. Accent écrit partout sauf à `viajaremos`.
3. `tener` → `tendr-` ; `poder` → `podr-` ; `hacer` → `har-` ; `decir` → `dir-` ; `salir` → `saldr-` ; `saber` → `sabr-`.
4. `Voy a estudiar esta noche.` Ne pas oublier le `a`.
5. `Serán las diez.` Futur de probabilité : le futur exprime une hypothèse sur le présent.
6. `Si **llueve**, no **saldremos**.` Présent de l'indicatif après `si`, futur dans le résultat. `Salir` est irrégulier : `saldr-`.
7. `Cuando **llegues**, te **llamo**.` Subjonctif présent après `cuando` au sens futur ; on accepte aussi `te llamaré`.
8. `si` est suivi du présent de l'**indicatif**, `cuando` au sens futur est suivi du présent du **subjonctif**. Ni l'un ni l'autre n'admet le futur.
9. « Dans trois jours » : `dentro de tres días`. « La semaine prochaine » : `la semana que viene` ou `la próxima semana`.
10. Par exemple : `Pienso aprender alemán el año que viene.` et `Algún día viviré en España.`
:::
:::

::: cocher
- Je sais les six terminaisons sans notes
- Je sais les douze radicaux irréguliers
- Je n'oublie pas le `a` de `ir a`
- Je mets l'indicatif après `si` et le subjonctif après `cuando`
- Je reconnais le futur de probabilité
- J'ai eu au moins 8 bonnes réponses sur 10 à l'auto-test
:::
