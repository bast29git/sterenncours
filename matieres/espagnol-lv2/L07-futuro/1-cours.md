## 1. Les trois façons de parler du futur

::: grille
| Forme | Construction | Valeur |
|---|---|---|
| **Présent** | présent de l'indicatif | futur **proche et certain**, souvent programmé |
| **`Ir a` + infinitif** | `voy a`, `vas a`, `va a`... | **intention**, projet décidé |
| **Futur simple** | infinitif + terminaison | futur **plus lointain**, prédiction, promesse |
:::

::: exemple La même idée, trois formes
- `Mañana voy al cine.` Demain je vais au cinéma. **C'est prévu, les places sont prises.**
- `Mañana voy a ir al cine.` Demain je vais aller au cinéma. **C'est mon intention.**
- `Mañana iré al cine.` Demain j'irai au cinéma. **Prédiction ou décision, plus neutre.**
:::

::: retenir Les trois sont correctes
Aucune des trois n'est fausse. Le choix apporte une **nuance**, comme en français entre « je vais y aller » et « j'irai ». Ce que l'on attend de toi, c'est de savoir construire les trois et de comprendre ce qu'elles ajoutent.
:::

::: aide L'ordre d'apprentissage
Commence par maîtriser `ir a` + infinitif, qui est la plus employée à l'oral et la plus simple. Le futur simple vient ensuite : il demande un tableau de terminaisons et douze irréguliers.
:::

## 2. Le présent à valeur de futur

::: formule La construction

```
présent de l'indicatif + marqueur de temps futur
```
:::

::: exemple Des projets programmés
- `El tren sale a las ocho.` Le train part à huit heures.
- `Mañana tengo clase de música.` Demain j'ai cours de musique.
- `La semana que viene vamos a Sevilla.` La semaine prochaine nous allons à Séville.
:::

::: retenir Quand l'employer
Quand l'événement est **programmé** et **certain** : horaires, emploi du temps, rendez-vous pris. Le français fait exactement la même chose : « demain je pars à huit heures ».
:::

::: piege Il faut un marqueur de temps
Sans `mañana`, `la semana que viene` ou une heure, le présent reste un présent. C'est le **marqueur** qui projette la phrase dans l'avenir.
:::

## 3. `Ir a` + infinitif

::: formule La construction

```
ir (conjugué au présent) + a + infinitif
```
:::

::: grille
| Personne | Forme |
|---|---|
| `yo` | `voy a` |
| `tú` | `vas a` |
| `él`, `ella`, `usted` | `va a` |
| `nosotros` | `vamos a` |
| `vosotros` | `vais a` |
| `ellos`, `ellas`, `ustedes` | `van a` |
:::

::: exemple L'intention
- `Voy a estudiar esta tarde.` Je vais étudier cet après-midi.
- `¿Qué vas a hacer el sábado?` Qu'est-ce que tu vas faire samedi ?
- `Vamos a comprar el billete mañana.` Nous allons acheter le billet demain.
:::

::: piege Le `a` est obligatoire
On ne dit jamais `voy estudiar`. La préposition `a` fait partie de la construction, comme en français « je vais **à** » ? Non, justement : le français n'en met pas. C'est une différence à mémoriser.

```
❌ Voy estudiar.
✅ Voy a estudiar.
```
:::

::: retenir Le sens précis
`Ir a` + infinitif exprime une **intention** ou une décision déjà prise. C'est la forme la plus employée à l'oral pour parler de l'avenir proche, exactement comme « je vais faire » en français.
:::

::: exemple Deux nuances proches
- `Voy a llamarla.` Je vais l'appeler. → j'ai décidé, je le ferai bientôt.
- `La llamaré.` Je l'appellerai. → promesse ou prédiction, sans indication de moment.
:::

## 4. Le futur simple : les réguliers

::: formule La construction

```
infinitif COMPLET + terminaison
```

On n'enlève rien : la terminaison s'ajoute à l'infinitif entier.
:::

::: grille
| Personne | Terminaison | `hablar` | `comer` | `vivir` |
|---|---|---|---|---|
| `yo` | `-é` | `hablaré` | `comeré` | `viviré` |
| `tú` | `-ás` | `hablarás` | `comerás` | `vivirás` |
| `él`, `ella`, `usted` | `-á` | `hablará` | `comerá` | `vivirá` |
| `nosotros` | `-emos` | `hablaremos` | `comeremos` | `viviremos` |
| `vosotros` | `-éis` | `hablaréis` | `comeréis` | `viviréis` |
| `ellos`, `ellas`, `ustedes` | `-án` | `hablarán` | `comerán` | `vivirán` |
:::

::: retenir Une seule série de terminaisons
Contrairement au présent, il n'y a **pas** trois séries selon `-ar`, `-er` ou `-ir` : les six terminaisons sont les **mêmes pour tous les verbes**. C'est le temps le plus simple de l'espagnol.
:::

::: aide L'accent écrit
Cinq personnes sur six portent un **accent écrit** : `-é`, `-ás`, `-á`, `-éis`, `-án`. Seule la forme `nosotros` en `-emos` n'en porte pas.
Oublier ces accents est la faute la plus fréquente à l'écrit, et elle est comptée.
:::

::: exemple Des phrases complètes
- `Mañana estudiaré para el examen.` Demain j'étudierai pour l'examen.
- `El año que viene viviremos en Madrid.` L'an prochain nous vivrons à Madrid.
- `¿Comerás con nosotros?` Tu mangeras avec nous ?
:::

::: pause
Fin de la séance 1. Trois formes vues. Avant de continuer, conjugue `viajar` au futur simple aux six personnes.
:::

## 5. Les douze irréguliers

::: retenir Ce qui change, et ce qui ne change pas
Les **terminaisons** ne changent jamais. Seul le **radical** est modifié. Il suffit donc d'apprendre douze radicaux, et de leur coller les six terminaisons déjà connues.
:::

::: grille
| Groupe | Verbe | Radical | Exemple |
|---|---|---|---|
| **Voyelle qui disparaît** | `caber` | `cabr-` | `cabré` |
| | `haber` | `habr-` | `habrá` |
| | `poder` | `podr-` | `podré` |
| | `querer` | `querr-` | `querré` |
| | `saber` | `sabr-` | `sabré` |
| **`d` qui apparaît** | `poner` | `pondr-` | `pondré` |
| | `salir` | `saldr-` | `saldré` |
| | `tener` | `tendr-` | `tendré` |
| | `valer` | `valdr-` | `valdrá` |
| | `venir` | `vendr-` | `vendré` |
| **Radical raccourci** | `decir` | `dir-` | `diré` |
| | `hacer` | `har-` | `haré` |
:::

::: aide Comment retenir les trois groupes
- **Groupe 1** : la voyelle de la terminaison de l'infinitif **tombe**. `poder` → `pod(e)r` → `podr-`.
- **Groupe 2** : la voyelle tombe **et** un `d` apparaît pour faciliter la prononciation. `tener` → `ten(e)r` → `tendr-`.
- **Groupe 3** : deux verbes entièrement raccourcis, `decir` et `hacer`. Il faut les apprendre tels quels.
:::

::: retenir Les composés suivent
`obtener`, `mantener`, `detener` suivent `tener` : `obtendré`, `mantendré`, `detendré`.
`deshacer` suit `hacer` : `desharé`. `componer` suit `poner` : `compondré`.
Apprendre douze verbes revient donc à en maîtriser bien davantage.
:::

::: exemple Le tableau à l'œuvre
- `Tendré quince años en mayo.` J'aurai quinze ans en mai.
- `No podré venir el sábado.` Je ne pourrai pas venir samedi.
- `¿Qué harás este verano?` Que feras-tu cet été ?
- `Te diré la verdad.` Je te dirai la vérité.
- `Saldremos a las siete.` Nous sortirons à sept heures.
:::

::: piege `habrá`, forme unique
`haber` au futur donne `habrá` au sens de « il y aura », toujours au **singulier**, même devant un pluriel.

```
✅ Habrá mucha gente.       Il y aura beaucoup de monde.
✅ Habrá dos exámenes.      Il y aura deux examens.
❌ Habrán dos exámenes.
```
:::

## 6. Quand choisir quelle forme

::: methode La question à se poser
1. L'événement est-il **programmé**, avec une heure ou une date fixée ? → **présent**.
2. S'agit-il d'une **intention** ou d'une décision déjà prise ? → **`ir a` + infinitif**.
3. S'agit-il d'une **prédiction**, d'une **promesse** ou d'un futur **lointain** ? → **futur simple**.
:::

::: grille
| Situation | Forme attendue | Exemple |
|---|---|---|
| Un horaire de train | présent | `El tren sale a las ocho.` |
| Un projet pour ce soir | `ir a` | `Voy a ver una película.` |
| Une promesse | futur simple | `Te ayudaré, no te preocupes.` |
| Une prédiction météo | futur simple | `Mañana lloverá en el norte.` |
| Un rendez-vous pris | présent | `El lunes tengo dentista.` |
| Une décision qui vient d'être prise | `ir a` | `Vale, voy a llamarla ahora.` |
:::

::: retenir Ce que fait l'oral
Dans la conversation courante, `ir a` + infinitif domine largement. Le futur simple est plus fréquent à l'écrit, dans la presse et dans les prédictions. Si tu hésites à l'oral, `ir a` + infinitif est presque toujours acceptable.
:::

## 7. Le futur de probabilité

::: formule L'emploi

```
futur simple = hypothèse sur le PRÉSENT
```
:::

::: exemple Des hypothèses, pas des prédictions
- `¿Qué hora es?` `Serán las tres.` Quelle heure est-il ? Il doit être trois heures.
- `¿Dónde está Ana?` `Estará en el instituto.` Où est Ana ? Elle doit être au lycée.
- `Tendrá unos veinte años.` Il doit avoir la vingtaine.
:::

::: retenir Comment le reconnaître
Le verbe est au **futur**, mais la phrase parle du **présent**. En français, on traduit par « il doit être », « il est sans doute », « ce doit être ».
C'est un emploi très fréquent en espagnol, et il surprend souvent les francophones.
:::

::: grille
| Espagnol | Traduction |
|---|---|
| `Serán las diez.` | Il doit être dix heures. |
| `Estará cansado.` | Il doit être fatigué. |
| `Habrá unas cien personas.` | Il doit y avoir une centaine de personnes. |
| `No sé, será que no le gusta.` | Je ne sais pas, c'est sans doute qu'il n'aime pas ça. |
:::

::: piege Ne confonds pas les deux emplois
`Estará en casa.` peut signifier « il sera à la maison » (futur réel) ou « il doit être à la maison » (probabilité au présent). C'est le **contexte** qui tranche, en particulier la présence ou l'absence d'un marqueur de temps futur.
:::

## 8. Les marqueurs temporels

::: grille
| Espagnol | Français |
|---|---|
| `mañana` | demain |
| `pasado mañana` | après-demain |
| `esta tarde`, `esta noche` | cet après-midi, ce soir |
| `la semana que viene`, `la próxima semana` | la semaine prochaine |
| `el mes que viene`, `el año que viene` | le mois prochain, l'an prochain |
| `dentro de dos días` | dans deux jours |
| `pronto` | bientôt |
| `luego`, `más tarde` | ensuite, plus tard |
| `algún día` | un jour |
| `en el futuro` | à l'avenir |
:::

::: piege `dentro de` et `en`
Pour dire « dans deux jours », on emploie `dentro de dos días`. La construction `en dos días` existe mais signifie plutôt « en deux jours », c'est-à-dire la durée nécessaire pour faire quelque chose.

```
Volveré dentro de dos días.    Je reviendrai dans deux jours.
Lo haré en dos días.           Je le ferai en deux jours.
```
:::

::: retenir `que viene` et `próximo`
Les deux se valent : `la semana que viene` et `la próxima semana` sont équivalents. Attention à la place : `próximo` se met **avant** le nom, `que viene` **après**.
:::

## 9. `Cuando` et le subjonctif

::: formule La règle

```
cuando + subjonctif présent  ,  futur ou présent
```

Jamais le futur de l'indicatif après `cuando` quand on parle de l'avenir.
:::

::: exemple La construction
- `Cuando llegues, te llamo.` Quand tu arriveras, je t'appelle.
- `Cuando sea mayor, viajaré.` Quand je serai grande, je voyagerai.
- `Te lo diré cuando lo sepa.` Je te le dirai quand je le saurai.
:::

::: retenir La différence avec le français
Le français emploie le **futur** après « quand » : « quand tu arriveras ». L'espagnol emploie le **subjonctif présent** : `cuando llegues`.
C'est l'une des différences les plus visibles entre les deux langues, et l'une des plus évaluées.
:::

::: grille
| Français | Espagnol |
|---|---|
| quand tu arriveras | `cuando llegues` |
| quand je serai grande | `cuando sea mayor` |
| quand nous aurons le temps | `cuando tengamos tiempo` |
| dès que tu pourras | `en cuanto puedas` |
| jusqu'à ce que tu finisses | `hasta que termines` |
:::

::: retenir D'autres conjonctions suivent la même règle
`en cuanto` (dès que), `hasta que` (jusqu'à ce que), `mientras` (tant que), `antes de que` (avant que) fonctionnent comme `cuando` : **subjonctif** quand on parle de l'avenir.
:::

::: piege `Cuando` au passé ou au présent habituel
Quand `cuando` décrit une habitude ou un fait passé, on emploie l'**indicatif** :

```
Cuando llego a casa, ceno.        Quand j'arrive à la maison, je dîne. (habitude)
Cuando llegué, no había nadie.    Quand je suis arrivée, il n'y avait personne. (passé)
Cuando llegue, te llamo.          Quand j'arriverai, je t'appelle. (futur, subjonctif)
```

Trois phrases très proches, trois modes différents.
:::

## 10. Les phrases avec `si`

::: formule La règle

```
si + présent de l'indicatif  ,  futur ou présent ou impératif
```

Jamais de futur ni de conditionnel après `si`.
:::

::: exemple La construction
- `Si llueve, no saldremos.` S'il pleut, nous ne sortirons pas.
- `Si tienes tiempo, llámame.` Si tu as le temps, appelle-moi.
- `Si estudias, aprobarás.` Si tu étudies, tu réussiras.
:::

::: piege L'erreur à ne jamais commettre

```
❌ Si lloverá, no saldremos.
✅ Si llueve, no saldremos.
```

Le français fait exactement la même chose : on ne dit pas « s'il pleuvra ». La règle est donc facile à retenir, mais elle est souvent oubliée par inattention.
:::

::: retenir `Si` et `cuando` ne se construisent pas pareil
C'est le point le plus délicat de la leçon.

```
si + présent de l'INDICATIF        →  Si llueve, no saldré.
cuando + présent du SUBJONCTIF     →  Cuando llueva, no saldré.
```

`si` exprime une condition incertaine, `cuando` un moment qui arrivera.
:::

## 11. Parler de ses projets

::: grille
| Formule | Traduction |
|---|---|
| `Tengo la intención de...` | J'ai l'intention de... |
| `Pienso + infinitif` | Je compte... |
| `Me gustaría + infinitif` | J'aimerais... |
| `Quiero + infinitif` | Je veux... |
| `Espero + infinitif` | J'espère... |
| `Tengo ganas de + infinitif` | J'ai envie de... |
| `Estoy pensando en + infinitif` | Je pense à... |
| `Mi sueño es + infinitif` | Mon rêve est de... |
:::

::: exemple Un paragraphe de projets
> El año que viene voy a estudiar más idiomas.
> Pienso aprender alemán, porque me gusta viajar.
> Cuando termine el instituto, me gustaría vivir un año en España.
> Si encuentro un intercambio, iré a Sevilla.
> Algún día trabajaré en algo relacionado con las lenguas.

Cinq phrases, cinq constructions différentes. C'est exactement ce qu'on attend en 4ème.
:::

::: methode Construire un paragraphe de projets
1. **Ouvre** par un marqueur temporel : `El año que viene...`
2. **Annonce** une intention avec `voy a` ou `pienso`.
3. **Justifie** avec `porque`.
4. **Ajoute** une condition avec `si` ou un moment avec `cuando`.
5. **Conclus** par un projet lointain au futur simple : `Algún día...`
:::

::: grille
| Question utile à l'oral | Traduction |
|---|---|
| `¿Qué vas a hacer este fin de semana?` | Que vas-tu faire ce week-end ? |
| `¿Qué harás cuando termines el instituto?` | Que feras-tu quand tu auras fini le lycée ? |
| `¿Tienes planes para el verano?` | As-tu des projets pour l'été ? |
| `¿Y tú, qué piensas hacer?` | Et toi, que comptes-tu faire ? |
:::

::: aide Prononciation
Les formes du futur portent l'accent tonique sur la **dernière syllabe** : `hablaré`, `saldrá`, `tendrán`. Exagère cet accent en t'entraînant : c'est lui qui permet de distinguer `hablo` de `hablará` à l'oreille.
:::

## 12. Les pièges à éviter

::: piege 1. Le `a` de `ir a`
❌ `Voy estudiar` → ✅ `Voy a estudiar`. La préposition est obligatoire.
:::

::: piege 2. L'infinitif entier au futur
On ajoute la terminaison à l'**infinitif complet** : `hablar` + `é` = `hablaré`. On n'enlève rien.
:::

::: piege 3. Les accents écrits
Cinq formes sur six en portent un : `-é`, `-ás`, `-á`, `-éis`, `-án`. Seule `-emos` n'en a pas.
:::

::: piege 4. `habrá` toujours au singulier
`Habrá dos exámenes.` et jamais `habrán`.
:::

::: piege 5. Futur après `si`
❌ `Si lloverá` → ✅ `Si llueve`. Comme en français.
:::

::: piege 6. Indicatif après `cuando` pour l'avenir
❌ `Cuando llegarás` → ✅ `Cuando llegues`. Subjonctif présent.
:::

::: piege 7. Confondre `si` et `cuando`
`si` + **indicatif**, `cuando` + **subjonctif** quand il s'agit de l'avenir.
:::

::: piege 8. Oublier le futur de probabilité
`Serán las tres` ne veut pas dire « il sera trois heures » mais « il doit être trois heures ».
:::

::: retenir Les cinq phrases du chapitre
1. Trois formes pour le futur : le **présent** programmé, **`ir a`** + infinitif pour l'intention, le **futur simple** pour la prédiction.
2. Le futur simple s'obtient en ajoutant les terminaisons à l'**infinitif complet**, avec une seule série pour tous les verbes.
3. Douze **irréguliers** seulement, et les terminaisons ne changent jamais.
4. Après **`si`**, présent de l'**indicatif** ; après **`cuando`** au sens futur, présent du **subjonctif**.
5. Le futur peut exprimer une **probabilité au présent** : `Serán las tres.`
:::
