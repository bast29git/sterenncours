## 1. Se présenter en cinq phrases

::: motscles
- `Me llamo…`
- `Tengo … años.`
- `Soy … y vivo en…`
- `Me gusta…`
- `Estudio…`
:::

::: formule-cle
Pour l'âge, on emploie **tener**, jamais `ser`.
`Tengo trece años.`
:::

## 2. Le présent des verbes réguliers

::: grille
| | **hablar** | **comer** | **vivir** |
|---|---|---|---|
| yo | habl**o** | com**o** | viv**o** |
| tú | habl**as** | com**es** | viv**es** |
| él, ella | habl**a** | com**e** | viv**e** |
| nosotros | habl**amos** | com**emos** | viv**imos** |
| vosotros | habl**áis** | com**éis** | viv**ís** |
| ellos, ellas | habl**an** | com**en** | viv**en** |
:::

::: formule-cle
Les groupes en **-er** et en **-ir** ont les **mêmes terminaisons**, sauf à `nosotros` et `vosotros`.
Cela divise par deux ce qu'il y a à mémoriser.
:::

::: methode Conjuguer un verbe inconnu
::: etapes
1. Je repère la terminaison : `-ar`, `-er` ou `-ir`.
2. Je retire cette terminaison : il reste le **radical**.
3. J'ajoute la terminaison de la personne et du groupe.
:::
:::

## 3. Les deux verbes irréguliers indispensables

::: grille
| | **ser** (être) | **tener** (avoir) |
|---|---|---|
| yo | soy | tengo |
| tú | eres | tienes |
| él, ella | es | tiene |
| nosotros | somos | tenemos |
| vosotros | sois | tenéis |
| ellos, ellas | son | tienen |
:::

::: info Pourquoi ces deux-là d'abord
Ils servent dans presque toutes les phrases de présentation : l'identité avec `ser`, l'âge et la possession avec `tener`. Ils ne suivent aucun modèle, donc ils s'apprennent par cœur.
:::

## 4. Les verbes pronominaux

::: grille
| Personne | Pronom | `levantarse` |
|---|---|---|
| yo | `me` | `me levanto` |
| tú | `te` | `te levantas` |
| él, ella | `se` | `se levanta` |
| nosotros | `nos` | `nos levantamos` |
| vosotros | `os` | `os levantáis` |
| ellos, ellas | `se` | `se levantan` |
:::

::: formule-cle
Le pronom se place **avant** le verbe conjugué : `me levanto`.
Il se **colle à la fin** de l'infinitif : `voy a levantarme`.
:::

::: motscles
- `despertarse` : se réveiller
- `levantarse` : se lever
- `ducharse` : se doucher
- `vestirse` : s'habiller
- `peinarse` : se coiffer
- `acostarse` : se coucher
:::

## 5. L'heure

::: formule-cle
**Es la una.** pour une heure, au singulier.
**Son las…** pour toutes les autres, au pluriel.
:::

::: grille
| Français | Espagnol |
|---|---|
| une heure | `Es la una.` |
| trois heures | `Son las tres.` |
| trois heures et quart | `Son las tres y cuarto.` |
| trois heures et demie | `Son las tres y media.` |
| quatre heures moins le quart | `Son las cuatro menos cuarto.` |
| midi | `Es mediodía.` |
| minuit | `Es medianoche.` |
| à sept heures | `a las siete` |
:::

::: info Demander l'heure, dire l'horaire
`¿Qué hora es?` pour demander l'heure qu'il est.
`¿A qué hora…?` pour demander à quelle heure a lieu une action.
:::

## 6. La journée et les connecteurs

::: grille
| Espagnol | Français |
|---|---|
| `por la mañana` | le matin |
| `por la tarde` | l'après-midi |
| `por la noche` | le soir |
| `hoy` | aujourd'hui |
| `mañana` | demain |
| `todos los días` | tous les jours |
:::

::: motscles
- `primero` : d'abord
- `después` : ensuite
- `luego` : puis
- `más tarde` : plus tard
- `finalmente` : enfin
:::

::: motscles
- `desayunar` : prendre le petit déjeuner
- `comer` : manger, déjeuner
- `cenar` : dîner
- `estudiar` : étudier
- `escuchar` : écouter
- `salir` : sortir
:::

## 7. Les questions

::: grille
| Espagnol | Français |
|---|---|
| `¿Cómo te llamas?` | Comment t'appelles-tu ? |
| `¿Cuántos años tienes?` | Quel âge as-tu ? |
| `¿De dónde eres?` | D'où viens-tu ? |
| `¿Dónde vives?` | Où habites-tu ? |
| `¿A qué hora…?` | À quelle heure… ? |
| `¿Por qué?` | Pourquoi ? |
:::

::: formule-cle
Tous les mots interrogatifs portent un **accent écrit** : `cómo`, `cuántos`, `dónde`, `qué`, `cuándo`.
L'accent ne change pas la prononciation : il signale la question.
:::

## 8. Les huit pièges

::: piege 1. L'âge avec ser
`Soy trece años` est faux. On dit `tengo trece años`, avec **tener**.
:::

::: piege 2. Le signe ouvrant
`Cómo te llamas?` est incomplet. Il faut `¿Cómo te llamas?`. C'est une faute, pas une question de présentation.
:::

::: piege 3. La place du pronom
`Levanto me` est faux. Le pronom vient **avant** le verbe conjugué : `me levanto`.
:::

::: piege 4. Le pronom à l'infinitif
Après un infinitif, le pronom se **colle** : `voy a levantarme`, et non `me voy a levantar me`.
:::

::: piege 5. L'heure
`Es las tres` est faux. Le singulier ne vaut que pour une heure : `es la una`. Sinon, `son las tres`.
:::

::: piege 6. Mañana
`La mañana` = le matin. `Mañana` = demain. `Mañana por la mañana` = demain matin.
:::

::: piege 7. Por qué et porque
`¿Por qué?` en deux mots avec accent pose la question. `porque` en un mot sans accent donne la réponse.
:::

::: piege 8. Le pronom sujet systématique
`Yo hablo español` n'est pas faux, mais lourd. En espagnol, le pronom sujet s'omet sauf pour insister : la terminaison suffit.
:::

## 9. Auto-test

Réponds sans regarder la fiche de cours. Les réponses sont juste en dessous.

::: exercice 1 | application | 8 min | ecran
1. Traduis : « J'ai treize ans. »
2. Conjugue `hablar` à la première personne du singulier.
3. Conjugue `vivir` à `nosotros`.
4. Traduis : « Il est une heure. »
5. Traduis : « Il est sept heures et demie. »
6. Traduis : « Je me lève. »
7. Traduis : « Je vais me coucher. »
8. Que signifie `mañana por la mañana` ?
9. Quelle est la différence entre `¿por qué?` et `porque` ?
10. Traduis : « D'où viens-tu ? »

::: corrige
1. `Tengo trece años.` Avec **tener**, jamais `ser`.
2. `hablo`.
3. `vivimos`.
4. `Es la una.` Singulier, parce que `una` est un singulier.
5. `Son las siete y media.`
6. `Me levanto.` Le pronom avant le verbe conjugué.
7. `Voy a acostarme.` Le pronom collé à la fin de l'infinitif.
8. **Demain matin**. `Mañana` sans article = demain ; `la mañana` = le matin.
9. `¿Por qué?` en deux mots avec accent pose la question « pourquoi ? ». `porque` en un mot sans accent signifie « parce que ».
10. `¿De dónde eres?`
:::
