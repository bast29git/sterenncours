## 1. Les phrases de présentation

::: motscles
- `¿Cómo te llamas?`
- `Me llamo…`
- `¿Cuántos años tienes?`
- `Tengo … años.`
- `¿De dónde eres?`
- `Soy de…`
- `¿Dónde vives?`
- `Vivo en…`
:::

::: exemple Une présentation complète
> `¡Hola! Me llamo Sterenn.`
> `Tengo trece años.`
> `Soy francesa y vivo en Bretaña.`
> `Me gusta leer y dibujar.`
> `Estudio español desde este año.`

Cinq phrases suffisent. Chacune emploie une structure différente, et toutes sont réutilisables telles quelles.
:::

::: piege Tener años, et non être
En français on dit « j'**ai** treize ans ». En espagnol aussi : `tengo trece años`.
Mais en anglais on dit `I am thirteen`. L'erreur vient souvent de là, par contamination.
En espagnol, pour l'âge, c'est toujours le verbe **tener**.
:::

::: definition Les points d'interrogation et d'exclamation
En espagnol, une question s'ouvre par `¿` et se ferme par `?`.
Une exclamation s'ouvre par `¡` et se ferme par `!`.
`¿Cómo te llamas?` `¡Hola!`
Oublier le signe ouvrant est une faute, pas un détail de présentation.
:::

## 2. Les pronoms personnels

::: grille
| Espagnol | Français |
|---|---|
| `yo` | je |
| `tú` | tu |
| `él / ella / usted` | il / elle / vous de politesse |
| `nosotros / nosotras` | nous |
| `vosotros / vosotras` | vous |
| `ellos / ellas / ustedes` | ils / elles / vous de politesse pluriel |
:::

::: retenir
En espagnol, le pronom sujet est le plus souvent **omis**, parce que la terminaison du verbe suffit à dire qui parle.
On dit `hablo español`, pas `yo hablo español`, sauf si l'on veut insister : `yo hablo español, pero él no`.
C'est l'inverse du français, où le pronom est obligatoire.
:::

## 3. Le présent des verbes réguliers

Il existe trois groupes, selon la terminaison de l'infinitif.

::: grille
| | **hablar** (-ar) | **comer** (-er) | **vivir** (-ir) |
|---|---|---|---|
| yo | habl**o** | com**o** | viv**o** |
| tú | habl**as** | com**es** | viv**es** |
| él, ella, usted | habl**a** | com**e** | viv**e** |
| nosotros | habl**amos** | com**emos** | viv**imos** |
| vosotros | habl**áis** | com**éis** | viv**ís** |
| ellos, ellas, ustedes | habl**an** | com**en** | viv**en** |
:::

::: methode Conjuguer un verbe régulier
::: etapes
1. Je repère la **terminaison de l'infinitif** : `-ar`, `-er` ou `-ir`.
2. Je retire cette terminaison : il reste le **radical**. `hablar` → `habl-`.
3. J'ajoute la **terminaison** correspondant à la personne et au groupe.
:::
:::

::: retenir
Les groupes en `-er` et en `-ir` ont **les mêmes terminaisons**, sauf à `nosotros` et `vosotros`.
`comemos` / `vivimos`, `coméis` / `vivís`. Partout ailleurs, elles sont identiques.
Cela réduit beaucoup ce qu'il y a à mémoriser.
:::

::: exemple Conjuguer un verbe inconnu
Le verbe `escribir` signifie « écrire ». Il se termine par `-ir`.
Radical : `escrib-`.
`escribo, escribes, escribe, escribimos, escribís, escriben`.

Le même raisonnement fonctionne pour tout verbe régulier, même rencontré pour la première fois.
:::

::: info Deux verbes irréguliers indispensables
`ser` (être) : `soy, eres, es, somos, sois, son`.
`tener` (avoir) : `tengo, tienes, tiene, tenemos, tenéis, tienen`.
Ils ne suivent aucun des trois modèles. Ils s'apprennent par cœur, et ils servent dans presque toutes les phrases.
:::

::: pause
Fin de la première séance. La présentation et le présent régulier sont posés.
:::

## 4. Les verbes pronominaux

::: definition Verbe pronominal
Un **verbe pronominal** se conjugue avec un pronom qui renvoie au sujet.
À l'infinitif, il se termine par `-se` : `llamarse`, `levantarse`, `ducharse`.
:::

::: grille
| Personne | Pronom | Exemple avec `levantarse` |
|---|---|---|
| yo | `me` | `me levanto` |
| tú | `te` | `te levantas` |
| él, ella, usted | `se` | `se levanta` |
| nosotros | `nos` | `nos levantamos` |
| vosotros | `os` | `os levantáis` |
| ellos, ellas, ustedes | `se` | `se levantan` |
:::

::: piege La place du pronom
Le pronom se place **avant** le verbe conjugué : `me levanto`, et jamais `levanto me`.
En revanche, à l'infinitif, il se **colle à la fin** : `voy a levantarme`, « je vais me lever ».
Ce double fonctionnement est la principale difficulté du chapitre.
:::

::: motscles
- `levantarse` : se lever
- `despertarse` : se réveiller
- `ducharse` : se doucher
- `vestirse` : s'habiller
- `peinarse` : se coiffer
- `acostarse` : se coucher
- `llamarse` : s'appeler
:::

## 5. Dire l'heure

::: formule La structure de l'heure
Pour **une heure** : `Es la una.`
Pour **toutes les autres** : `Son las dos.` `Son las siete.`
:::

::: retenir
Le verbe est au **singulier** seulement pour une heure, parce que `una` est un singulier.
Partout ailleurs, il est au **pluriel** : `son las…`.
C'est la faute la plus fréquente sur cette partie.
:::

::: grille
| Français | Espagnol |
|---|---|
| Il est une heure | `Es la una.` |
| Il est trois heures | `Son las tres.` |
| Il est trois heures dix | `Son las tres y diez.` |
| Il est trois heures et quart | `Son las tres y cuarto.` |
| Il est trois heures et demie | `Son las tres y media.` |
| Il est quatre heures moins vingt | `Son las cuatro menos veinte.` |
| Il est quatre heures moins le quart | `Son las cuatro menos cuarto.` |
| Il est midi | `Es mediodía.` |
| Il est minuit | `Es medianoche.` |
:::

::: exemple Demander et donner l'heure
> `¿Qué hora es?`
> `Son las ocho y media.`

Pour dire à quelle heure a lieu une action, on emploie `a las` :
> `¿A qué hora te levantas?`
> `Me levanto a las siete.`
:::

## 6. Les moments de la journée

::: grille
| Espagnol | Français |
|---|---|
| `la mañana` | le matin |
| `el mediodía` | le midi |
| `la tarde` | l'après-midi |
| `la noche` | le soir, la nuit |
| `por la mañana` | le matin, habituellement |
| `por la tarde` | l'après-midi |
| `por la noche` | le soir |
| `hoy` | aujourd'hui |
| `mañana` | demain |
| `todos los días` | tous les jours |
:::

::: piege Mañana, deux sens
`la mañana` avec l'article signifie « le matin ».
`mañana` sans article signifie « demain ».
`Mañana por la mañana` veut donc dire « demain matin », et la répétition n'est pas une erreur.
:::

## 7. Les verbes de la vie quotidienne

::: motscles
- `desayunar` : prendre le petit déjeuner
- `comer` : manger, déjeuner
- `cenar` : dîner
- `estudiar` : étudier
- `trabajar` : travailler
- `escuchar` : écouter
- `leer` : lire
- `escribir` : écrire
- `salir` : sortir
- `volver` : rentrer
:::

::: info Comer, deux emplois
`comer` signifie « manger » au sens général, mais aussi « déjeuner » en Espagne, où le repas de midi s'appelle `la comida`.
Le contexte lève l'ambiguïté : `como a las dos` veut dire « je déjeune à deux heures ».
:::

Fin de la deuxième séance.
:::

## 8. Raconter sa journée

::: methode Raconter sa journée en six phrases
::: etapes
1. Je dis à quelle heure je me lève : `Me levanto a las…`
2. Je dis ce que je fais ensuite : `Después, me ducho y desayuno.`
3. Je dis ce que je fais le matin : `Por la mañana, estudio…`
4. Je dis quand je déjeune : `Como a las…`
5. Je dis ce que je fais l'après-midi : `Por la tarde…`
6. Je dis à quelle heure je me couche : `Me acuesto a las…`
:::
:::

::: exemple Une journée complète
> `Me levanto a las siete y media.`
> `Después, me ducho y desayuno con mi familia.`
> `Por la mañana, estudio matemáticas y francés.`
> `Como a la una y media.`
> `Por la tarde, escucho música y leo.`
> `Me acuesto a las diez.`

Six phrases, trois verbes pronominaux, deux indications d'heure, deux moments de la journée. C'est exactement ce qui est attendu en production.
:::

::: motscles
- `primero` : d'abord
- `después` : ensuite
- `luego` : puis
- `más tarde` : plus tard
- `finalmente` : enfin
:::

::: aide Si l'on bloque à l'oral
Commencer par les deux phrases les plus sûres : `Me llamo…` et `Me levanto a las…`.
Le reste vient plus facilement une fois la voix lancée. Il vaut mieux six phrases simples et justes qu'une phrase longue et fausse.
:::

## 9. Poser des questions

::: grille
| Espagnol | Français |
|---|---|
| `¿Cómo te llamas?` | Comment t'appelles-tu ? |
| `¿Cuántos años tienes?` | Quel âge as-tu ? |
| `¿De dónde eres?` | D'où viens-tu ? |
| `¿Dónde vives?` | Où habites-tu ? |
| `¿Qué haces?` | Que fais-tu ? |
| `¿A qué hora…?` | À quelle heure… ? |
| `¿Por qué?` | Pourquoi ? |
| `¿Cuándo?` | Quand ? |
:::

::: piege Por qué et porque
`¿Por qué?` en deux mots et avec accent signifie « pourquoi ? ». C'est une question.
`porque` en un mot et sans accent signifie « parce que ». C'est une réponse.
`¿Por qué estudias español? Porque me gusta.`
:::

::: retenir
Tous les mots interrogatifs portent un **accent écrit** : `cómo`, `cuántos`, `dónde`, `qué`, `cuándo`, `por qué`.
Cet accent ne change pas la prononciation : il signale que le mot pose une question.
:::

## 10. Les pièges à éviter

::: grille
| Piège | Ce qui est faux | Ce qui est juste |
|---|---|---|
| L'âge | `soy trece años` | `tengo trece años` |
| Signe ouvrant | `Cómo te llamas?` | `¿Cómo te llamas?` |
| Place du pronom | `levanto me` | `me levanto` |
| Pronom à l'infinitif | `me voy a levantar` mal placé | `voy a levantarme` |
| L'heure au singulier | `es las tres` | `son las tres` |
| Mañana | confondre les deux sens | `la mañana` = le matin, `mañana` = demain |
| Por qué | `porque estudias?` | `¿Por qué estudias?` |
| Accent des interrogatifs | `como te llamas` | `¿Cómo te llamas?` |
:::

::: retenir
Trois phrases suffisent à retenir le chapitre.
**Pour l'âge, on emploie tener : tengo trece años.**
**Le pronom du verbe pronominal se place avant le verbe conjugué, et après l'infinitif.**
**Une seule heure prend le singulier : es la una ; toutes les autres, son las…**
:::

::: cocher
- Je sais me présenter en cinq phrases
- Je sais conjuguer un verbe régulier des trois groupes
- Je connais par cœur `ser` et `tener`
- Je sais employer six verbes pronominaux
- Je sais dire l'heure, y compris et quart, et demie, moins le quart
- Je connais les moments de la journée
- Je sais raconter ma journée en six phrases
- Je sais poser six questions différentes sur quelqu'un
:::
