## 1. Pourquoi une trame fixe

La prévisibilité fait une grande partie du travail. Quand le **déroulé** est connu
à l'avance et identique d'une fois sur l'autre, l'énergie disponible passe entièrement
dans le **contenu** au lieu de servir à anticiper ce qui va arriver.

::: retenir La règle qui tient tout
Ce qui est annoncé en début de séance **ne change pas** en cours de séance.
Pas d'exercice ajouté, pas de séance prolongée, même si tout se passe bien.
:::

## 2. La trame minutée

::: grille
| Temps | Phase | Ce qu'on fait | Durée |
|---|---|---|---|
| 0 → 2 | **Annonce** | Dire ce qu'on va faire, combien de temps, ce qui se passe après. L'écrire quelque part de visible. | 2 min |
| 2 → 7 | **Réactivation** | Trois questions sur la séance précédente. But : réussir, pas évaluer. | 5 min |
| 7 → 27 | **Découverte 1** | Fiche de cours, premiers blocs. Lecture à voix haute si elle aide. | 20 min |
| 27 → 32 | **🔁 Pause** | Vraie pause. Pas d'écran, aucune question sur le cours. | 5 min |
| 32 → 52 | **Découverte 2** | Fiche de cours, blocs suivants. | 20 min |
| 52 → 67 | **Application** | Exercices de niveau *Application* uniquement. Correction après **chaque** exercice. | 15 min |
| 67 → 72 | **Clôture** | Un point sur la grille d'évaluation. Annonce de la séance suivante. | 5 min |
:::

::: info La proportion normale
**72 minutes de séance pour 55 minutes de travail effectif.**
Viser 100 % de temps utile est le meilleur moyen d'obtenir 40 %.
:::

## 3. Les règles de conduite de séance

::: methode Les transitions
::: etapes
1. **Prévenir** : « dans 3 minutes, on passe aux exercices ».
2. **Nommer** : « on quitte la leçon, on passe à l'entraînement ».
3. **Clore** : « la partie cours est terminée, on n'y revient plus aujourd'hui ».
:::
:::

::: grille
| Situation | Réponse |
|---|---|
| Blocage à l'entrée sans avoir lu l'énoncé | Lire l'énoncé à voix haute, faire ensemble la première ligne |
| Question répétée à l'identique | Répondre à l'identique, calmement, autant de fois que nécessaire |
| Irritation sur un détail de forme | Pause immédiate, reprise ensuite **au même endroit** |
| La séance se passe très bien | **Ne rien ajouter.** S'arrêter à l'heure annoncée |
| La séance se passe mal | Raccourcir la **suivante**, pas la rendre plus facile |
:::

## 4. La fiche vierge à remplir

::: grille
| | |
|---|---|
| **Date** | |
| **Matière** | |
| **Leçon (référence)** | |
| **Objectif annoncé, en une phrase** | |
| **Documents utilisés** | 1-cours ☐ 2-revision ☐ 3-exercices ☐ 4-evaluation ☐ |
| **Exercices prévus (numéros)** | |
| **Durée annoncée** | |
| **Ce qui se passe après la séance** | |
:::

::: piege Le champ le plus important
**« Exercices prévus (numéros) »**. Écrire « 1 à 5 » et s'y tenir.
« On verra jusqu'où on va » transforme chaque exercice en négociation.
:::

## 5. Le bilan de fin de séance

Trois lignes, pas plus, à reporter dans `00-pilotage/journal-seances/`.

::: grille
| | |
|---|---|
| **Ce qui a été traité** | |
| **Ce qui a bloqué, et à quel moment précis** | |
| **Décision pour la prochaine fois** | |
:::

::: cocher
- Le déroulé a été annoncé au début
- La pause a été prise
- Rien n'a été ajouté en cours de séance
- La séance s'est arrêtée à l'heure annoncée
- Le bilan en trois lignes est écrit
:::
